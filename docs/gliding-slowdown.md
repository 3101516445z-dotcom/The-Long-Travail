# 无垠恶意：滑翔减速适配

2026-09-30：修复发布自检中记录的高空鞘翅减速缺少本地生效路径的问题。

## 行为

佩戴苦旅、尚未获得无垠见证、位置高于 `boundless.heightThreshold` 时，滑翔使用现有 `boundless.speedReduction` 配置。默认减速 80%，即原版当帧计算出的三轴位移乘以 0.2。

只缩放 `LivingEntity.travel` 的鞘翅分支传给 `move` 的位移。保留原版速度递推、俯仰控制、重力和烟花推进；不把减速后的位移写回下一帧速度，因此不会累积乘以 0.2。实际距离仍受碰撞限制，并不表示从不同位置出发的两条完整飞行轨迹始终严格相差五倍。

普通移动继续使用 `AltitudeSpeedMixin`，能力飞行继续使用已有飞行速度调整。删除服务端事件中旧的滑翔 `setDeltaMovement` 反复缩速。新增 Mixin 在公共列表注册，由实际执行移动的端生效，沿用已有配置同步和每玩家缓存。

碰撞仍由 `Entity.move` 处理；不恢复被碰撞清零的速度。原版滑翔撞墙伤害公式中的速度损失按同一系数换算，再应用原版伤害门槛及音效判断。离开高空区域、解除装备或取得无垠见证后恢复原版位移，允许发生即时速度变化。

## 验证

`tools/smoke/GlidingSlowdownSmoke.java` 调用经过 Mixin 转换的原版 `travel`：连续 80 帧对照、改变俯仰、真实烟花实体推进、额外冲量、0/50/80/100% 减速、高度边界、见证和卸下装备、模拟撞墙伤害、真实石块碰撞。与现有 smoke 一起运行；日志为 `build/gliding-review.log`。

自动化测试使用隔离服务端中的可本地控制 FakePlayer，未替代完整整合包的客户端联机实飞验收。其他模组若直接替换原版滑翔移动流程，需要单独核查兼容性。
