# 穷遐之见证：增益升级黑名单

在 `config/the_long_travail-common.toml` 的 `[farReach]` 段内填写：

```toml
beneficialLevelBonusBlacklist = ["minecraft:night_vision", "minecraft:water_breathing"]
```

默认值为 `[]`，不排除任何效果。支持原版和模组药水效果的完整注册 ID（`命名空间:路径`），不支持显示名称、通配符或标签。前后空格会去除，重复项自动合并；格式错误的 ID 忽略并记录警告，未安装的效果 ID 保留并提示。

黑名单仅跳过穷遐之见证的额外等级提升：效果仍可正常获得，持续时间及显示标志不变，原本就是高等级的效果不会降级；不会将它从随机增益池中移除，也不限制其他模组提升等级。

Forge 配置重载后更新缓存，后续获得或续加效果时使用新名单。已经生效的效果不会被追溯降级。多人游戏由服务端配置决定；无须给客户端同步名单。
