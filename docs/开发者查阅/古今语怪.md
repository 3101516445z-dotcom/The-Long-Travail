# 古今语怪

玩家操作见[使用说明](../玩家查阅/古今语怪.md)。本页说明内部实现约定，不作为稳定公共 API。

## 职责与数据

- `item/AncientStrangeTalesItem`：继承 `BookItem`，堆叠上限 1；接入无垠名称、拾遗说明及书式附魔资格。
- `boundless/EnchantmentTransfer`：使用单件副本计算来源与目标的变更；筛选、适用性、冲突检查、材料门槛、255 等级上限及 NBT 读写均集中于此。
- `boundless/EnchantmentTransferRecipe`：一个 `CustomRecipe` 支持双方向、三种筛选模式，三个入口复用按输入缓存的计划，不在预览阶段改变输入。

古今语怪使用 `Enchantments`；原版附魔书使用 `StoredEnchantments`。读写保留已有条目的额外字段；未知 ID、非正等级、重复条目及非法结构不生成转移结果。不得用 `EnchantmentHelper.setEnchantments` 直接替换来源附魔书：该方法对原版附魔书采用逐项追加逻辑，不能正确删除或降低旧附魔。

正常来源不存在内部冲突时无需额外排序。来源存在冲突时按 NBT 原有顺序尝试，每次成功转移都会更新接收集合；不清理未转移的异常组合。

仅直接支持标准附魔 NBT。覆盖附魔读取、使用能力或自定义容器存储的模组物品需要单独核对，不以物品黑名单代替能力判断。

## 等级与材料资格

`Materials` 保存本次合成是否提供三种升级材料，以双方等级差的绝对值判断资格。差值不超过 10 无额外门槛，11～100 要求回响碎片，超过 100 同时要求回响碎片、下界之星及附魔之瓶。资格对所有附魔共享。

目标没有同种附魔时保留来源等级，仍受 255 上限约束。目标已有同种附魔且未满上限时，结果为 `min(255, max(source, target) + 1)`，成功后移除来源的该附魔。未满足材料、适用性或冲突条件的条目保留，不妨碍其他条目转移。外部输入的来源等级超过 255 且目标无同种附魔时，按可接收部分转移并保留超出部分。

## 合成返还

枚举材料角色，拒绝不唯一的有效解释，避免目标恰好为材料物品时由槽位顺序决定方向。只允许一个古今语怪、一个方向材料、一个目标、最多一个筛选材料，以及回响碎片、下界之星、附魔之瓶各一个材料槽。重复材料角色和其他多余输入不生成结果。

接收方进入结果槽，来源单件副本通过 `getRemainingItems` 放在来源槽，蜂蜜瓶固定返回一个玻璃瓶。主体不调用通用容器剩余物接口，避免重复返还空容器。

原版 `ResultSlot` 消耗每个非空槽的一件输入；不相同的返还物会进入背包或掉落。严禁输出原堆叠数量或同时把接收方写入剩余物。

## 原版接入边界

附魔台资格通过物品自身的 `canApplyAtEnchantingTable` 提供，以 `isAllowedOnBooks` 为许可依据。候选筛选、等级和随机选取由当前附魔系统负责，不修改 `EnchantmentHelper` 或 `EnchantmentMenu`，也不模拟普通书的随机删减。附魔自身重写的资格限制仍可能优先生效；合成转移独立执行本页的规则。

| Mixin / 资源 | 作用 |
| --- | --- |
| `TalesAnvilMixin` | 在 `AnvilMenu.createResult` 的左侧附魔书适用性豁免中包含本物品；不改右侧书材料识别 |
| `minecraft:bookshelf_books` | 追加物品，沿用雕纹书架存取 |

铁砧 Mixin 限定方法中的 `ItemStack.is(Item)` 调用，不全局修改物品身份，不覆盖整段原版方法。移植版本时须重新核对调用点，尤其不能把右侧材料判断也扩大到古今语怪。

铁砧继续运行冲突检查、正常附魔等级上限及费用逻辑，包括现有冥府见证处理与神化兼容。高等级同种附魔合并可能降级，这是正常铁砧规则；自定义合成的等级提升与材料门槛不用于铁砧。

## 注册与资源

物品 ID 为 `the_long_travail:ancient_strange_tales`，特殊配方类型为 `the_long_travail:enchantment_transfer`。五语言短述与 JEI 说明维护于 `src/main/lang/*/aspects/boundless.json`，拾遗正文维护于 `catalog_boundless.json`；拾遗条目属于无垠主题，JEI 通过 `BoundlessJeiPlugin` 显示物品说明。

## 回调异常与提示

附魔筛选、适用性或兼容性回调抛出运行时异常时取消整个计算，保留输入；适用性回调收到目标副本。相同输入复用成功或失败结果，输入变化或标签重载后重新计算。`TransferNotices` 在服务端发送快捷栏提示，同组失败输入只提示一次，并在原版背包与工作台的结果领取前清除失效预览。详细职责见[运行时异常保护](runtime-failure-guards.md)。
