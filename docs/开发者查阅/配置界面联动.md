# 配置界面联动

当前适配对象为 Minecraft 1.20.1 Forge 下的 Forge Config Screens 8.0.2，仅接管苦旅 `ManagedConfig` 对应编辑页的“完成”提交。未安装该模组或版本不匹配时不注入；其他模组沿用原保存流程。此适配不提供远程修改专用服务器配置的功能。

## 保存流程

`compat/mixin/configscreens/ConfigScreenMixin` 在编辑页创建时记录配置文件版本、字段原值和界面草稿访问器；`ConfigScreenSaveMixin` 在原界面写入运行值之前接管保存。事务逻辑位于 `compat/configscreens/ConfigScreenSession`。

提交时校验各字段，拒绝打开页面后发生的磁盘修改，并通过既有 `ManagedConfig.update` 先保存再发布。仅提交相对于打开页面时改变的字段。发布前校准 Forge 的内存注释，避免 Forge 因注释差异再次绕过安全入口写盘。成功后发送一次重载事件，复用原有运行状态刷新和客户端提示同步。

失败时保留磁盘文件与运行值，显示提示；草稿保留在当前编辑页，用户可返回配置列表重新打开。无修改时退出不写盘、不发送重载事件。取消按钮沿用原界面逻辑。
