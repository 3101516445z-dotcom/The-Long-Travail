## 术语与证据

- **通用基础**：承担可复用能力，尽量不引用具体玩法；不意味着脱离 Minecraft API。
- **核心协调**：在模组运行中居于中心，但可能直接依赖多个具体玩法。
- **模块**：按职责划定的逻辑单元，可跨越多个 Java 包；不等于目录或 Gradle 子工程。
- **目录初分**：依据包职责建立的查阅归属，仍需逐类复核；不会据此移动代码。
- **静态引用候选**：从代码文本获得的关系线索，不是已经解析的真实方法调用。
- **人工核对链路**：已阅读对应入口和处理分支；不等于客户端或整合包测试通过。

本项目书描述现状。改善建议、待确认行为和已确认实现必须分开；不能把理想分层写成已经实现的架构。
