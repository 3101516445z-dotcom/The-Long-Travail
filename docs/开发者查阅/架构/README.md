# TLT 代码架构与维护手册

TLT 是面向 Minecraft 1.20.1、Forge 的六主题玩法模组。本手册说明源码职责、数据生命周期和功能协作，供定位实现与维护功能使用。

## 阅读顺序

1. [总体架构](总体架构.md)：了解平台、领域数据、核心协调与玩法扩展之间的关系。
2. [模块与链路导航](链路/README.md)：按功能进入模块，再沿链路查看触发、状态变化、反馈和清理。
3. [源码归属](索引/源码归属.md)与[引用候选](索引/引用候选.md)：定位文件和关联入口。

## 文档分工

| 目录 | 内容 |
|---|---|
| 模块 | 职责、主要入口、依赖与扩展方式 |
| 链路 | 触发条件、处理顺序、数据生命周期与回归关注点 |
| 索引 | 自动生成的文件归属、词法引用候选与输入指纹 |
| 维护 | 更新规则、验证证据及发布验收事项；过程记录位于历史记录 |

API 参数与调用契约以 [状态与旅程 API](../state-api.md)、[携带 API](../carrying-api.md)、[运行时约定](../runtime-integration.md) 等接口文档为查阅入口。玩家操作和效果说明见 [玩家文档](../../玩家查阅/README.md)。

“模块”按职责划分，可以跨越 Java 包；“引用候选”来自词法扫描，具体调用需沿源码确认。模块和链路正文描述实现，测试执行结果集中在 [当前状态与验收边界](维护/当前状态与验收边界.md)。
