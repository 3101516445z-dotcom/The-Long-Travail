# 归墟战斗与药效

补齐駅战斗资格、深夜拉菲药效与夜间加成，并校正完美流体物品和日记流体侵蚀的归属。女仆完整事件链与第三方药效合并行为仍独立待验收。

## 駅：资格与移速

ekiState 要求实际日记、天气符合 EKI_LOCAL/EKI_SKY 配置、CarryingApi.isCarrying 确认携带；UNKNOWN 不视为携带。天气仅限主世界，下雨或雷暴，并按配置检查露天及当地降水。满足后有归墟见证返回 WITNESS，否则 MALICE；不是另外强制查询独立恶意标记。

EkiItem.inventoryTick 只是外部携带信号接入，内置区域与实际物品查询由 CarryingApi 负责。不能把東海道的配置装备槽查询当成駅的查询。

RainState.speed 在服务端恶意时返回 1+RainConfig.SPEED，其余为 1；客户端仅使用匹配 clientPlayerId 的同步倍率。[AltitudeSpeedMixin](../../../../src/main/java/com/thelongtravail/mixin/AltitudeSpeedMixin.java) 在 Player.getSpeed 返回原速度×高度倍率×駅倍率，僵直时直接为 0。这里不增删速度 AttributeModifier，也不是与磷叶石互相转换属性。

## 駅战斗与日记回退

CombatContext 在非终结、非玫瑰、攻击者为另一名 ServerPlayer 且駅恶意时记录 RainConfig.DAMAGE，汇入 outgoingBonus。移速与增伤使用同一资格查询，但属于不同消费者。

免疫求值位于上下文一次性 immunityEvaluated 区域，终结和玫瑰路径提前返回。玩家駅生效但非见证时按 MALICE_SKIP 决定是否跳过受击惩罚；见证抽取要求 amount>0、非 GENERIC_KILL，且伤害类型 ID 不在 IMMUNITY_EXCLUSIONS。

| 情况 | 行为 |
|---|---|
| 駅见证抽中 IMMUNITY | 设置 ekiImmune；受击惩罚跳过由 IMMUNE_SKIP 决定 |
| 駅符合抽取条件但未抽中 | 仅在 FALLBACK 开启时继续日记归墟见证回退 |
| 駅不符合抽取条件 | 有日记归墟见证时仍可进入日记回退，不受前一行 FALLBACK 限制 |

回退检查 CombatRules.abyssEnvironmentDamage，或正伤害、非 GENERIC_KILL、玩家处于流体/水泡/岩浆时按 ABYSS_CANCEL_CHANCE 抽取。排除某伤害的駅概率免疫不自动等同于排除日记所有保护。ekiImmune 最终进入公共 blocked，其他免疫和反馈仍按 CombatContext 次序处理。

RainState.forget/clear 清携带和东海道位置缓存；客户端 reset 将速度恢复 1。这里没有持久化“駅已免疫”状态，每个伤害上下文重新求值。

## 拉菲：装备与夜间输出

有效装备要求存活、非旁观玩家在非装饰 hands 槽携带拉菲；非玩家委托 MaidAccessories。Item 的 canEquip 无日记要求，因此基础药效能力不应添加日记前置。阶段加成另查 TravailStateApi。

dayTime 经 floorMod 24000：前半周期没有夜间增伤；后半周期见证固定 witnessBonus，恶意使用非负正弦曲线（18000 达峰）。只有“不晴天且不露天”同时满足才使用 shelteredNonClearPeak，其余用 malicePeak。晴天/露天复用 IcarusEnvironment，包括下界/末地特例，不能简化成仅按主世界天气。

CombatContext 对玩家拉菲输出快照排除终结、玫瑰和自伤，并在公共 outgoingBonus 汇总；其他特殊来源再由公共上下文控制。女仆另有调用入口，不因本章读取玩家链路而声明完整兼容通过。

## 药效等级、时长和免疫是三条路径

基础 levels 只给再生和饱和配置等级增益，不要求阶段。IncomingEffectLevels 在服务端计算，排除槲寄生；再加符合穷遐见证规则的有益效果增益，使用 RuntimePools 的最大等级或回退上限。返回值至少为 original，所以不会为了上限降低已有更高等级。

常规 addEffect 的入口顺序为：拉菲需要等级增益时先深复制效果及 hidden 链，再经 FloralEvents 延长、女仆延长、拉菲 duration、孢子花 shorten，最后调用原方法。Added 事件经 TravailEffectActions 调用 adjusted 设置等级；不是 duration 方法同时负责等级提升。

[LafiteInstantEffectMixin](../../../../src/main/java/com/thelongtravail/mixin/LafiteInstantEffectMixin.java) 对即时 SATURATION 且有效装备者另行调整传入 amplifier，再调用原即时效果；这条路径不能由普通 Added 事件覆盖情况直接推断。

duration 仅改有限正时长的 POISON/CONFUSION。乘数为 1、无限或非正时长保留原对象；恶心乘数>1 时还要求 LAFITE_NAUSEA 模式规则允许。新时长向上取整并限制在 1 到 Integer.MAX_VALUE。copyEffect 递归复制 hidden 链，但 duration 只修改顶层时长；不能说隐藏效果都被同倍率缩放。后续孢子花逻辑有自己的递归行为。

见证免疫仅针对 HUNGER 和 LEVITATION：Applicable 事件 LOWEST 在服务端设置 DENY；玩家 END tick 的 clear 清除已存在效果，ServerPlayer 经 EffectChanges.remove，其他实体经 removeEffect。卸下或阶段失效后停止后续拒绝/清理，不恢复此前已删除或已改写的效果，也不撤回已经发生的即时饱和收益。

## 完美流体与流体侵蚀的归属校正

当前 [AbyssItem(false)](../../../../src/main/java/com/thelongtravail/item/AbyssItem.java) 是可堆叠的普通物品，主要提供名称和说明；[PerfectFluidRecipe](../../../../src/main/java/com/thelongtravail/abyss/PerfectFluidRecipe.java) 接入复制。检索 PERFECT_FLUID 的主源码使用者未发现其授予流体侵蚀战斗能力的调用。复制路径继续见 [复制预览与领取](复制预览与领取.md)。

[TravailEvents](../../../../src/main/java/com/thelongtravail/event/TravailEvents.java) 在已有日记的玩家维护路径中，按 diaryApplies、未见证归墟、接触流体和周期到期条件调用 [TrueDamage.hurtFluid](../../../../src/main/java/com/thelongtravail/helper/TrueDamage.java)，使用 fluid_erosion 类型。该调用不要求携带完美流体。

侵蚀保护策略由 CombatContext/AttributeDamage 与相关吸收桥接承担，完整日记周期规则见 [日记主题与阶段](日记主题与阶段交叉复核.md)。
