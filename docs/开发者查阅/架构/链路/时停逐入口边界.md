# 时停逐入口边界

说明活塞、爆炸、传输/拾取、连接输入与客户端桥接。主体更新和任务队列见 [时停与恢复](../模块/时停与恢复.md)、[冻结与恢复](冻结与恢复.md)。下表是 TLT 源码行为，第三方更新接入位置见 [时停模块](../模块/时停与恢复.md)。

## 判定基础

[TimeStopManager](../../../../src/main/java/com/thelongtravail/boundless/TimeStopManager.java) 的实体查询使用实体位置并检查 allies/归属豁免；方块位置查询按方块中心检查场域，不携带操作者身份。客户端查询转发到同步视图。实体豁免不能推导为其操作的方块、容器或粒子也豁免。

“拒绝/跳过”仅取消当前调用，后续由原有玩法再次触发；“转存”才有明确的恢复队列。两者不能统一写成解冻后重放。

## 方块、物品与容器

| 源码 / 方法 | 判定与动作 | 恢复边界 |
|---|---|---|
| [TimeStopPistonMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopPistonMixin.java) triggerEvent | 使用 resolver 检查活塞、前方、待推动方块及目的地、待破坏方块；任一位置冻结则返回 false | 服务端将原 BlockEventData 及全部 gates 转存 FrozenBlockEvents；解冻且满足加载条件后重新提交事件，不保存完整 resolver 结果 |
| 同类 moveBlocks | 检查同一组位置，冻结则返回 false | 服务端记录活塞位置的邻居通知，恢复时重新触发判断；不是保存后续机械移动步骤 |
| [TimeStopExplosionMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopExplosionMixin.java) finalizeExplosion | 从 toBlow 删除冻结位置 | 不取消整个爆炸，不在此处理实体伤害，不排队补炸 |
| [TimeStopHopperMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopHopperMixin.java) addItem(Container, ItemEntity) | 物品实体或目标容器冻结则返回 false | 不转存吸取请求 |
| 同类 addItem(Container, Container, ItemStack, Direction) | 来源或目标容器冻结则原样返回传入 stack | 表示本次传输未接受，不另创建恢复任务 |
| 同类 suckInItems | 检查漏斗坐标上方一格位置，冻结则返回 false | 不是仅检查漏斗自身，也不是所有机器传输的通用拦截 |
| [TimeStopPickupMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopPickupMixin.java) ItemEntity / ExperienceOrb.playerTouch | 被接触的物品/经验实体冻结则取消 | 此入口不单独查询拾取玩家，后续接触才能再尝试 |
| [TimeStopMobPickupMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopMobPickupMixin.java) Mob / Allay.pickUpItem | 物品实体冻结则取消 | 不将豁免拾取者视为自动放行冻结物品 |
| [TimeStopItemMergeMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopItemMergeMixin.java) isMergable | 当前物品实体冻结则 false | 不排队合并 |
| [TimeStopOrbMergeMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopOrbMergeMixin.java) canMerge | 现有经验球冻结则 false | 实体查询包含其豁免规则 |
| 同类 tryMergeToExisting | 新经验位置落入任何场域则 false | 使用精确 Vec3 与场域包含关系，不查询实体豁免；拒绝合并不等于拒绝生成所有经验球 |

[FrozenContainers](../../../../src/main/java/com/thelongtravail/boundless/FrozenContainers.java) 是共享识别辅助：BlockEntity 按位置、Entity 按实体规则、CompoundContainer 递归检查两半；其他 Container 返回 false。菜单先检查所有 slot.container，再反射查找菜单继承链中类型恰为 ContainerLevelAccess 的非静态可访问字段。无法建立来源的自定义菜单不自动视为冻结；字段读取的 IllegalAccessException 会转为 IllegalStateException。此辅助没有持久化任务或重试队列。

## 服务端连接输入

[TimeStopConnectionMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopConnectionMixin.java) 的下列包入口先调用 ensureRunningOnSameThread；它们是原版协议处理桥接，不是新的 TLT 自定义协议注册。

| 入口 | 条件与处理 | 同步 / 补偿 |
|---|---|---|
| handleMovePlayer | 冻结玩家取消；未冻结且有位置的包按 clip 裁剪位移，必要时替换 PosRot 包 | 不暂存玩家动作，也不在这里自行发送传送包 |
| handleMoveVehicle | 玩家或当前坐骑冻结则取消 | 本入口不实现车辆包的边界裁剪 |
| connection.tick | 玩家或 rootVehicle 冻结 | 清 aboveGround 计数及浮空标记，继续连接 tick，非断开连接 |
| handleUseItem | 玩家冻结则取消 | 无恢复队列 |
| handleUseItemOn | 玩家、命中方块或相邻放置位置冻结则取消 | 向客户端补发命中位置的方块更新 |
| handlePlayerAction | 玩家或包中位置冻结则取消 | 补发该位置方块更新；判断覆盖这个包入口而非只列一种挖掘动作 |
| handleInteract | 冻结玩家全部取消；未冻结玩家面对冻结目标时，取消普通交互但放行 attack 分支 | 普通交互拒绝时同步当前菜单；放行只指此桥接，后续伤害规则仍有效 |
| handleContainerClick | 玩家冻结，或非玩家自身库存菜单被 FrozenContainers 判为冻结，则取消 | sendAllDataToRemote；不缓存点击等待解冻 |
| handleContainerButtonClick | 同上 | 这里只取消，没有同样的显式全量菜单重发 |
| handlePlayerCommand | 玩家冻结则取消 | 原版玩家动作包入口，不等于取消所有聊天命令 |

这里不能推出“冻结目标完全无法受伤”或“所有网络包都被拦截”。Forge 交互事件及第三方自有包仍需按各自入口查证。

## 客户端显示与本地更新

| 源码入口 | 实际行为 | 豁免与恢复 |
|---|---|---|
| [TimeStopLocalPlayerMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopLocalPlayerMixin.java) LocalPlayer.tick | 冻结时 setOldPosAndRot 并取消 | 使用实体冻结查询；解冻后恢复正常 tick，不补算旧 tick |
| [TimeStopClientLevelMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopClientLevelMixin.java) tickNonPassenger/tickPassenger | 冻结实体固定旧位置/旋转并取消自身更新；仍递归处理其乘客 | 乘客独立判断，不能把整条乘骑链视作同一豁免结果 |
| 同类 doAnimateTick | 第一次读取选中位置方块状态前，若该位置冻结则取消本次调用 | 位置判定；不冻结整个客户端世界，也不排队补播 |
| [TimeStopEntityRenderMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopEntityRenderMixin.java) render | 冻结实体传入 partialTick=1.0F，否则传原值；继续调用原渲染 | 固定插值参数，不隐藏实体，不保证第三方自有动画时钟也暂停 |
| [TimeStopParticleMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopParticleMixin.java) tickParticle | 同步场域有效且粒子位置落入球内时，固定旧坐标并取消粒子 tick | TimeStopCue.exempt 粒子例外；不使用实体 allies 判定，解冻后继续剩余粒子生命周期 |

客户端依赖已收到的场域视图，不是服务器物理状态的独立权威来源；本次未验证同步延迟、画面或输入手感。

## 维护和验证

修改一个桥接前，先明确查询对象是实体还是位置、是否转存、返回值由谁消费、是否需要客户端纠正。新增机器或菜单支持应补充真实来源识别，不能默认所有未知容器都等同已支持容器。

回归关注点：跨场域活塞推动/回缩、爆炸实体与方块效果区别、双箱和自定义容器、豁免玩家拾取冻结物品、经验球生成/合并、菜单纠正、冻结目标攻击、乘客差异豁免、粒子提示与第三方渲染。
