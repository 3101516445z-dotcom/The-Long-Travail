# 永生芽赋予与物品保护

永生芽属于繁茂主题的普通材料，物品 ID 为 the_long_travail:immortal_bud。保护状态保存在物品栈中，按实例标记生效。

## 职责和路径

| 职责 | 源码入口 | 维护边界 |
|---|---|---|
| 物品入口 | [ImmortalBudItem](../../../../src/main/java/com/thelongtravail/item/ImmortalBudItem.java) | 物品属性、主题名称、简述与详情；详情第三条后插入空白组件 |
| 规则与数据 | [ImmortalBud](../../../../src/main/java/com/thelongtravail/flourishing/ImmortalBud.java) | 标记判定、目标资格、复制赋予、掉落物保护资格 |
| 合成适配 | [ImmortalBudRecipe](../../../../src/main/java/com/thelongtravail/flourishing/ImmortalBudRecipe.java) | 槽位匹配、输出与剩余物；由 ModRegistry 注册序列化器 |
| 破损判断 | [ImmortalBudHurtMixin](../../../../src/main/java/com/thelongtravail/mixin/ImmortalBudHurtMixin.java) | ItemStack.hurt 入口拦截正数损耗 |
| 耐久写入 | [ImmortalBudDamageMixin](../../../../src/main/java/com/thelongtravail/mixin/ImmortalBudDamageMixin.java) | Item 提供 IForgeItem.setDamage 转发，拒绝损伤增加 |
| 掉落物生命周期 | [ImmortalBudDropMixin](../../../../src/main/java/com/thelongtravail/mixin/ImmortalBudDropMixin.java) | 火焰、爆炸伤害拦截及非负 age 重置 |

物品入口、主题玩法和原版注入分别维护；三个 Mixin 注册在 [公共清单](../../../../src/main/resources/mixins.the_long_travail.json)。

## 运行链路

1. [制造配方](../../../../src/main/resources/data/the_long_travail/recipes/immortal_bud.json) 使用树苗标签、骨粉、无穷花生成永生芽。
2. [赋予配方](../../../../src/main/resources/data/the_long_travail/recipes/immortal_bud_apply.json) 进入 ImmortalBudRecipe，要求一个芽槽位和一个有耐久容量、未标记的目标槽位，不允许其他非空槽位。
3. assemble 调用 ImmortalBud.apply，复制目标栈，输出数量为一，写入独立布尔标记并令 Damage 为零。预览不修改输入；领取由原版合成流程消耗材料，剩余物全部为空，避免重复返还目标。
4. 此后耐久调用通过 hurt 前置保护和 setDamage 写入保护两条入口处理；两者互补，不能仅保留 setter。Forge 的 hurt 使用局部计算损伤判断破损，拒绝写入不能单独阻止超额消耗后的破损返回值。
5. 掉落后从实体所持 ItemStack 读取保护资格。永生芽自身或带标记的栈防火、防爆，并重置非负年龄以阻止普通自然消失；正常 tick、拾取和合并继续执行。保存重载依靠物品栈 NBT，无需额外生命周期缓存。

完整 NBT 契约、Forge 转发原因、绕过路径和保护边界统一维护在 [永生芽开发说明](../../immortal-bud.md)，玩家效果见 [玩家说明](../../../玩家查阅/immortal-bud.md)。

## 展示与资源维护

- [ThemeTooltips](../../../../src/main/java/com/thelongtravail/client/ThemeTooltips.java) 在原名称之后插入“恒久长青”，使用繁茂主题材质；简述通过两个语言键输出。
- [CatalogEntries](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogEntries.java) 注册拾遗入口；ImmortalBudItem 提供六条说明和一个空白组件；[CatalogTextStyle](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogTextStyle.java) 按该条目的语言键限定术语与条件染色，空白组件重置段落去重。
- [FloralJeiPlugin](../../../../src/main/java/com/thelongtravail/compat/jei/FloralJeiPlugin.java) 提供六条信息说明；动态赋予不是固定输出展示。增删详情时同时核对物品详情和 JEI 键清单。
- 五语言维护源位于 src/main/lang/<locale>/aspects/flourishing.json；模型与贴图位于 assets/the_long_travail 的 models/item、textures/item；配方与解锁进度位于 data/the_long_travail。

## 修改后的核对顺序

先确认注册和配方，再检查复制不修改输入、数据保留与消耗；修改保护时核对三个 Mixin 的目标和公共清单；修改展示时核对提示、拾遗分段、JEI 与五语言。验证入口、证据范围及尚未覆盖的真实整包验收见 [当前状态与验收边界](../维护/当前状态与验收边界.md)。
