# 获取、配方与展示一致性

以 ModRegistry 的 24 个主题物品为范围，对照内置默认战利品、交易、方块破坏、配方及三个 JEI 插件。下表是模组源码默认入口，不是当前整合包最终获取指南。

## 共享奖励与特殊表不能混算

[UnifiedLootConfig](../../../../src/main/java/com/thelongtravail/loot/UnifiedLootConfig.java) 从 default_loot.json 建立 general.toml 的 loot.tables 默认值。[LootReloadEvents](../../../../src/main/java/com/thelongtravail/loot/LootReloadEvents.java) 在资源重载任务启动前同步读取配置；[TravailLootTableMixin](../../../../src/main/java/com/thelongtravail/mixin/TravailLootTableMixin.java) 在 freeze 前先注入 UnifiedLoot，再注入 MaterialLoot，覆盖该加载路径中的世界数据包表。

UnifiedLoot 为匹配表增加一个有名字的额外池：先判断表 chance，再按权重选一个物品，最后按 min/max 取数量；已有同名池不重复添加。默认 JSON 有 34 张表。比如末地城表 chance=0.35，伊卡洛斯/逍遥游/星之声/洛伦兹幻想权重为 2/3/2/3，不能把 35% 写成每件物品各自的概率。父表与子表独立，且没有额外附加玩家击杀、抢夺或精准采集条件。

MaterialLoot 的考古/钓鱼等特殊奖励改写原有单轮池的权重，保持一次抽取，不是额外再给一件。六张考古表为 desert_pyramid、desert_well、ocean_ruin_cold、ocean_ruin_warm、trail_ruins_common、trail_ruins_rare，堂吉诃德在各表占目标概率 5%；磷叶石仅 trail_ruins_rare 增加 5%。结构校验失败就保留原表并告警跳过；其他模组加池、条件或非固定轮数都可能影响是否可注入。共享池先注入同一特殊表，也可能令后续单轮结构不再合格。

完美流体配置默认 fishingChance=0.0025，注入宝藏子表时乘 20，即默认子表条件概率 5%；配置注释的 0.25% 是零幸运、开放水域基准口径，不能把对子表的 5% 当作每次垂钓概率。修改原版宝藏分支、幸运或开放水域条件后，须重新核算。loot.enabled 控制共享池及完美流体概率，不代表同时关闭全部精粹/考古注入。

配置非法时按 UnifiedLoot 的逐表/整体保留策略处理，不等于所有表自动回到默认。默认初始化、迁移及全项目池重载的完整审计仍归 A08；本章核实当前获取消费者与默认数据。

## 交易创建、补齐与价格

五种交易均注册在对应职业 5 级，默认单次补货最多购买 1 次、村民经验 30、价格乘数 0。乘数为零不等于所有第三方或 specialPrice 修改都被禁止。

| 输出 | 职业 | 默认成本 | 迁移与价格边界 |
|---|---|---|---|
| mistletoe | farmer | 64 骨粉 + 1 金苹果 | 识别旧 64+64 骨粉组合，仅替换序列化 buyB，保留 uses 等其余字段 |
| tower_of_babel | leatherworker | 1 鞍 + 1 山羊角 | 保留首条、移除同输出重复项；BabelOfferMixin 返回基础 A 成本 |
| don_quixote | shepherd | 1 盾牌 + 1 下界合金剑 | 保留首条、补齐缺项；匹配固定配方时 FixedMistletoePriceMixin 返回基础 A 成本 |
| phosphophyllite | mason | 64 青金石 + 1 幽谷之石 | 同上 |
| lorentz_fantasy | fletcher | 64 绿宝石 + 64 龙息 | 保留首条、补齐缺项；固定价格 Mixin 和 BabelTrades 排除表没有包含它 |

[MistletoeTradeMixin](../../../../src/main/java/com/thelongtravail/mixin/MistletoeTradeMixin.java) 在 AbstractVillager.getOffers 返回时对 Villager 依次调用四类 ensure；入世事件主动读取符合职业/等级的村民 offers，让已有大师村民也可补齐。ensure 按输出物品去重，不是只识别自己创建的交易，因此同输出的第三方自定义交易也可能被去重。

除槲寄生的特定旧成本组合外，这些 ensure 并不把保留下来的首条交易强制改成默认成本，也不重置其使用次数。[FixedMistletoePriceMixin](../../../../src/main/java/com/thelongtravail/mixin/FixedMistletoePriceMixin.java) 的匹配含成本数量检查；[BabelOfferMixin](../../../../src/main/java/com/thelongtravail/mixin/BabelOfferMixin.java) 另处理巴别塔。BabelTrades.refresh 跳过三类 fixed 交易，但洛伦兹幻想不在此列表，不能写成“五种都完全固定价”。

## 小王子：概率与一次性保底

[PrinceBlockBreakMixin](../../../../src/main/java/com/thelongtravail/mixin/PrinceBlockBreakMixin.java) 包装 ServerPlayerGameMode.destroyBlock，保留破坏前状态并在原调用返回后传入结果。broken 要求成功、非创造/旁观者、方块状态确实改变；只对虞美人与玫瑰丛登记。爆炸、其他实体破坏或直接删除方块不自动经过这个玩家入口。

玩家 persistentData 的 the_long_travail:prince_progress 保存 roses、poppies、completed。两种计数分别累计，玫瑰达到 300 或虞美人达到 600 时任选其一触发一次保底，删除两计数并置 completed。混合破坏不会按比例合并阈值。Clone 复制完整进度标签。

每次先登记计数；达到保底直接产出，否则独立随机判断。默认虞美人 0.2%、玫瑰丛 0.5%。提前随机得到小王子不会清计数或设置 completed；一次保底完成后仍有随机掉落。概率设为零也不会禁用硬编码保底。保底与随机以短路 OR 合成，一次调用最多生成一个小王子。

completed 在 Block.popResource 之前写入；发放是世界掉落，不是直接入背包，也没有在掉落实体被取消/无法拾取后回滚计数的处理。不要将其描述为“保证物品进背包”。玫瑰双格一次实际破坏调用及保护模组取消需运行验证，不能从语言文本代替验收。

## 配方与 JEI 的一致性边界

内置配方共 42 份 JSON：25 份 spring_corner 春日一隅、15 份普通 shaped、2 份特殊配方。六个主题物品有普通 shaped 直接产出：槲寄生、无穷花、黄金时代、伊卡洛斯、万魂幡、地下丝绒；其余普通 shaped 是石与公共工具。标签实际展开和外部配方覆盖依赖运行时资源管理器。

SpringRecipes.Crown 包装 shaped 配方并写入 FlowerData，matches 同时检查花可合成与启用配置。Change 处理选花/加花/水桶洗去配花；已有主花、三花上限和桶返还由服务端配方决定。[FloralRecipeDisplays](../../../../src/main/java/com/thelongtravail/compat/jei/FloralRecipeDisplays.java) 根据启用 mask 构造展示快照。FloralJeiPlugin 隐藏真实 Crown 列表，按配置同步 revision、标签和配方更新切换合并展示；展示配方使用内置材料布局，不是逐一复制数据包中的最终真实配方。因此外部修改春日一隅材料后必须检查展示是否仍一致，不能把 JEI 缩略配方当作服务端权威。

EssenceJeiPlugin 只注册紫水晶母岩精粹、虞美人小王子、玫瑰丛小王子三个方块掉落说明。小王子的百分比读取 TooltipConfigSync 的 boundlessItem.* 同步值并回退本地配置；文本来自 [简体中文兼容语言组](../../../../src/main/lang/zh_cn/compatibility.json)。这里没有保底计数展示，也不是完整战利品/交易目录。

AbyssJeiPlugin 使用钻石和钻石剑演示可堆叠/不可堆叠复制，完美流体登记为 catalyst。是否允许真实目标、预览、领取及余留槽由 PerfectFluidRecipe 和复制基础处理，见 [复制预览与领取](复制预览与领取.md)。不能根据 JEI 示例推导任意第三方容器必然可复制。

## 维护顺序与保留范围

修改获取时先查本表，沿“注册 ID → 真实发放/配方 → 配置与资源 → JEI/语言说明”逐层核对。新增交易检查新村民注册和旧村民 ensure；改成本检查 fixed 与旧价迁移；改小王子概率检查同步文本但不要误改保底生命周期。语言仍在分组源维护，规则见 [语言源说明](../../../../src/main/lang/README.md)。

明确未覆盖：外部数据包/KubeJS/用户 general.toml 的最终结果；所有材料精粹 JSON 的逐概率审计；标签完整成员、全部语言正文、纹理像素/模型继承、JEI 实际显示、第三方村民价格与补货；完整默认池初始化归 A08，资源指纹/锚点自动校验归 A10。没有以入口存在性宣称这些范围通过。

回归用例：新旧大师村民、重复与自定义同输出交易、已用尽交易迁移、巴别塔价格叠加；父子钓鱼表、第三方多池考古表、资源重载；小王子随机先出/混合计数/死亡重登/概率为零/保底掉落被取消；禁用花、改配方材料及 JEI 刷新。
