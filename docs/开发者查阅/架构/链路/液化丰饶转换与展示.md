# 液化丰饶转换与展示

## 公共端链路

LiquefiedAbundanceItem 的 use → LiquefiedAbundance.begin 建立会话并进入原版使用流程；releaseUsing 在5 tick内松开时切换类型，超过窗口且未蓄满时取消；finishUsingItem 结算。默认蓄力1秒，实际值来自 AbyssItemsConfig。会话固定物品引用、手、类型和总刻数，服务端移除会话后才抽取并交付，避免重复结算。

AbundanceEffectPool 在启动或配置重载时构建效果→去重等级→去重时长表，转换时逐层随机。配置黑名单只排除效果，回退持续时间默认15秒；瞬时效果不使用回退时间。产物采用原版药水与自定义效果，带独立来源标记。AbundanceLingeringPotionMixin 只对带标记的滞留产物调整持续时间。

玩家类型保存于 Forge 玩家持久数据，Clone复制，登录、重生、跨维度和切换时由 AbundanceModePacket 同步；AbundanceCancelPacket 仅取消发送者会话。协议23限制客户端与服务端版本匹配。

## 客户端链路

TravailClientEvents 统一初始化 AbundanceUseClient 的回调。客户端负责按压锁、打断请求和提示所有权，不能指定奖励。Action Bar 使用原版文本和 ThinProgressBar；共享横条同时用于 DiaryProgressTooltip。进度按实际使用刻数计算，其他提示覆盖时让位。

ThemeTooltips 复用既有 flavor 翻译键入口显示风味文本，AbundanceText 提供摘要及拾遗内容。当前类型只在物品描述显示；拾遗动态参数和黑名单来自 TooltipConfigSync。CatalogTextStyle 的新增匹配限定于液化丰饶，三种类型并列句的局部补色不改变通用染色协议。

## 注册与资源

ModRegistry 注册物品及创造物品栏；无序合成使用JSON配方，ModBrewing 通过标准 Forge 酿造注册接入。配置重载通过 ConfigReloadCoordinator 取消会话、重建抽样表并同步。主源码、资源与构建输入由项目书生成器记录指纹。
