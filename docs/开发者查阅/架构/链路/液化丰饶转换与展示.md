# 液化丰饶转换与展示

液化丰饶是归墟主题的消耗品。短按切换普通、喷溅、滞留三种类型，长按完成后由服务端抽取药水效果并交付产物。

## 职责与入口

| 实现 | 职责 |
|---|---|
| [LiquefiedAbundanceItem](../../../../src/main/java/com/thelongtravail/item/LiquefiedAbundanceItem.java) | use、releaseUsing、finishUsingItem 物品回调 |
| [LiquefiedAbundance](../../../../src/main/java/com/thelongtravail/abyss/LiquefiedAbundance.java) | 使用会话、类型持久化、抽样交付与清理 |
| [AbundanceEffectPool](../../../../src/main/java/com/thelongtravail/abyss/AbundanceEffectPool.java) | 效果、等级和时长的去重抽样表 |
| [LiquefiedAbundanceRecipe](../../../../src/main/java/com/thelongtravail/abyss/LiquefiedAbundanceRecipe.java) | 无序合成与容器返还 |
| [ModBrewing](../../../../src/main/java/com/thelongtravail/registry/ModBrewing.java) | Forge 酿造注册 |
| [AbundanceUseClient](../../../../src/main/java/com/thelongtravail/client/AbundanceUseClient.java) | 按压锁、取消请求、类型显示与蓄力提示 |

## 获取与容器返还

[合成配方](../../../../src/main/resources/data/the_long_travail/recipes/liquefied_abundance.json) 使用蜂蜜瓶、青金石、牛奶桶和 3 个玻璃瓶，产出 4 个液化丰饶。自定义序列化器委托原版无序配方处理材料和网络编码；getRemainingItems 清除蜂蜜瓶的玻璃瓶返还，牛奶桶仍按原版规则返还空桶。

ModBrewing 在 common setup 的工作队列中注册酿造：以龙息为输入、青金石块为材料，输出液化丰饶。

## 使用与结算

1. use 调用 begin，服务端以玩家对象为键保存物品引用、使用手、类型和总刻数，再进入原版使用流程。默认蓄力 1 秒，读取 AbyssItemsConfig，最少 10 tick。
2. 未蓄满松开时，已用时长不超过 5 tick 则循环切换类型并同步；超过窗口则结束会话，不产出药水。
3. 完成使用时，complete 先移除会话，再检查物品引用、存活状态、手中物品和数量。重复完成回调找不到会话，直接返回原物品。
4. 从效果池抽样；空池只显示提示并保留输入。普通模式通过 ItemUtils.createFilledResult 消耗输入并交付药水；创造模式保留输入，通过 ItemDelivery 交付。

## 效果池与产物

启动和配置重载时，AbundanceEffectPool 从效果注册表和 Potion 注册表建立“效果 → 等级 → 时长”结构。效果按 ID 排序，每个等级的时长去重；抽取在三个层级分别等概率选择。

白名单为空时不限制效果种类；非空时只允许列出的有效效果，黑名单再排除整个效果。白名单中的未知或格式错误 ID 会告警，重复项不增加权重；非空名单全部无效时保留空池，不退回全部效果。两张名单只改变可抽取效果的集合，不改变等级和时长的分层抽样规则。没有药水样本的效果回退到等级 I，非瞬时效果使用配置时长（默认 15 秒），瞬时效果使用 1 tick。已有样本保留各等级和有效时长，包括无限时长。

产物使用原版药水物品、空基础药水与单个自定义效果，并写入 `the_long_travail:liquefied_abundance=1`。AbundanceLingeringPotionMixin 对带标记滞留产物的非瞬时效果，将有限时长除以 4、最低保留 1 tick；无限时长保持 -1。

## 状态与生命周期

| 状态 | 存放位置 | 更新与清理 |
|---|---|---|
| 选定类型 | 玩家 persistentData 的 `the_long_travail:abundance_mode` | 取值 0–2；Clone 复制；登录、重生、跨维度和短按切换时同步 |
| 转换会话 | 服务端 IdentityHashMap | 完成、取消、停止使用、死亡、换物、登出和跨维度时清理；配置重载停止使用并清空会话，停服清空 |
| 抽样表 | AbundanceEffectPool 不可变列表 | 启动及配置重载重建，停服清空 |
| 输入与提示 | AbundanceUseClient 静态状态 | 攻击、开界面、滚轮、换槽、丢弃、换手、失焦或配置 revision 改变触发取消；松键解除按压锁，退出重置类型和提示 |

协议版本为 23。ID 19 的 AbundanceCancelPacket 只取消发送者的当前会话；ID 20 的 AbundanceModePacket 将服务端类型同步到客户端。载荷与接收检查见 [网络协议表](网络协议与状态生命周期.md)。

## 展示与维护

TravailClientEvents 初始化客户端回调。蓄力使用原版 Action Bar 文本和 ThinProgressBar，按实际使用刻数绘制；其他提示取得 Action Bar 后，本次蓄力提示让位。DiaryProgressTooltip 共用横条绘制。

ThemeTooltips 读取风味翻译键，AbundanceText 提供摘要及拾遗内容，TooltipConfigSync 提供动态数值和黑名单。当前类型显示在物品描述中；CatalogTextStyle 对三种类型并列句进行局部补色。

修改合成材料时同时检查容器返还；修改转换行为时检查短按窗口、完成回调与取消会话；修改效果池时检查空池、黑名单、重复样本、瞬时效果和无限时长。
