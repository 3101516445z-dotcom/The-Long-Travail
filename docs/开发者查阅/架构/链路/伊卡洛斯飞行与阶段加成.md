# 伊卡洛斯飞行与阶段加成

范围为玩家滑翔、开关、环境增伤、免疫、点燃以及显示/兼容入口。

## 职责和依赖

| 层次 | 入口 | 维护职责 |
|---|---|---|
| 公共基础 | [TravailStateApi](../../../../src/main/java/com/thelongtravail/api/TravailStateApi.java)、[CombatContext](../../../../src/main/java/com/thelongtravail/helper/CombatContext.java) | 阶段查询、单次伤害上下文与效果结算 |
| 物品入口 | [FarReachAccessoryItem](../../../../src/main/java/com/thelongtravail/item/FarReachAccessoryItem.java) 的 false 分支 | 非装饰 back 槽、唯一装备、潜行使用开关和提示 |
| 滑翔判定 | [IcarusFlight](../../../../src/main/java/com/thelongtravail/farreach/IcarusFlight.java) | 物品开关、有效滑翔装备、Caelus 拒绝检查、可见堆叠 |
| 战斗装备判定 | [FarReachEquipment](../../../../src/main/java/com/thelongtravail/farreach/FarReachEquipment.java) 的 false 分支 | 存活、非旁观玩家的非装饰 back 槽；不读取飞行开关 |
| 环境计算 | [IcarusEnvironment](../../../../src/main/java/com/thelongtravail/farreach/IcarusEnvironment.java) | 世界时间曲线、晴天和露天查询，不保存玩家状态 |
| 战斗玩法 | [FarReachCombat](../../../../src/main/java/com/thelongtravail/farreach/FarReachCombat.java) | 汇合装备、阶段、环境和配置，返回增伤/免疫，执行点燃 |
| 参数 | [FarReachItemsConfig](../../../../src/main/java/com/thelongtravail/config/FarReachItemsConfig.java) | aspects/far_reach.toml 中 items.icarus 下的增伤、点燃和扩展免疫 |

因此修改滑翔开关应查 IcarusFlight；修改伤害不能只改该类，须追 FarReachCombat 和 CombatContext。伊卡洛斯当前链路没有 IcarusGrowth；不能从历史名称推导出仍存在的成长能力。

## 开关、滑翔与退出

`IcarusFlightDisabled` 保存在物品堆叠 NBT。没有该标记或值为 false 时默认启用；禁用写 true，重新启用移除该键。潜行使用在服务端切换并发送启用/禁用提示，客户端返回交互成功；潜行时不通过 canEquipFromUse 自动装备。

滑翔装备查询要求实体是存活、非旁观玩家，并在非装饰 back 槽找到启用的伊卡洛斯。它不要求日记、阶段或 Curios 显示开关。以下三个桥接只包裹原有方法内部的指定调用，不替代整个原版方法的前置条件。

| 桥接 | 调用与分支 |
|---|---|
| [IcarusLocalFlightMixin](../../../../src/main/java/com/thelongtravail/mixin/IcarusLocalFlightMixin.java) | LocalPlayer.aiStep 的 canElytraFly：有效装备时取 allowed，否则调用原方法 |
| [IcarusPlayerFlightMixin](../../../../src/main/java/com/thelongtravail/mixin/IcarusPlayerFlightMixin.java) | Player.tryToStartFallFlying 的 canElytraFly：同上 |
| [IcarusLivingFlightMixin](../../../../src/main/java/com/thelongtravail/mixin/IcarusLivingFlightMixin.java) | LivingEntity.updateFallFlying 的 canElytraFly：同上；elytraFlightTick 在有效装备时返回 true，并在服务端 `(ticks+1)%10==0` 发 ELYTRA_GLIDE 事件 |

有效装备分支跳过原堆叠的 elytraFlightTick；未装备或禁用则恢复原调用。这里没有写入 abilities.mayfly/flying，也没有自行维护飞行速度或退出恢复队列。卸下/禁用后是否仍滑翔取决于原路径及其他滑翔来源，不能描述成“必定立即落地”。tick 桥接自身不再调用 allowed，不能把它描述成每个桥接都独立复核 Caelus。

## Caelus 扩展边界

[IcarusCaelusCompat](../../../../src/main/java/com/thelongtravail/compat/caelus/IcarusCaelusCompat.java) 只将 Caelus 的 DENY 视为拒绝。Gate 未启用时不拒绝；捕获 LinkageError 后关闭 Gate 并返回不拒绝，不吞掉所有异常。

[IcarusCaelusApiMixin](../../../../src/main/java/com/thelongtravail/compat/mixin/caelus/IcarusCaelusApiMixin.java) 在 API 返回处，仅对 Gate 启用、原结果 DEFAULT 且有效装备的玩家改成 ALLOW；保持显式 DENY/ALLOW。反向调用只检查 equipped，不递归调用 allowed。

[OptionalCompatPlugin](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatPlugin.java) 检查模组存在及 Caelus 契约。主桥接登记见 [主 Mixin 配置](../../../../src/main/resources/mixins.the_long_travail.json)，可选桥接见 [兼容 Mixin 配置](../../../../src/main/resources/mixins.the_long_travail.compat.json)。

## 战斗阶段与环境

战斗装备判定不读取 `IcarusFlightDisabled`：禁用飞行不等于关闭增伤、免疫和点燃。基础装备效果不额外要求日记；阶段效果通过 TravailStateApi 判断。

| 分支 | 当前计算 |
|---|---|
| 见证增伤 | 优先于恶意；露天返回 witnessBonus，否则 0；无时间或晴天要求 |
| 恶意增伤 | sunlight × 峰值；同时晴天且露天用 sunnyPeak，其余用 malicePeak |
| 无阶段 | 增伤 0 |
| 基础免疫 | IS_FALL 伤害标签或 FLY_INTO_WALL |
| 见证附加免疫 | MAGIC、INDIRECT_MAGIC，以及 extraImmunities 中匹配的伤害 ID 或 #标签 |

`sunlight` 以 floorMod(dayTime,24000) 计算：前 12000 刻为非负正弦曲线，后半周期为 0，正午 6000 达峰。下界永不判晴天；末地总判晴天；其他维度要求 levelData 无雨且无雷。所有维度仍按世界时间计算恶意加成。

通常维度在眼睛方块位置使用 canSeeSky。下界/末地改为从 max(眼睛高度,最低建造高度) 扫至最高建造高度前一格；任何格 lightBlock>0 或不向下传播天光即阻挡。这是透光路径判定，不是“只要非空气就遮挡”。

CombatContext 在非终结、非玫瑰伤害、存在服务端攻击者且非自伤时采样伊卡洛斯增伤，汇入 outgoingBonus；不是独立再次乘算。quixoteStrike、insightRetaliation、lorentzVoid 的 outgoingBonus 返回 0。免疫在上下文中一次求值并加入 blocked；终结和玫瑰路径在该免疫求值前提前返回，所以不能把 FarReachCombat.immune 描述为覆盖所有伤害入口。

[CombatConsequences](../../../../src/main/java/com/thelongtravail/helper/CombatConsequences.java) 的 confirmed 分发点燃。FarReachCombat 要求目标符合 ICARUS_FIRE 模式规则、服务端、非火免且 igniteSeconds 非 0；伤害源实体须为有效装备的 ServerPlayer，且不是目标。随后调用 setSecondsOnFire，不要求恶意/见证，也不读取飞行开关。实际确认与重放边界沿用 [伤害确认与重放](伤害确认与重放.md)。

## 显示与其他实体

visibleStack 在有效滑翔装备基础上增加玩家不隐身、槽位 visible 的条件。隐藏槽位只影响显示，不关闭滑翔或战斗能力。

[IcarusElytraLayerMixin](../../../../src/main/java/com/thelongtravail/mixin/IcarusElytraLayerMixin.java) 找到可见堆叠后使用 [IcarusWingModel](../../../../src/main/java/com/thelongtravail/client/IcarusWingModel.java)，渲染成功路径取消原 ElytraLayer；[IcarusCapeMixin](../../../../src/main/java/com/thelongtravail/mixin/IcarusCapeMixin.java) 在同一可见条件下取消披风。visibleStack 不检查 Caelus allowed，因此拒绝滑翔本身不会隐藏翅膀。

模型由图层延迟创建，以纹理 alpha 读取轮廓；已核对装配和读取入口；模型几何、资源重载与视觉效果待验收。语言维护入口见 [语言源说明](../../../../src/main/lang/README.md)。

[MaidCombatCalculations](../../../../src/main/java/com/thelongtravail/compat/maid/MaidCombatCalculations.java) 承接女仆伊卡洛斯增伤和免疫分支，[MaidCombatFeedback](../../../../src/main/java/com/thelongtravail/compat/maid/MaidCombatFeedback.java) 承接点燃反馈，继续复用环境查询。玩家滑翔 equipped 限定 Player，不能据女仆战斗兼容推导女仆也有滑翔。

## 验证与维护边界

运行/视觉验收 NOT_RUN：开关持久化、卸下后其他滑翔来源接管、Caelus DENY、雨天/夜晚/特殊维度、阶段免疫、点燃与模式规则、槽位隐藏/隐身/披风组合均需对应环境验证。
