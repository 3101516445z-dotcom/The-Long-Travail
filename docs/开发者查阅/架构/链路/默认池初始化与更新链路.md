## 装配与时序

[ConfigFiles](../../../../src/main/java/com/thelongtravail/config/ConfigFiles.java) 在 Loading 收集配置引用。完美流体在 FMLCommonSetup 的 enqueueWork 初始化；群系、结构、奖励物品、钓鱼实体、药效、黄金时代在 ServerStarting 处理。ServerStarted 的 TravailEvents 随后调用 RuntimePools.reload。注册顺序不应被写成所有任意模组监听器的全局执行保证。

普通文件监视热重载由 [ManagedConfig](../../../../src/main/java/com/thelongtravail/config/ManagedConfig.java) 解析、校验并发布配置，发送 Reloading。ConfigReloadCoordinator 将 RuntimePools.reload、GoldenAgeActions.reload、Affection.resetAll、容器刷新、降雨配置更新和提示快照发送安排到服务端线程。七类预设没有通过这次事件重新执行 starting/initialize；把标记设为 false 后应在对应启动阶段重试，不能承诺热重载立即补项。

[WeightedPresetEntries](../../../../src/main/java/com/thelongtravail/config/WeightedPresetEntries.java) 和 [ExplorationPresetEntries](../../../../src/main/java/com/thelongtravail/config/ExplorationPresetEntries.java) 在模组/命名空间存在、预设非空、标记未完成时运行。即使候选全部不存在或都已配置，也会置处理标记；标记表示“已尝试合并”，不是“所有预设成功添加”。黄金时代也有这一性质。完美流体要求该规则全部物品存在，缺项时不置标记，是明确例外。

这些合并保留已有列表顺序及自定义值，追加缺项，不清理已有重复项，也不恢复标记为 true 后手动删除的条目。预设列表中的每个兼容 ID 来自各 compat 子包 Defaults 数据提供者；本轮追到消费、筛选和保存机制，未将所有第三方注册 ID 运行可用性标为通过。

## update 与直接 save 的不同失败边界

六个 update 调用方就是上表除完美流体以外六类。update 要求 active 已加载且 writable，先比较磁盘字节，再从记录的 disk 解析候选；edit 返回 false 不写盘。修改后再次比较磁盘、写文件、读取新 disk、发布 active、acceptConfig 与 afterReload。该方法不执行 ConfigValidation.validate，也不显式发 Reloading，不能称为完整热重载事务。磁盘并发变更/IO 异常报告失败；运行时异常不在其 IOException 捕获范围。

完美流体 initialize 先 apply 到 loaded.getConfigData，再调用 save 与 afterReload。save 无返回成功状态；若配置不可写或检查到外部修改，磁盘可保留原内容，但已编辑的活动列表/标记不因此自动回滚。此处仅记录现状，未擅自改变实现；不能用 update 的候选隔离保证描述它。

## 持久配置与派生池

[RuntimePools](../../../../src/main/java/com/thelongtravail/data/RuntimePools.java) 发布不可变 Snapshot，包含穷遐/幽谷药效、钓鱼/幻翼物品、钓鱼实体、等级上限及黑名单。reload 还诊断药效预算、失效高度与需求缓存、清旅程查询/路引搜索。RequirementPools 是探索条件候选，不等于已有日记会重新抽取条件。

黄金时代派生池见 [黄金时代转换池与执行路径](黄金时代转换池与执行路径.md)。共享战利品 default_loot.json → UnifiedLootConfig → UnifiedLoot 是独立资源重载链，见 [获取、配方与展示一致性](获取配方与展示一致性.md)。七类兼容初始化不能代替这些消费者自己的重载。

修改预设时一起检查 provider 列表、define 标记、Loading 捕获、启动触发、合并 helper、配置保存、运行消费者和提示同步。不要仅改默认列表并假定已标记的旧用户配置自动升级。

## 原版结构默认值与检测回归

TravailConfig 为六主题定义各两个原版结构，并将 requirements.structureDrawCount 默认值设为 2。该层提供新配置或缺失键的默认值；StructureCompatDefaults 仍只按独立标记追加联动候选，不覆盖已有空池或抽取数。具体组合见 [配置说明](../../../玩家查阅/configuration-controls.md)。

第十七轮 structures 套件在种子 12345 的自然世界中检查全部 12 种结构：选取首、中、末结构片段的多个高度位置，调用 JourneySpatial.loadedAt 验证首次查询、缓存查询及范围外排除；正常保存退出后由第二个 JVM 重读原坐标复查。生成阶段 2019 项、重启阶段 2008 项检查通过，未发现漏检。各主题另用 100 个随机种子验证默认两项必选与追加候选后的不重复抽取；追加项使用原版结构模拟扩池，不代表全部第三方联动组合验收。
