# 洛伦兹属性与虚空战斗链路

A07-08 静态核对日期：2026-10-24。范围为玩家装备/开关、箭矢初始化与寿命、命中作用域、爆头、见证虚空伤害及公共战斗衔接；运行验收 NOT_RUN。女仆完整生命周期、获取配方及第三方弹射物完整兼容不随本章关闭。

## 装备与属性对账

玩家 equipped 要求存活、未移除、非旁观、实际日记，以及非装饰 bracelet 槽的洛伦兹物品；非 ServerPlayer 路径委托 MaidAccessories。phase 再通过无垠状态返回恶意/见证/无阶段。

refresh 按固定 UUID 为恶意添加 CRITICAL_CHANCE 的 ADDITION 临时修饰符，其余阶段金额为 0 并撤去旧修饰符。同金额时直接返回。玩家服务端 END tick、AttributeDamage.begin 的攻击者刷新及女仆适配入口会调用它；物品类没有独立 onEquip/onUnequip 刷新实现。日记依赖失效则通过 [DependentAccessories](../../../../src/main/java/com/thelongtravail/helper/DependentAccessories.java) 的清理回调 refresh，返还流程沿用 [装备恢复与依赖返还](装备恢复与依赖返还.md)。

物品 NBT `LorentzGravityDisabled` 只控制新箭初始化时是否调用 setNoGravity(true)，不关闭穿透、暴击、恶意增伤或见证效果；禁用也不会主动把箭改为有重力。

## 射出时标记与箭矢生命周期

服务端 EntityJoinLevel：新加入的 AbstractArrow 执行 initialize，排除 ThrownTrident、已标记箭、无 LivingEntity 所有者和未有效装备。初始化不要求 phase 非零，因此装备成立但无阶段也能获得基础箭矢处理。

| 字段或状态 | 写入规则 |
|---|---|
| TravailLorentz | 标记已初始化，避免重复追加 |
| TravailLorentzPhase | 保存初始化时阶段 |
| noGravity | 重力开关未禁用时设 true |
| pierceLevel | 原非负穿透等级加配置值，上限 127 |
| LongTravailFlyingProjectile | 射手为 ServerPlayer 且 abilities.flying 或 isFallFlying 时置 true |
| TravailLorentzAge | 后续有效寿命累计 |
| TravailLorentzHits | 命中时记录目标 UUID 字符串 |

从磁盘加载时不重新初始化；已有标记则重新加入 ARROWS 弱集合。已经射出的箭不随玩家卸下或开关变化自动还原重力/穿透。

服务器 END tick 对集合中未移除、无重力、未入地、未冻结的箭将 AGE 加一，到 arrowLifetime 对应刻数则 discard。这里按这些条件计数，没有额外速度阈值；入地、重力状态或冻结会暂停。停服清集合和命中作用域，不代表删除世界中所有箭矢。

## 命中作用域与敌我复核

LorentzArrowMixin 在 onHitEntity 内包装实际 hurt。普通 LivingEntity 或 PartEntity 的 LivingEntity 父实体可作为逻辑目标；其他目标、未标记箭、无有效所有者或非敌对目标直接调用原 hurt。

敌我判断排除自己、死亡/移除目标、双方任一方向盟友；玩家目标还检查旁观、MaidAccessories.canHarm 和可解析所有者的 FTB Teams 关系；驯服动物排除射手/女仆主人自己的宠物。这不是对所有生物统一使用“敌对怪物”分类。

同一箭的 HITS 按父实体 UUID 去重。首次命中在原 hurt 前写入 UUID，设置 ThreadLocal Impact，保存父实体命中前生命；finally 恢复原作用域，支持嵌套。已记录目标再次命中仍执行原 hurt，但不重新建立本次特殊判定。原 hurt 抛异常时恢复作用域，已写 HITS 不撤销，之后的虚空处理不执行。

## 恶意增伤与爆头

基础增伤要求非虚空伤害、IS_PROJECTILE 标签、来源 LivingEntity、当前敌对且射手当前为恶意；不限于已标记箭，因此不能把全部恶意投射物增伤等同于箭矢初始化效果。

额外爆头加成还要求 Impact 的目标与直接伤害实体匹配、headshot=true、箭矢保存阶段为恶意。两个加成相加后进入公共 outgoingBonus，不独立重复乘算。

headshot 使用箭当前位置到下一速度端点的线段，与目标扩大 0.3 的包围盒求交，未求交时用箭当前位置。命中 Y 须在眼睛下方 headTolerance×高度以上，且不超过底部+高度+0.3。几何修正名单内使用当前高度与注册高度的较小值，按原眼高比例修正眼睛位置；它修改判定变量，不修改实体实际碰撞箱。多部位逻辑使用父实体进行这一判定。

## 见证虚空伤害的顺序

首次特殊命中要求箭保存阶段为见证且当前射手也为见证；另记录无垠恶意飞行攻击阻止条件。原 hurt 正常返回后，再检查该条件未阻止、射手仍见证、目标仍敌对、命中前生命为正有限值。

**原 hurt 的布尔结果不是虚空触发条件。** 因此原攻击返回 false 时仍可能进入后续判定；原攻击击杀目标则敌我检查不再通过。结果仍返回原 hurt 的布尔值。

冷却按目标实体弱键和 casterId UUID 存储，使用主世界 gameTime；到期先写新截止时间，再调用 hurtVoid，金额为命中前生命×voidRatio。不是按最大生命，也不是按普通攻击实际损失计算。每 200 个服务器 tick 清理已到期条目；停服清表。没有随卸装备清空全部冷却的专门入口。

hurtVoid 再核金额正有限、敌对、射手/父目标/命中部位同世界、部位未移除且仍属于该父实体。生命取样、冷却和 invulnerableTime/lastHurt 恢复使用父实体，实际 hurt 仍传给原命中部位，保留该部位自身的受击规则。finally 恢复父实体受伤状态；金额封顶 Float.MAX_VALUE。若最后复核失败或 hurt 返回 false，已占用的命中记录/冷却不会自动返还。

公开 hurtVoid 重载只执行伤害层检查，不自行检查阶段或写冷却；不能将 impact 的前置条件当成这个方法本身的保证。

## 公共战斗与资源边界

虚空使用 [lorentz_void 伤害类型](../../../../src/main/resources/data/the_long_travail/damage_type/lorentz_void.json)，在 [伤害标签目录](../../../../src/main/resources/data/minecraft/tags/damage_type) 登记绕过护甲、冷却、效果、附魔、抗性和盾牌。

CombatContext 对 lorentzVoid 将 outgoingBonus 设为 0，跳过常规 confirmed 副作用；finish 仍调用 attributeDamage.finish 后返回。AttributeDamage 明确不为洛伦兹虚空取攻击者暴击概率，但不能据此宣称跳过全部战斗属性：防御属性仍取决于公共排除标签与结算逻辑。虚空分支仍通过 hurt、公共 blocked 和第三方事件，不能解释为无条件扣血或绕过所有免疫。

参数与语言说明继续维护于配置源和 [语言源说明](../../../../src/main/lang/README.md)。射出时保存的阶段/标记与命中时读取的数值、当前装备并存；重载配置不会重写已有箭的穿透等级或保存阶段。
