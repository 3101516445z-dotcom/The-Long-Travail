# 黄金时代转换池与执行路径

本章核对 A07-03：黄金时代的手动丢弃登记、浸水计时、候选池、转换提交、挖掘与兼容默认值。静态核对日期为 2026-10-24；运行验收 NOT_RUN。

## 分层与维护入口

| 层次 | 源码 | 职责及依赖 |
|---|---|---|
| 公共基础 | [TravailStateApi](../../../../src/main/java/com/thelongtravail/api/TravailStateApi.java)、[TimeStopManager](../../../../src/main/java/com/thelongtravail/boundless/TimeStopManager.java) | 提供主题阶段、冻结查询；转换器消费查询结果 |
| 玩法条件 | [FarReachEquipment](../../../../src/main/java/com/thelongtravail/farreach/FarReachEquipment.java)、[FarReachAccessoryItem](../../../../src/main/java/com/thelongtravail/item/FarReachAccessoryItem.java) | 黄金时代使用 true 分支；有效装备要求存活、非旁观、非装饰 charm 槽；Item 还负责唯一装备与展示 |
| 玩法协调 | [GoldenAgeActions](../../../../src/main/java/com/thelongtravail/farreach/GoldenAgeActions.java) | 登记所有者、计时、阶段选择、每刻额度、生成后扣除输入、挖掘冷却 |
| 派生数据 | [GoldenAgePools](../../../../src/main/java/com/thelongtravail/farreach/GoldenAgePools.java) | 注册表减黑名单、按玩家查询默认堆叠食物属性；不扣金块、不生成实体 |
| 配置扩展 | [FarReachItemsConfig](../../../../src/main/java/com/thelongtravail/config/FarReachItemsConfig.java)、[GoldenAgeCompatDefaults](../../../../src/main/java/com/thelongtravail/config/GoldenAgeCompatDefaults.java) | 定义参数、黑名单和一次性兼容初始化；发布流程复用 ManagedConfig |

这些是现有逻辑职责，并非独立编译模块。修改筛选应先查 Pools，修改额度和提交顺序查 Actions，修改触发范围查下表的 Mixin。

## 输入登记与实体入口

| 桥接 | 进入玩法的条件 |
|---|---|
| [GoldenAgePlayerDropMixin](../../../../src/main/java/com/thelongtravail/mixin/GoldenAgePlayerDropMixin.java) | 包裹 ServerPlayer.drop(boolean)，建立 manual 作用域 |
| [GoldenAgeMenuDropMixin](../../../../src/main/java/com/thelongtravail/mixin/GoldenAgeMenuDropMixin.java) | 菜单 THROW，或槽位 -999 的 PICKUP，建立 manual 作用域 |
| [GoldenAgeItemMixin](../../../../src/main/java/com/thelongtravail/mixin/GoldenAgeItemMixin.java) | ItemEntity.tick 尾部驱动转换；pending 实体禁止合并 |
| [GoldenAgeInteractionMixin](../../../../src/main/java/com/thelongtravail/mixin/GoldenAgeInteractionMixin.java) | 原 ForgeHooks.onRightClickBlock 完成后调用 dig，保留先前取消/拒绝结果 |

manual 使用 ThreadLocal UUID，退出作用域恢复之前的值，支持嵌套。ItemTossEvent 在 LOWEST 优先级检查服务端玩家、作用域 UUID、有效黄金时代装备和未冻结，再登记 **Items.GOLD_BLOCK（金块）**。这只能证明上述手动路径，不能推导所有外部模组掉落都被登记。

登记写入实体 persistentData：`LongTravailGoldThrower` 为所有者 UUID，`LongTravailGoldWetTicks` 为 0。pending 只要求物品仍为金块且有 UUID，因此离水、所有者离开时也禁止合并。不得把源码个别注释中的“金锭”当作输入类型。

## 浸水、资格与批次

服务端存活、pending 且未冻结的实体进入 tick。PROCESSING 按所有者 UUID 防止同一调用链重入，finally 移除；它不代替每刻额度。

1. 离水将计时归零；在水中以 long 中间值累加，再限制到配置要求区间，避免损坏持久化值溢出。
2. 达到 waterTime 后，从实体所在世界按 UUID 找玩家。玩家须有效装备、未冻结且在 range 内；离线、不同世界或离开范围时保留金块和已累积计时。
3. 优先判断穷遐见证；不是见证时才要求恶意阶段。没有阶段则等待。
4. BATCHES 以 ServerPlayer 对象为键，以当前世界 gameTime 判断是否新一刻。多个金块实体共享该玩家的 used 和池快照。
5. 扣除已用次数后无额度或本刻 poolFailed 时返回。按阶段延迟查询池，空池同样返回。满足条件后开始本实体循环。

阶段和池在本次调用中确定，不是每件产物都重新校验全部资格。循环上限取剩余额度与堆叠数的较小值，并在循环条件再次读取 batchSize。

## 候选池和抽取契约

| 阶段 | nextBoolean 为 true | 否则 |
|---|---|---|
| 恶意 | 从附魔池均匀抽取，生成等级 1 附魔书 | 青金石块 |
| 见证 | 从食物池均匀抽取并复制堆叠 | 蜂蜜块 |

两条分支各 50%。**对应候选池为空时，两条分支都不执行**，没有仅保留固定方块产出的回退。

附魔池遍历注册表并排除精确 ID 黑名单；没有额外的诅咒、宝藏或可交易性过滤。食物池先取得注册表减黑名单的 Item 候选，再取每个物品默认堆叠，以 `stack.getFoodProperties(player)` 查询。它不枚举所有创造模式或 NBT 变体。

食物必须非空、营养值不低于 minNutrition，且 `2 × nutrition × saturationModifier` 不低于 minSaturation。allowHarmfulFood 为 false 时排除声明效果中任意 HARMFUL 类效果，不按效果概率加权，也不扫描食用回调自行施加的效果。通过后堆叠数量设为 1。

非食物快速跳过仅在反射确认 Item/ItemStack 沿用 Forge 默认查询、物品精确类型为 Item 或 BlockItem、基础食物属性为空时启用。自定义子类仍走默认堆叠及玩家查询。

## 缓存与失效

| 数据 | 生命周期 |
|---|---|
| 注册表候选及黑名单快照 | GoldenAgePools 静态缓存；黑名单列表不相等时重建；保留注册表遍历次序 |
| 最终食物堆叠列表 | Actions 的玩家/刻 Batch；依赖玩家属性，不作为全局最终结果缓存 |
| 附魔列表引用、used、poolFailed | 同一玩家本刻复用；进入不同 gameTime 才替换 Batch |
| DIG_COOLDOWNS、BATCHES | WeakHashMap，以玩家对象为弱键；没有据此推导出明确的登出即清空契约 |

TagsUpdatedEvent 和 ServerStoppedEvent 清除 Pools 候选。配置重载由 [TravailNetwork](../../../../src/main/java/com/thelongtravail/network/TravailNetwork.java) 调用 Actions.reload：清候选并将已有 Batch 的 foods/enchantments 置空，**不重置 tick、used 或 poolFailed**。标签事件本身没有逐个清除 Actions 已持有的本刻池引用。

## 生成、扣除和失败顺序

每次抽取后，在原实体位置创建产物，继承速度，设置默认拾取延迟；先 `batch.used++`，然后 `addFreshEntity`。返回 true 后才复制输入堆叠、减去一个金块并写回，空堆叠则 discard。

| 分支 | 输入和后续行为 |
|---|---|
| 构建池抛 RuntimeException | 本刻 poolFailed=true；保留输入，不执行抽取；警告全局最多每 60 秒一次；后续刻可重试 |
| 候选池为空 | 保留输入，无随机抽取或额度消耗 |
| addFreshEntity 返回 false | 本次金块保留，随机与一次额度已消耗，结束本实体本次循环；后续刻可重试 |
| 生成成功 | 消耗一个金块，继续至堆叠或额度耗尽 |
| 产物构造、生成或后续处理抛异常 | 外层 finally 释放重入保护；没有覆盖这些步骤的事务回滚，不承诺异常下恰好一次 |

这里记录当前提交次序，没有调整概率、额度或失败策略。

## 挖掘与默认值初始化

挖掘是独立支路：主手空手、有效装备、未冻结，事件未取消且 useBlock/useItem 非 DENY，玩家有建造和当前位置交互权限，目标为沙子、红沙或砂砾。先取消事件并设置 sidedSuccess，再在服务端检查 digCooldown；因此冷却中也已接管该交互。成功时等概率给金粒或燧石，调用 TravailCurios.returnToInventoryOrDrop，不消耗目标方块；此方法没有额外的穷遐阶段判定。

兼容初始化由 [ConfigFiles](../../../../src/main/java/com/thelongtravail/config/ConfigFiles.java) 装配：加载匹配 aspects/far_reach.toml 的 ManagedConfig 后，在 ServerStarting 更新。Enigmatic Legacy、Enigmatic Delicacy 提供食物黑名单预设，L2 Complements、Celestial Enchantments 提供附魔黑名单预设。

只有模组存在、预设非空、对应 `items.golden_age.compatInitialization.<mod>.<marker>` 未置 true 时处理。保持原列表次序、去重追加注册表中存在的预设 ID，然后置初始化标记；即使没有追加 ID，也置标记。用户之后删除某个条目，不会在标记仍为 true 时自动补回。本章只覆盖黄金时代这一入口，不关闭 A08 全部默认池初始化工作。

配置加载细节见 [配置加载与重载](配置加载与重载.md)。名称和提示维护源见 [语言源说明](../../../../src/main/lang/README.md)，按 far_reach 分组；展示文字不是运行证据。
