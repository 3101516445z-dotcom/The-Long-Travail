# 施色领取与名称显示

## 职责分布

施色属于通用功能物品，使用七种主题颜色不代表归属某一个主题包。代码按物品入口、公共端菜单、客户端显示和可选兼容分布。

| 路径 | 职责与维护边界 |
|---|---|
| [ColoringItem](../../../../src/main/java/com/thelongtravail/item/ColoringItem.java) | 名称、提示及右键开窗；通过 NetworkHooks 在服务端打开菜单 |
| [NameColoring](../../../../src/main/java/com/thelongtravail/item/NameColoring.java) | 物品栈样式 ID 与名称组件变换；使用公共端类型，供菜单、名称注入和客户端标签调用 |
| [ColoringMenu](../../../../src/main/java/com/thelongtravail/menu/ColoringMenu.java) | 两端槽位布局及 DataSlot 同步；服务端生成预览、扣除输入和返还物品 |
| [ColoringScreen](../../../../src/main/java/com/thelongtravail/client/ColoringScreen.java) | 提交按钮请求、排版和绘制；复用 CatalogFrame 的无状态绘制方法 |
| [ColoringNameMixin](../../../../src/main/java/com/thelongtravail/mixin/ColoringNameMixin.java) | 包裹 ItemStack.getHoverName，在完整名称上应用样式 |
| [AffixNameStyle](../../../../src/main/java/com/thelongtravail/compat/apotheosis/AffixNameStyle.java) | 神化词缀与品质颜色适配，隔离神化依赖 |

`NameColoring` 与物品栈直接关联，当前规模适合保留在 `item`。`menu` 承载两端共享的容器模型，不属于纯客户端拾遗会话。注册由 `ModRegistry` 管理，Screen 由 `TravailClientEvents` 在客户端装配。

## 打开、选择与领取

1. `ColoringItem.use` 在服务端打开 `ColoringMenu`，客户端按菜单类型创建 `ColoringScreen`。
2. 输入槽变化触发 `updateResult`。服务端复制输入物品，写入所选样式，作为输出预览。
3. 按钮通过原版菜单协议提交选项；`clickMenuButton` 校验所有者、当前菜单和选项范围，更新 DataSlot 与预览。
4. 结果槽左键领取可容纳数量，右键领取一个，Shift 转移至背包。服务端按实际领取量扣除输入，再同步剩余预览。
5. 关闭时清除预览并返还输入；背包无空间时沿用原版掉落规则。输出预览不作为第二份物品返还。

输入、预览及选项属于菜单实例；持久样式写在领取物品根 NBT 的 `the_long_travail:name_style`。输入物品本身在预览阶段不写入所选样式。

## 名称显示与兼容

物品或自定义名称 → 神化词缀名称 → TLT 神化适配 → `NameColoring.decorate`。

样式变换复制名称组件及其子组件，保留物品名称数据、说明、附魔和属性。`clear` 表示关闭 TLT 名称效果；删除标记则恢复物品自身规则。神化的品质色处理留在 `compat/apotheosis`，通用变换不加载神化类。

客户端使用现有 `DiaryFontEffects` 和 Shader 材质。镀金、陶染的扫光宽度按当前字体计算。还原按钮在五种语言资源中明确两行断点，每行整体适配可用宽度。

## 配套入口与修改范围

- 增减样式：同步 `NameColoring` 的 ID、范围与标记、`ColoringScreen` 布局、五语言 `utility_items.json` 及回归矩阵。既有持久 ID 保持稳定。
- 调整槽位：同步 `ColoringMenu`、`ColoringScreen` 和客户端回归点击坐标。
- 修改拾遗：查 `CatalogEntries`、`CatalogUtilityDetails`、`CatalogTextStyle`；目录排列由 `CatalogScreen` 管理。
- 获取与资源：`recipes/coloring.json`、`advancements/recipes/coloring.json`、物品模型和贴图；注册与创造栏位于 `ModRegistry`。
- 修改名称兼容：同时检查 `ColoringNameMixin`、神化适配及改名后的样式保留。验证入口见[施色回归说明](../../../../tools/structure-regression/coloring-README.md)。

菜单不使用 `TravailNetwork` 自定义包；维护网络索引时应区分原版容器协议与模组消息注册。

详细样式语义、面板坐标及展示规则见[施色与名称显示](../../name-coloring.md)。
