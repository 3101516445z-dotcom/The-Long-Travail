# 界面会话与渲染生命周期

本文介绍日记/目录、字体路由和剑与灯光照入口。网络快照见 [网络协议与状态生命周期](网络协议与状态生命周期.md)。

## 状态归属与基础能力

| 层次 / 源码 | 归属与使用者 |
|---|---|

## 从悬停进入阅读

```mermaid
flowchart TD
    A[提示框收集悬停物品与位置] --> B[DiaryReadingTarget 观察槽位和身份]
    B --> C[按键或鼠标入口开始 hold]
    C --> D[每帧验证 owner、焦点、悬停与目标]
    D --> E{达到按住阈值}
    E -->|日记| F[TravelDiaryScreen 持续读取 source]
    E -->|目录| G[CatalogSession 父页或直接详情]
    F --> H[原 owner 的 Post 阶段绘制阅读层]
    G --> H
    H --> I[关闭或 owner 改变后释放会话]
```

canRead 要求没有活动目录、悬停属于当前 Screen、观察不超过 250 ms、鼠标与采样位置差各小于 0.5 GUI 单位。聚焦 EditBox 时不开始入口；按住失去窗口焦点或 Screen 不符会重置。每帧时间增量最多计 0.1 秒，阈值 0.5 秒，松开会衰减。DiaryEntryHold 在首次有效输入时锁定入口，两者同时按下优先日记；已有归属后任一入口键仍按住均可继续进度，不在半途切换归属。

DiaryReadingTarget 按物品对象引用寻找 Curios（含 cosmetic）、菜单槽位、玩家库存；记录来源 owner/kind/slot/index 并通过 supplier 重读。日记按 Journey UUID 接受，不按整个 NBT 完全相等；已定位且最初未初始化的日记允许接纳后续初始化身份。其他物品使用 ItemStack.matches。找不到槽位时退为位置和物品匹配的 preview，不能称为已追踪任意第三方容器。

日记 render 发现 source 已不是日记就关闭；旅程 revision 的正常变化可更新内容，原槽位被不同 Journey 替换则不继续读旧物品。目录详情路径不同：CatalogSession.detail 使用 entry.stack() 的标准新物品构造说明，传入的实际 stack 没有用于详情生成；不能把详情当作该实例 NBT 的实时查看器。

## owner、导航与输入消费

两种阅读层都没有把自己的 page 直接设为 Minecraft 当前 Screen，而是保留原 owner，取消其 Render.Pre，在 Render.Post 绘制阅读层。owner 被替换/关闭会退出；目录 END tick 还检查玩家存在和当前 Screen 等于 owner。页面的 isPauseScreen=false 不能独自决定原 owner 是否暂停游戏。

| 操作 | 当前语义 |
|---|---|
| 日记 Esc / 右键 / 关闭按钮 | 关闭阅读层；方向及翻页键滚动，Backspace 不导航 |
| 目录父页 Esc / 右键 / 关闭按钮 | 退出整个目录会话 |
| 从父页打开的详情 Esc / 右键 | 返回保留的父页，并收起搜索展开状态 |
| 直接打开的详情 Esc / 右键 | 退出会话；没有隐含父页 |
| 详情底部返回 | 调用 session.back，必要时创建父页 |
| 详情关闭按钮 | 始终退出会话 |
| 父页搜索 Backspace | EditBox 编辑；详情 Backspace 不导航 |

DiaryInputRouter 通过 heldKeys 判断首次按下，阅读中只在 firstPress 转交按键；目录仅抑制 Esc 自动重复，其余重复键可转交，便于连续删字/滚动。两者记录 consumedKeys/consumedButtons，关闭后仍拦截对应释放。日记键鼠事件使用 HIGHEST 优先级，释放订阅同时接收已取消事件，以清除入口与消费记录。目录活动时 DiarySession.canRead 返回 false，日记键盘处理让位于目录。

## 日记状态清理

| 触发 | 状态所有者与处理 |
|---|---|
| 关闭阅读页 | DiarySession 清 reading、owner 与悬停观察，播放关闭音效；宿主界面继续存在，输入消费记录留到释放事件 |
| 宿主 Closing | DiarySession 重置长按，关闭属于该宿主的阅读页，清悬停；DiaryInputRouter 清按下与消费集合 |
| Render.Pre 发现宿主变化 | DiarySession 关闭旧阅读页；每帧先清旧悬停观察 |
| Render.Pre 发现窗口失焦 | DiarySession 重置长按，DiaryInputRouter 清输入集合；阅读页继续由宿主生命周期管理 |
| 松开入口键或鼠标键 | DiarySession 移除对应入口输入；DiaryInputRouter 移除消费记录，长按进度在后续帧衰减 |
| LoggingOut | 公共客户端订阅完成其他状态清理后，先清 DiaryInputRouter，再由 DiarySession 关闭阅读页、重置长按 |

日记没有单独的换维度订阅；界面切换沿宿主 Closing 或后续 Render.Pre 清理。renderingReading 仅在阅读层绘制期间置位，并在 finally 中复位。新增会话状态应归入对应所有者的清理路径。

目录布局计算虚拟页面尺寸与 scale；鼠标位置和拖动增量除以 scale，裁剪坐标乘回 scale。新增命中区必须使用对应坐标空间，不能直接混用屏幕像素、GUI 单位和页面单位。

## 绘制次序与状态恢复

日记按背景遮罩、书签/书本、身份与页签、正文、关闭控件、悬停提示绘制。正文裁剪后逐行绘制，再关闭裁剪并画滚动条。布局键包括主题、见证/揭示、初始化、群系数、配置 revision、资源 generation、Language 和字体行高，内容另核对条件身份和状态 revision。

目录详情在 init 时将构造时段落快照分行，尺寸变化可重新排版，但不是每帧重新生成玩法说明。正文绘制跳过 alpha<4 的行，避免 Font 将极小 alpha 当作未指定透明度。[CatalogFrame.fadeEdges](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogFrame.java) 在渐变覆盖前后 flush，使用 guiOverlay，使覆盖发生在此前正文提交之后。

| 状态 | 已有恢复措施 | 限制 |
|---|---|---|
| 阅读层外部 pose | 日记事件层与 CatalogSession 都在 finally 中 popPose | 只负责自己的一个栈层，不会自动清空内部泄漏层 |
| renderingReading 标记 | 日记事件层 finally 置 false | [GuiGraphicsTooltipMixin](../../../../src/main/java/com/thelongtravail/mixin/presentation/GuiGraphicsTooltipMixin.java) 据此屏蔽背景提示框，而允许阅读层内部提示 |
| 页面内部 pose/scissor | 正常路径成对 push/pop、enable/disable | 部分路径缺少局部 finally，绘制异常可能中断状态恢复 |
| 日记纹理颜色/混合 | 正常路径恢复白色、disableBlend | 不是保存任意进入状态并原样还原的通用事务 |
| 字体 RenderType | 包装类型调用原 setup，clear 委托原 clearRenderState | 依赖 RenderType/缓冲提交生命周期，不是每次 draw 结束手工恢复旧 Shader |

## 字体标记 → 材质 → Shader

[ThemeTooltipMixin](../../../../src/main/java/com/thelongtravail/mixin/presentation/ThemeTooltipMixin.java) 在 ItemStack.getTooltipLines 返回后调用 ThemeTooltips.finish；物品名称、主题标题及 DiaryDialogue 等文本通过 Style.insertion 附材质标记。[DiaryFontMixin](../../../../src/main/java/com/thelongtravail/mixin/presentation/DiaryFontMixin.java) 以 priority 3000 拦截 Component 和 FormattedCharSequence 两种 drawInBatch。

[DiaryFontEffects.material](../../../../src/main/java/com/thelongtravail/client/diary/DiaryFontEffects.java) 忽略空白，要求非空白字符能归为同一材质；混杂普通字符或不同材质时返回 -1，走原绘制。ThreadLocal probe 有 busy 防重入。DiaryText.Unmarked 和清除 insertion 的绘制序列阻止再次进入同一材质分支；光晕多次绘制会预备 glyph 数组，普通一次绘制使用惰性去标记。

名称/主题光晕由 NameHaloKernel 与质量配置决定，先画两圈采样光晕，再画正文。MaterialBuffers 在一次绘制范围按原 RenderType 对象身份复用包装。setup 先调用原状态，Shader 未加载或原 Shader 名含 stroke/background 时保留原路径；按 sdf/intensity 名称选择图集模式，再设置时间、材质、起点、扫描宽度和主题调色板。

资源入口为 [diary_font.fsh](../../../../src/main/resources/assets/the_long_travail/shaders/core/diary_font.fsh)。prose:flavor 用负 SweepWidth 区分风味文本，材质编号还区分名称、散文、主题、光晕及词缀。资源重载注册 Shader 后增加 generation，清 DiaryDialogue 缓存和材质日志标记。新增标记必须同时对齐生产者、material 识别、编号/调色板与 Shader 分支，不能仅改颜色。

## 剑与灯光照是另一条渲染链

[LanternLightingClient](../../../../src/main/java/com/thelongtravail/client/lighting/LanternLightingClient.java) 收集玩家同步状态/手持、女仆和掉落物光源，在 RenderTick.START 构造当前来源，再由重建调度器发布 [LanternLightSnapshot](../../../../src/main/java/com/thelongtravail/client/lighting/LanternLightSnapshot.java) 并标记脏 section。快照构建后只读，网格线程按采样位置查询快照中的区段。换世界重置网格相关缓存，退出清全部状态。

| 桥接 | 修改位置 |
|---|---|
| [LanternEntityLightMixin](../../../../src/main/java/com/thelongtravail/mixin/valley/LanternEntityLightMixin.java) | EntityRenderer 返回 packed light 后，按插值位置及实体中部合并光源 |
| [LanternLevelLightMixin](../../../../src/main/java/com/thelongtravail/mixin/valley/LanternLevelLightMixin.java) | LevelRenderer.getLightColor 两个重载返回后合并；isSolidRender 判断限制适用位置，首个重载另有已满亮/空快照快速返回 |
| [LanternEmbeddiumLightMixin](../../../../src/main/java/com/thelongtravail/compat/mixin/embeddium/LanternEmbeddiumLightMixin.java) | 可选 smooth/flat light pipeline.calculate 返回后，按 quad 四个顶点采样合并 out.lm |

这些桥接修改客户端渲染采样结果。第三方光影沿用这些采样入口时可读取合并结果；独立采样管线需专用适配。

## 视觉剥夺的状态与画面

`client/visual` 集中这条表现链。ClientSetup 将 VisualDeprivationPacket 的接收器绑定到 [VisualDeprivationClient](../../../../src/main/java/com/thelongtravail/client/visual/VisualDeprivationClient.java)，区分持续时间更新、进度同步与立即清除。客户端以玩家和世界为状态归属，VisualDeprivationTimeline 按服务端进度插值采样；客户端逐刻推进插值时钟，暂停或时停时暂停推进。

VisualDeprivationStyle 保存画面参数并处理插值与脉动。VisualDeprivationFog 调整雾参数；[VisualDeprivationRenderer](../../../../src/main/java/com/thelongtravail/client/visual/VisualDeprivationRenderer.java) 在 ModBus 注册着色器，由 VisualDeprivationRenderMixin 接入画面绘制。退出、玩家失效或世界改变时清理本地时间线与样式。

## 维护要点

改输入先查 owner/已消费集合和导航来源；改数据先区分日记实时 supplier 与目录快照；改布局同时检查 scale、命中区与 scissor；改文字效果同时检查 marker、Unmarked 和缓冲生命周期；改光照检查快照发布与脏区段。

## 摘要提示与进度条

物品先通过 `ItemDescription → ItemSummary → ThemeTooltips.append` 返回完整摘要，再由 `ThemeTooltipMixin` 整理附加提示。`DiarySession.tooltip` 在 GatherComponents 阶段调用 `DiaryHintTooltip.findPrompt`，递归检查外层组件及其子组件中的长按提示键。匹配后按实际提示宽度在最后一行提示下加入 `DiaryProgressTooltip`；提示不必位于最外层可翻译组件。

进度取自当前宿主界面和同一悬停目标的长按状态；键鼠输入、打开拾遗及关闭清理仍由现有 DiarySession、DiaryInputRouter 和 CatalogSession 管理。
