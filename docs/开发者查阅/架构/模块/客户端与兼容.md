# 客户端与兼容

本章介绍启动装配、代表性客户端订阅和网络请求、Mixin 清单及可选加载策略。网络入口见 [输入请求与可选加载](../链路/输入请求与可选加载.md)；另见 [界面会话与渲染生命周期](../链路/界面会话与渲染生命周期.md)。

## 展示注入

`mixin/presentation` 中，DiaryFontMixin 负责字体效果，GuiGraphicsTooltipMixin 处理日记覆盖层后的背景提示，ThemeTooltipMixin 整理完整物品提示，SkillNoticeGuiAccessor 访问动作栏消息，VisualDeprivationRenderMixin 接入视觉剥夺渲染。ColoringNameMixin 在完整物品名称返回后施色，保留通用端注册。

高度导致的本地垂直飞行速度调整位于 `mixin/movement/AltitudeLocalFlightMixin`；日记会话与输入分别由 `DiarySession` 和 `DiaryInputRouter` 管理。

## 三种边界分别查

| 边界 | 入口 | 负责什么 |
|---|---|---|
| 物理客户端加载 | [TravailClientEvents](../../../../src/main/java/com/thelongtravail/client/TravailClientEvents.java) 的 Dist.CLIENT 内部订阅类 → [ClientSetup](../../../../src/main/java/com/thelongtravail/client/ClientSetup.java) | 按键、渲染器、tooltip 工厂与客户端接收回调装配 |
| 协议与逻辑端 | [TravailNetwork](../../../../src/main/java/com/thelongtravail/network/TravailNetwork.java) | 通道版本、消息编号、编码解码与 PLAY_TO_CLIENT / PLAY_TO_SERVER 方向 |
| 外部模组契约 | [OptionalCompatPlugin](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatPlugin.java)、[OptionalCompatState](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatState.java) | 按分支检查模组、目标类、方法字段或指令结构，并决定适配是否启用 |

公共启动 [TheLongTravail](../../../../src/main/java/com/thelongtravail/TheLongTravail.java) 注册网络、配置、注册表及公共事件。客户端类通过专用订阅装配，日记、灯光、飞行与视觉剥夺分别集中在 client 下对应子包；network 保存协议与同步缓存。

## 客户端职责地图

| 功能 | 查阅入口 | 与游戏状态的关系 |
|---|---|---|
| 日记会话 | [DiarySession](../../../../src/main/java/com/thelongtravail/client/diary/DiarySession.java)、[TravelDiaryScreen](../../../../src/main/java/com/thelongtravail/client/diary/TravelDiaryScreen.java) | 保存 owner、悬停目标、长按和阅读实例，绘制覆盖层与提示 |
| 日记输入 | [DiaryInputRouter](../../../../src/main/java/com/thelongtravail/client/diary/DiaryInputRouter.java) | 维护按下及已消费输入，判断编辑焦点并分发键鼠事件 |
| 拾遗图鉴 | [CatalogSession](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogSession.java) | 保存 owner、父目录和当前页，处理缩放与输入消费；不是服务器菜单 |
| 名称/文字渲染 | [ThemeTooltips](../../../../src/main/java/com/thelongtravail/client/ThemeTooltips.java)、[AspectTheme](../../../../src/main/java/com/thelongtravail/AspectTheme.java) | 主题标记、样式与提示文本 |
| 施雨输入 | [RainClient](../../../../src/main/java/com/thelongtravail/client/RainClient.java) | 按键发请求；本地按键条件不是服务端资格判定 |
| 苏生按钮 | [UnderworldClient](../../../../src/main/java/com/thelongtravail/client/UnderworldClient.java) | 缓存服务端给出的 Death UUID，发送请求，不自行决定消耗或复活 |
| 梦境与时停 | [BoundlessClientEvents](../../../../src/main/java/com/thelongtravail/client/BoundlessClientEvents.java)、[BoundlessClient](../../../../src/main/java/com/thelongtravail/client/BoundlessClient.java)、[TimeStopClient](../../../../src/main/java/com/thelongtravail/client/timestop/TimeStopClient.java) | BoundlessForgeBus 分发逐刻更新和退出清理；BoundlessClient 管理梦境输入与冷却；timestop 管理时停快照、边界和提示 |
| 飞行 | client/flight 中的 PrinceFlightClient、PrinceFlightPermission、IcarusWingModel、IcarusWingTexture | 本地授权状态、消息接收及翅膀模型与贴图 |
| 灯光 | client/lighting 中的 LanternLightingClient、LanternLightSnapshot、LanternRebuildScheduler | 收集光源、发布快照与调度网格重建 |
| 视觉剥夺 | client/visual 中的 VisualDeprivationClient、Timeline、Style、Fog、Renderer | 接收进度、采样时间线、雾参数与画面遮罩 |
| 终结 | ExecutionTerminationClient | 由主客户端 setup 绑定接收器并处理本地状态 |

拾遗正文由 [CatalogTextStyle](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogTextStyle.java) 执行匹配、去重和样式叠加；[CatalogHighlightRules](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogHighlightRules.java) 保存固定词表与正则模式。规则按主题分组，应用顺序由 CatalogTextStyle 管理。

DiarySession.open 创建并 init 阅读实例，保留原 owner；CatalogSession.show 保存 page 并计算布局。两者在宿主界面上绘制覆盖层。JEI 覆盖层适配需同时核对 owner、渲染阶段和输入消费。

退出清理由多个订阅分担。TravailClientEvents 依次清理僵硬状态、JourneySync、对话与音效、TooltipConfigSync、视觉剥夺，再调用 DiaryInputRouter.clear 和 DiarySession.logout。RainClient 清客户端雨状态与提示缓存；UnderworldClient 清 Death UUID；BoundlessClientEvents 先清梦境，再清时停快照与提示粒子。各状态的清理入口见 [会话生命周期](../链路/界面会话与渲染生命周期.md#日记状态清理)。

## 物品摘要与翻译回退

物品的 `appendHoverText` 调用 [ItemDescription](../../../../src/main/java/com/thelongtravail/item/ItemDescription.java)，通过 [ItemSummary](../../../../src/main/java/com/thelongtravail/item/ItemSummary.java) 的回调直接生成完整摘要。公共入口只依赖物品和文本类型；`ClientSetup` 在客户端初始化时安装 `ThemeTooltips.append`，专用服务端保留空回调。

`ThemeTooltips` 在私有列表内组织简介、状态、限制和拾遗提示，对外返回可读内容；外层样式标记用于后续识别。`ThemeTooltipMixin` 在完整提示返回时调用 `finish`，整理属性和女仆提示的位置，并兼容可翻译组件或普通字符串形式的旧标记。未知物品的旧标记被移除，重复整理复用同一组内容。

[TooltipTranslations](../../../../src/main/java/com/thelongtravail/client/TooltipTranslations.java) 为摘要、主题详情构建器和术语卡片提供翻译入口。类初始化时读取包内英文资源；正常译文优先，缺失时使用英文备用文本，包内也无对应键时显示 `Description unavailable`。缺失键以线程安全集合去重，每次启动每键记录一次；资源重载不清空集合，也没有全局条数上限。包内英文读取失败仅在初始化时记录错误。

物品玩法仍在主题与公共机制层，客户端摘要只读取物品数据和同步配置。可选联动调用与成员桥接留在 `compat`，共用异常包装由 `DirectCalls` 保持；各存储实现和 RSI 版本约束见 [外部库存复制](外部库存复制.md)。

## 施色容器与名称显示

施色使用 `ColoringItem → ColoringMenu → ColoringScreen`：服务端负责预览及领取，客户端只提交选项和绘制。名称变换在 `NameColoring`，原版桥接在 `ColoringNameMixin`，神化品质规则留在可选兼容包。菜单属于正式服务器容器，与拾遗的本地会话不同；仅共享无状态框架绘制。领取、同步与名称处理顺序见 [施色领取与名称显示](../链路/施色领取与名称显示.md)，样式语义与布局参数见 [施色与名称显示](../../name-coloring.md)。

## 网络装配

当前通道为 `the_long_travail:main`，协议字符串为 `23`，两侧均要求相等。消息编号与方向在 TravailNetwork.register 中逐项指定；完整21项注册、字段、身份与清理见 [网络协议与状态生命周期](../链路/网络协议与状态生命周期.md)，本章保留代表性路径。

UnderworldPacket 默认 receiver 是空回调，客户端 setup 才绑定 UnderworldClient。handler 通过 enqueueWork 执行接收或服务端请求，再标记 handled。类似回调装配把 Minecraft 客户端访问放在对应端；但“用了 receiver”本身不证明整个消息所有引用都满足端隔离。

服务器权威数据、同步后的展示快照与客户端输入状态不能混为一份：提示配置同步不意味着玩家修改客户端显示值能更改玩法；按钮显示可用也不能跳过服务端死亡记录检查。实际链路见 [输入请求与可选加载](../链路/输入请求与可选加载.md)。

## 可选兼容并非统一开关

完整来源分类继续维护在 [可选模组联动入口](../../optional-compat.md)。这里只解释加载机制：

- [主 Mixin 清单](../../../../src/main/resources/mixins.the_long_travail.json) 与 [兼容 Mixin 清单](../../../../src/main/resources/mixins.the_long_travail.compat.json) 都区分公共 mixins 和 client。兼容清单指定 OptionalCompatPlugin，且 required=true、defaultRequire=1；启用的注入仍须满足目标匹配要求。
- 神化名称和 Quark 分支按模组存在判断；假人、女仆性格存储、Embeddium、JEI、Sounds 等还核对不同程度的字节码契约。检查严格程度因分支而异。
- Gravestone/Caelus 使用共享 Gate；Gate 缓存本次启动的 ABSENT/ENABLED/DISABLED，不在配置热重载时自动重新探测。
- 有些分支遇到不可读字节码会警告并禁用，有些会抛错。MaidSwim/MaidRelicSlot 的 IOException 分支会抛 IllegalStateException。
- 女仆攻击桥接 [UnderworldMaidAttackMixin](../../../../src/main/java/com/thelongtravail/compat/mixin/maid/UnderworldMaidAttackMixin.java) 注册于兼容清单，目标为原版 Mob；插件始终允许注入，由 MaidAccessories.seesUndead 在运行时决定是否替换类型判定。女仆缺席时沿用原版结果。
- 新生魔艺属性排除与假人收魂排除分别由 compat/arsnouveau/ArsNouveauAttributeRules 和 compat/dummmmmmy/DummySoulRules 提供；玩法类负责应用规则。
- 外部库存反射适配、注册表预设和外部插件接口并不都经过 OptionalCompatPlugin。联动存在、加载成功和行为兼容是三件不同的事。

[mods.toml](../../../../src/main/resources/META-INF/mods.toml) 将 Curios 声明为必需依赖；可选编译配置由 [optional-compat.gradle](../../../../gradle/optional-compat.gradle) 管理。运行是否可选需结合依赖声明、类加载路径和启动验证，不能仅凭 compat 目录名判断。

## 修改与验证入口

新增网络功能要同时检查编号/方向、输入格式、入队后的对象有效性、服务端业务资格、客户端缓存以及退出重置。新增可选适配要明确缺席、兼容、不兼容三种情况下的行为，并核对目标版本的方法语义。

后续验证至少区分专用服务器启动、客户端界面/输入、断开重连、换维度/重生，以及可选模组缺席和目标版本在场。

## 逐日与籠釣瓶女仆饰品

主体通过 MaidIntegration 查询装备、阶段和伤害主体；CompatBootstrap 安装 MaidIntegrationProvider，提供者转发到 MaidAccessories，加载判断后进入女仆实现。MaidPeriodicEffects 复用已有维护入口；onTakeOff 与 forget 清理籠釣瓶属性。主人阶段只控制恶意／见证，基础能力不依赖主人在线。ThemeTooltips 读取风味语言键，SunBladeText 与 CatalogTextStyle 分别负责正文和着色。接口与生命周期见 [女仆联动](../../sun-blade-maid-integration.md)。

## 札记卷首与拾遗术语

TravelDiaryScreen 管理七枚左侧书签、主题选择及会话内页面记忆，DiaryPreface 负责卷首和题记的五语言诗文、关键词样式及双页滚动。背景与固定纸页遮罩夹住书签末端，布局在初始化与绘制时同步，详见[卷首与题记](../../diary-preface.md)。

CatalogGlossary 在 CatalogTextStyle 染色之后标记每个详情页第一次出现的术语；CatalogDetailScreen 依据最终换行及样式计算悬浮区域，绘制解释小窗和一个帧缓冲像素的下划线。词条和解释属于五语言 catalog.json 及六份主题 catalog 分组，详见[拾遗术语解释](../../catalog-glossary.md)。

## 伊卡洛斯贴图生命周期

`IcarusWingTexture` 在客户端注册资源重载监听，校验贴图尺寸与格式，缓存轮廓和实际使用的贴图。资源包贴图异常时使用内置 PNG 注册动态贴图；重载时释放动态资源并更新代次。`IcarusElytraLayerMixin` 按代次重建 `IcarusWingModel`，飞行和战斗状态仍由服务端对应入口管理。详见[飞行与显示链路](../链路/伊卡洛斯飞行与阶段加成.md)。

## 物品摘要与展示配置

ThemeTooltips.finish 以 ItemDescription.SUMMARY 标记替换摘要，覆盖六主题物品、旅程助力、主题之石和主题精粹。风味文字与摘要显式换行分别拆为组件；摘要拆行保留语义样式。原生属性与女仆提示仍由各自组件提供。

佩戴门槛、效果门槛和携带不叠加提示使用公共语言键。携带提示位于拾遗入口之前，使用深灰色；门槛是否展示取决于玩家当前装备。CatalogTextStyle 保留古今语怪已指定的材料与动作染色。

TooltipConfigSync 将路引半径同步为 wayguide.radius；ThemeTooltips 与 CatalogUtilityDetails 共用该值。BoundlessRelicText 从同步快照读取 dream.duration，按键由客户端 KeyMapping 提供。东海道技能及永生芽修复已是固定机制，展示层不再接收它们的启用开关。

## 主题拾遗详情构建

CatalogEntries 将六主题条目分别交给 CatalogFlourishingDetails、CatalogAbyssDetails、CatalogFarReachDetails、CatalogValleyDetails、CatalogUnderworldDetails、CatalogBoundlessDetails。它们组织段落、列表、阶段标题与同步配置数值，CatalogUtilityDetails 组织通用物品。CatalogFarReachCards 提供淘金概率与佳肴筛选卡片，其他卡片由 CatalogGlossary 分派参数。服务端效果仍由主题实现负责，展示类全部留在 client/catalog。

TooltipConfigSync 同步 golden_age.digGoldChance 及卡片所需筛选状态，服务端配置决定实际效果。正文与小卡片的参数、术语适用范围和样式职责见[拾遗术语解释](../../catalog-glossary.md)。
