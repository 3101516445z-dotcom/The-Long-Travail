# 客户端与兼容

核对日期：2026-10-24。已核对启动装配、代表性客户端订阅和网络请求、Mixin 清单及可选加载策略。未完成所有包的协议安全审计、全部渲染流程或全部第三方版本验证，未启动客户端/专用服务器。实例见 [输入请求与可选加载](../链路/输入请求与可选加载.md)；A06 已补齐 [界面会话与渲染生命周期](../链路/界面会话与渲染生命周期.md) 的核心静态链路。

## 三种边界分别查

| 边界 | 入口 | 负责什么 |
|---|---|---|
| 物理客户端加载 | [TravailClientEvents](../../../../src/main/java/com/thelongtravail/client/TravailClientEvents.java) 的 Dist.CLIENT 内部订阅类 | 按键、渲染器、tooltip 工厂与客户端接收回调装配 |
| 协议与逻辑端 | [TravailNetwork](../../../../src/main/java/com/thelongtravail/network/TravailNetwork.java) | 通道版本、消息编号、编码解码与 PLAY_TO_CLIENT / PLAY_TO_SERVER 方向 |
| 外部模组契约 | [OptionalCompatPlugin](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatPlugin.java)、[OptionalCompatState](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatState.java) | 按分支检查模组、目标类、方法字段或指令结构，并决定适配是否启用 |

公共启动 [TheLongTravail](../../../../src/main/java/com/thelongtravail/TheLongTravail.java) 注册网络、配置、注册表及公共事件，不直接创建界面。客户端类通过专用订阅装配。包名本身不是端隔离证明：network 中既有协议又有本地缓存，boundless 中也有客户端授权状态。

## 客户端职责地图

| 功能 | 查阅入口 | 与游戏状态的关系 |
|---|---|---|
| 日记阅读 | [TravailClientEvents](../../../../src/main/java/com/thelongtravail/client/TravailClientEvents.java)、[TravelDiaryScreen](../../../../src/main/java/com/thelongtravail/client/TravelDiaryScreen.java) | 保存 owner、悬停目标、长按和阅读实例，协调输入与背景提示 |
| 拾遗图鉴 | [CatalogSession](../../../../src/main/java/com/thelongtravail/client/catalog/CatalogSession.java) | 保存 owner、父目录和当前页，处理缩放与输入消费；不是服务器菜单 |
| 名称/文字渲染 | [ThemeTooltips](../../../../src/main/java/com/thelongtravail/client/ThemeTooltips.java)、[AspectTheme](../../../../src/main/java/com/thelongtravail/AspectTheme.java) | 主题标记与展示；shader/Mixin 全链留待渲染专项 |
| 施雨输入 | [RainClient](../../../../src/main/java/com/thelongtravail/client/RainClient.java) | 按键发请求；本地按键条件不是服务端资格判定 |
| 苏生按钮 | [UnderworldClient](../../../../src/main/java/com/thelongtravail/client/UnderworldClient.java) | 缓存服务端给出的 Death UUID，发送请求，不自行决定消耗或复活 |
| 梦境与时停 | [BoundlessClient](../../../../src/main/java/com/thelongtravail/client/BoundlessClient.java)、[TimeStopClient](../../../../src/main/java/com/thelongtravail/client/TimeStopClient.java) | 单独订阅初始化与退出，接收状态并驱动本地表现 |
| 飞行、终结、灯光 | PrinceFlightClient、ExecutionTerminationClient、LanternLightingClient | 由主客户端 setup 绑定接收器，详细状态规则见既有专项章节 |

日记 open 创建并 init 阅读实例，保留原 owner；CatalogSession.show 保存 page 并计算布局。不能假定它们都通过 Minecraft.setScreen 替换当前界面。JEI 覆盖层适配需同时核对 owner、渲染阶段和输入消费。

退出清理由多个订阅分担。TravailClientEvents 清 JourneySync、TooltipConfigSync、音效、视觉剥夺、输入集合和阅读状态；RainClient 清客户端雨状态与提示缓存；UnderworldClient 清 Death UUID；BoundlessClient 清时停等状态。新增缓存应明确归属和清理入口，不能只在世界首次进入时初始化。

## 网络装配

当前通道为 `the_long_travail:main`，协议字符串为 `21`，两侧均要求相等。消息编号与方向在 TravailNetwork.register 中逐项指定；完整 19 项注册、字段、身份与清理见 [网络协议与状态生命周期](../链路/网络协议与状态生命周期.md)，本章保留代表性路径。

UnderworldPacket 默认 receiver 是空回调，客户端 setup 才绑定 UnderworldClient。handler 通过 enqueueWork 执行接收或服务端请求，再标记 handled。类似回调装配把 Minecraft 客户端访问放在对应端；但“用了 receiver”本身不证明整个消息所有引用都满足端隔离。

服务器权威数据、同步后的展示快照与客户端输入状态不能混为一份：提示配置同步不意味着玩家修改客户端显示值能更改玩法；按钮显示可用也不能跳过服务端死亡记录检查。实际链路见 [输入请求与可选加载](../链路/输入请求与可选加载.md)。

## 可选兼容并非统一开关

完整来源分类继续维护在 [可选模组联动入口](../../optional-compat.md)。这里只解释加载机制：

- [主 Mixin 清单](../../../../src/main/resources/mixins.the_long_travail.json) 与 [兼容 Mixin 清单](../../../../src/main/resources/mixins.the_long_travail.compat.json) 都区分公共 mixins 和 client。兼容清单指定 OptionalCompatPlugin，且 required=true、defaultRequire=1；被允许加载的注入不等于可以任意失配。
- 神化名称和 Quark 分支按模组存在判断；假人、女仆性格存储、Embeddium、JEI、Sounds 等还核对不同程度的字节码契约。检查严格程度因分支而异。
- Gravestone/Caelus 使用共享 Gate；Gate 缓存本次启动的 ABSENT/ENABLED/DISABLED，不在配置热重载时自动重新探测。
- 有些分支遇到不可读字节码会警告并禁用，有些会抛错。MaidSwim/MaidRelicSlot 的 IOException 分支会抛 IllegalStateException，不能宣称所有可选适配异常都静默降级。
- 外部库存反射适配、注册表预设和外部插件接口并不都经过 OptionalCompatPlugin。联动存在、加载成功和行为兼容是三件不同的事。

[mods.toml](../../../../src/main/resources/META-INF/mods.toml) 将 Curios 声明为必需依赖；可选编译配置由 [optional-compat.gradle](../../../../gradle/optional-compat.gradle) 管理。运行是否可选需结合依赖声明、类加载路径和启动验证，不能仅凭 compat 目录名判断。

## 修改与验证入口

新增网络功能要同时检查编号/方向、输入格式、入队后的对象有效性、服务端业务资格、客户端缓存以及退出重置。新增可选适配要明确缺席、兼容、不兼容三种情况下的行为；方法签名通过不代表其语义没有变化。

后续验证至少区分专用服务器启动、客户端界面/输入、断开重连、换维度/重生，以及可选模组缺席和目标版本在场。本轮文档检查不代表上述场景通过。
