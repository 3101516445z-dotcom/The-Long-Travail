# 六主题玩法功能地图

本章介绍六主题定义、28 个主题物品的注册映射、公共日记事件、部分物品回调和配置装配。具体数值、概率和第三方行为见专项章节。

## 两条入口分别查

**日记主题效果**从 [TravailEvents](../../../../src/main/java/com/thelongtravail/event/TravailEvents.java)、[TravailEffectActions](../../../../src/main/java/com/thelongtravail/event/TravailEffectActions.java) 和旅程状态进入。**主题物品**先通过 [ModRegistry](../../../../src/main/java/com/thelongtravail/registry/ModRegistry.java) 找构造类，再追物品使用、Curios 回调、主题事件或战斗入口。主题名称相同不表示两者共享所有触发条件。

[TravailAspect](../../../../src/main/java/com/thelongtravail/TravailAspect.java) 的 ID、枚举顺序和 mask 属于领域定义；[AspectTheme](../../../../src/main/java/com/thelongtravail/AspectTheme.java) 负责颜色和名称标记，forAspect 按枚举名称映射，material 使用 ordinal。两者不能因同样表示主题就混作状态判断入口。

## 主题、配置和实现目录

下表列出各主题的主要实现入口。每个主题另有 `<id>_stone` 与 `<id>_essence`，由 ModRegistry 遍历枚举注册。

| 主题 | 领域 ID / 实现包 | 物品配置定义 | 实现线索 |
|---|---|---|---|
| 繁茂 | flourishing / flourishing | [FlourishingItemsConfig](../../../../src/main/java/com/thelongtravail/config/FlourishingItemsConfig.java) | FloralEvents、FlowerData、FloralCombat、Affection、Mistletoe、EverlastingFlower、ImmortalBud |
| 归墟 | abyss / abyss | [AbyssItemsConfig](../../../../src/main/java/com/thelongtravail/config/AbyssItemsConfig.java)，另有 RainConfig | RainEvents、RainState、MidnightLafite、PerfectFluidRecipe、LiquefiedAbundance、AbundanceEffectPool |
| 穷遐 | far_reach / farreach | [FarReachItemsConfig](../../../../src/main/java/com/thelongtravail/config/FarReachItemsConfig.java) | GoldenAgeActions、IcarusFlight、FarReachCombat、DonQuixoteState、BabelCarrying |
| 幽谷 | deep_valley / valley | [DeepValleyItemsConfig](../../../../src/main/java/com/thelongtravail/config/DeepValleyItemsConfig.java)，另有 AzraelConfig、SwordLanternConfig | AzraelState、SwordLanternState、Phosphophyllite、UndergroundVelvet |
| 冥府 | underworld / underworld | [UnderworldItemsConfig](../../../../src/main/java/com/thelongtravail/config/UnderworldItemsConfig.java) | UnderworldItems、BookRevival、UnderworldRelics、DemonKingCombat、SoulBannerKills |
| 无垠 | boundless / boundless | [BoundlessItemsConfig](../../../../src/main/java/com/thelongtravail/config/BoundlessItemsConfig.java) | DreamState、StarVoiceState、LittlePrince、LorentzFantasy |

[TravailConfig](../../../../src/main/java/com/thelongtravail/config/TravailConfig.java) 既定义日记主题规则，也将上述物品定义装入 `aspects/<领域 ID>.toml`。不要根据 Java 包名推导文件名：farreach 对应 far_reach，valley 对应 deep_valley。配置发布和缓存刷新见 [配置与运行时数据](配置与运行时数据.md)。

## 跨层协作

| 触发 | 进入的基础或协调层 | 处理规则 |
|---|---|---|
| 日记佩戴与玩家更新 | TravailCurios → LongTravailData、JourneyQueries、TravailPlayerMaintenance | 没有日记时会走移除额外槽位、恢复速度等分支；不是只停止新效果 |
| 旅程变更 | JourneyService → JourneyRuntimeMaintenance.onJourneyChanged | 幽谷变更清 AzraelState，穷遐变更清 CleanseRotation，无垠变更刷新高度惩罚/槽位；按 mask 与 resetAspects 判断 |
| 日记治疗、攻击与受击效果 | TravailEffectActions → 状态判断、RuntimePools、EffectChanges、AutomaticEffectBudget | 穷遐/幽谷效果与繁茂治疗有不同分支；不能用一个“见证后统一加成”概括 |
| 已确认战斗结果 | [CombatConsequences](../../../../src/main/java/com/thelongtravail/helper/CombatConsequences.java) | confirmed 分发 FarReachCombat、SwordLanternState、StarVoiceState、AzraelState；玫瑰伤害分支会跳过部分分发 |
| 喜欢的心情绑定/清除 | FlourishingAccessoryItem(false) → Affection | interactLivingEntity 绑定；潜行 use 清除；装备/卸下重置运行状态 |
| 伊卡洛斯开关 | FarReachAccessoryItem(false) → IcarusFlight.toggle | 潜行使用时服务端切换物品开关；实际滑翔、Caelus 与退出回退已见 [伊卡洛斯专项](../链路/伊卡洛斯飞行与阶段加成.md) |
| 磷叶石卸下 | PhosphophylliteItem.onUnequip → Phosphophyllite.tick | 服务端立即触发重新对账，不能只看周期事件 |

公共机制详解： [旅程](旅程与主题状态.md)、[装备与携带](装备与携带.md)、[战斗](战斗结算.md)、[复制](外部库存复制.md)、[时停](时停与恢复.md)、[复活与终结](复活与终结.md)、[小王子飞行](../链路/小王子飞行.md)。

## 资源与展示入口

语言唯一维护源为 [src/main/lang](../../../../src/main/lang/README.md)，每种语言按 `aspects/<领域 ID>` 分组；不要手改 build 生成文件。名称、提示与图鉴说明应先定位翻译键及 ItemDescription/主题 Text 类，再追 TooltipConfigSync 的展示数值。提示文本不能反向证明服务端机制已经实现。

资源目录为 [assets/the_long_travail](../../../../src/main/resources/assets/the_long_travail) 和 [data/the_long_travail](../../../../src/main/resources/data/the_long_travail)。模型、纹理、配方、标签、进度分别维护；不要假设每件物品都通过同名 JSON 配方获得，注册中还存在自定义配方序列化器。

## 逐日与籠釣瓶

| 主题 | 注册 ID | 入口与职责 |
|---|---|---|
| 穷遐 | sun_chaser | SunChaserItem 接入 CarryingApi；farreach/SunChaser 处理免火、回血、抑制和固定追加 |
| 冥府 | kagotsurube | KagotsurubeItem 接入唯一腰带；underworld/Kagotsurube 处理属性、凋零与转换资格，KagotsurubeRecipe 匹配诅咒书 |

配置由 SunBladeConfig 分别装入 FarReachItemsConfig 和 UnderworldItemsConfig，TooltipConfigSync 同步有效值。ArchaeologyTrades 提供逐日交易，MaterialLoot 提供考古注入；KagotsurubeDisplay 只提供 JEI 展示。模型、贴图、腰带标签、配方及五种语言按注册 ID 对应。共享伤害范围和来源包装位于 combat，女仆专用资格位于 compat/maid，主题效果留在对应主题包。完整调用和边界见 [逐日与籠釣瓶](../../sun-chaser-kagotsurube.md)。
