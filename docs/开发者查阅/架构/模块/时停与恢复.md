# 时停与恢复

本章说明场域管理、豁免、主要更新桥接、任务恢复和服务器停止入口；其余时停 Mixin 见 [时停逐入口边界](../链路/时停逐入口边界.md)。完整流程见 [冻结与恢复](../链路/冻结与恢复.md)。

## 基础与玩法怎样分工

| 职责 | 源码 | 使用者与边界 |
|---|---|---|
| 玩法触发 | [StarVoiceState](../../../../src/main/java/com/thelongtravail/boundless/StarVoiceState.java) | 伤害接收/确认后检查装备、模式、间隔、冷却与概率，再请求创建场域 |
| 场域协调 | [TimeStopManager](../../../../src/main/java/com/thelongtravail/boundless/TimeStopManager.java) | 每个 ServerLevel 的场域、空间候选索引、重叠组、到期和冷却；直接依赖配置、女仆兼容与网络 |
| 关系判定 | [TimeStopExemptions](../../../../src/main/java/com/thelongtravail/boundless/TimeStopExemptions.java) | 释放时队友快照、查询时实体归属链、模式规则 |
| 外部查询 | [TimeStopApi](../../../../src/main/java/com/thelongtravail/api/TimeStopApi.java) | 实体/位置只读查询，允许 null；不提供创建或修改场域接口 |
| 实体计时补偿 | [FrozenEntityClock](../../../../src/main/java/com/thelongtravail/boundless/FrozenEntityClock.java) | 实体内时间戳去重；冻结生物仍递减受伤无敌计时，玩家另暂停两种状态计时 |
| 延迟任务与持久化 | [FrozenBlockTasks](../../../../src/main/java/com/thelongtravail/boundless/FrozenBlockTasks.java) | 方块/流体计划刻、流体边界、形状和邻居通知 |
| 方块事件持久化 | [FrozenBlockEvents](../../../../src/main/java/com/thelongtravail/boundless/FrozenBlockEvents.java) | 保存事件及关联阻挡位置，解冻后重新提交事件 |
| 恢复队列基础 | [IndexedFrozenQueue](../../../../src/main/java/com/thelongtravail/boundless/IndexedFrozenQueue.java)、[FrozenCoverage](../../../../src/main/java/com/thelongtravail/boundless/FrozenCoverage.java) | 按键合并、按区块筛选候选、稳定次序、异常保留；覆盖变化按场域 ID 集合比较 |
| 生命周期 | [BoundlessEvents](../../../../src/main/java/com/thelongtravail/boundless/BoundlessEvents.java) | 服务器刻、交互、登录、换维度及停止事件 |
| 展示状态同步 | [TimeStopSync](../../../../src/main/java/com/thelongtravail/network/TimeStopSync.java)、[TimeStopClient](../../../../src/main/java/com/thelongtravail/client/TimeStopClient.java) | 按玩家筛选附近场域、相同快照不重复发送、客户端按维度查询 |

队列和覆盖比较是可复用的内部支撑；Manager 是具体机制协调层。boundless 包同时包含这两类职责，分别承担共享支撑和具体玩法协调。

## 实际冻结入口

| 入口 | 行为与恢复方式 |
|---|---|
| [TimeStopWorldMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopWorldMixin.java) | 拦截实体/乘客 tick；继续逐个处理乘客以独立判定豁免；随机方块/流体 tick 直接跳过；方块事件转存 |
| [TimeStopPlayerMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopPlayerMixin.java) | 拦截 ServerPlayer 的 tick/doTick，调用去重后的冻结计时 |
| [TimeStopEntityMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopEntityMixin.java) | 冻结移动/转向/推挤，并裁剪进入场域的位移；投射物轨迹另有速度保护 |
| [TimeStopLevelMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopLevelMixin.java) | 跳过方块实体 tick；阻止破坏和放置，setBlock 保留 LanternLight.permitted 特例 |
| [TimeStopScheduledMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopScheduledMixin.java) | 调度及执行入口转存冻结计划刻；hasScheduledTick 包含已转存任务 |
| [TimeStopNeighborMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopNeighborMixin.java) | 将两种邻居通知及形状更新转存 |
| [TimeStopFluidMixin](../../../../src/main/java/com/thelongtravail/mixin/TimeStopFluidMixin.java) | 阻止冻结边界的流动并记录边界，解冻后重新安排源流体更新 |

这不是暂停整个维度时钟。随机 tick 和实体 tick 的跳过不会自动转换成事后逐刻补算；排队恢复只适用于显式转存的任务。连接输入、活塞、爆炸、漏斗、拾取合并、粒子和渲染还有独立 Mixin，逐项行为、返回值、豁免和恢复边界见 [时停逐入口边界](../链路/时停逐入口边界.md)；源码列表也可在 [源码归属](../索引/源码归属.md) 搜索 `TimeStop`。

## 豁免和重叠不能混淆

创建场域时保存不可变 allies 集合。玩家关系读取包括原版队伍与 FTB Teams；关系不可确认时 snapshot 返回空 Optional，创建请求失败。实体查询还检查 STAR_FREEZE 模式规则、实体 UUID 和最多 16 层且防环的主人链；它不是任意第三方随从关系的自动识别。

每个场域保留自己的 allies。实体只要落入一个对它不豁免的场域，就判定冻结；重叠组不会合并成全组共享豁免。位置查询按方块中心落在球内判断，不携带操作者身份，所以玩家豁免不等于场内方块自动豁免。

新场域与现有场域重叠时合并其组，继承最早组截止时间，并限制已有场域结束时间。组连接可以经多个场域传递；组成员锁定直到该组所有场域消失。源码没有在中间场域到期后重新拆分组的步骤。

## 数据所有权与保存边界

| 数据 | 存放位置 | 停止/恢复 |
|---|---|---|
| 场域、组、空间索引、离线冷却待交付表 | Manager 静态运行内存 | 停服时清场并完成组冷却，Stopped 清空；场域不写入 SavedData |
| 玩家冷却和判定间隔 | 玩家 persistentData | Clone 显式复制相关键；上线补交本进程离线冷却 |
| 延迟任务 | `travail_frozen_tasks` SavedData | 保存类型、位置、剩余延迟、优先级、次序及各类通知数据 |
| 方块事件 | `travail_frozen_events` SavedData | 保存事件参数和 gates，加载后等待满足恢复条件 |
| 客户端场域视图、最近发送快照 | 客户端状态 / TimeStopSync | 登录、退出、换维度会忘记相应发送缓存；客户端 clear 清除视图与维度 |

停服时释放已就绪任务；目标区块未加载的任务继续等待，由 SavedData 保存剩余记录。崩溃恢复以已落盘数据为准。

## 扩展与验证

第三方自主 tick、机器传输或脚本应在实际更新点调用 TimeStopApi，接入各自的更新路径。新增延迟类型时必须明确键、合并规则、加载条件、保存格式、恢复顺序及异常策略，不能只加入一个取消 tick 的注入。

回归关注点：不同豁免的重叠场域、边界投射物、嵌套乘客、区块卸载再加载、队列保存再读取、释放回调异常、停服残留任务，以及客户端换维度。
