# 工具、资源与构建

后续已补齐功能回归入口、进程防护、持续生命周期及原始发布 JAR 组合验证。当前范围见 [当前状态与验收边界](../维护/当前状态与验收边界.md)，完整运行命令见 [隔离回归说明](../../../../tools/structure-regression/README.md)。历史本机工具仍按各自范围管理，新增入口不代表所有 tools 已验收。

依据当前构建脚本、Git 跟踪清单、忽略规则及语言维护说明整理。

| 内容 | 维护入口 | 生成物或用途 |
|---|---|---|

| 构建装配 | [build.gradle](../../../../build.gradle)、[gradle](../../../../gradle) | 依赖、资源生成、检查、slim 与 jarJar 产物 |
| 架构人工章节 | [项目书入口](../README.md) | 职责、生命周期和维护路径；不会由索引生成器覆盖 |

## tools 的实际边界

当前 `git ls-files tools` 只有四个脚本，且 [.gitignore](../../../../.gitignore) 对它们显式放行：

| 脚本 | 用途 |
|---|---|
| [generate-language-files.cjs](../../../../tools/generate-language-files.cjs) | 生成标准语言资源；Gradle generateLanguageFiles 的入口 |
| [verify-language-files.cjs](../../../../tools/verify-language-files.cjs) | 语言源、键、参数等一致性校验 |
| [verify-locale.cjs](../../../../tools/verify-locale.cjs) | 指定语言/分组的专项检查 |
| [test-language-generation.cjs](../../../../tools/test-language-generation.cjs) | 无效输入与确定性生成测试 |

其他 tools 内容默认被忽略。当前可见大量 `*-smoke`、`*-client`、`*-resources`、`*.init.gradle` 和压力/历史验证资料，但命名不构成可运行性保证，也不证明测试已通过。它们可能需要本机模组、世界、资源或启动参数；普通源码构建不依赖整份本机 tools。

| 本机资料类型 | 已观察的例子 | 使用前核对 |
|---|---|---|
| 隔离机制验证 | boundless-smoke、rs-fluid-smoke、ledger-request-smoke | 源码入口、init 脚本、所需模组与断言范围 |
| 客户端观察 | reading-client、execution-client、catalog-jei-client | 窗口/渲染条件、截图与日志、是否仍匹配当前代码 |
| 配套资源/夹具 | *-resources、*-fixtures | 与哪个测试版本配套，是否被脚本改写 |
| 性能与故障注入 | combination-pressure、callback-fault-smoke | 负载、单位、异常注入范围；不能直接推算整合包 TPS |
| 归档与清理脚本 | archive-test-environment.py 等 | 实际目标和恢复方式；本章未执行任何归档动作 |

需要共享某项本机检查时，先梳理依赖、固定输入和输出位置，再迁入可跟踪路径并提供独立执行说明。不要仅解除整个 tools 的忽略规则，也不要因“未跟踪”就认为内容可删除。

## Gradle 职责分工

| 文件 | 装配责任 |
|---|---|
| [build.gradle](../../../../build.gradle) | Java 17 编译目标、Forge/Curios、MixinExtras 内嵌、资源与 Mixin、jar 与 jarJar |
| [language.gradle](../../../../gradle/language.gradle) | 语言源输入/生成目录、processResources 前置、check 的语言生成测试 |
| [config-checks.gradle](../../../../gradle/config-checks.gradle) | 配置布局、恢复、诊断、各类预设及组合测试接入 check |
| [compat-checks.gradle](../../../../gradle/compat-checks.gradle) | testOptionalCompatibility；可传 compatTestJars 指定目标 JAR |
| [optional-compat.gradle](../../../../gradle/optional-compat.gradle) | 可选 API compileOnly 依赖；maidApiJar 本地替代参数与 build/optional-api 缓存 |

可选 API 用于编译，不因此自动进入开发运行环境或成品。Curios 是必需依赖，MixinExtras 通过 jarJar 内嵌。JavaExec 测试与真实 Forge 启动是不同层次：check 没有自动把所有 tools 下的历史客户端测试全部执行。

## 语言与资源流水线

五种语言各有 11 个分组，以 zh_cn 的键及顺序为基准。分组源 → generateLanguageFiles → build/generated/resources/language → processResources → 打包。sourceSets.main.resources 加入生成目录，重复资源采用 FAIL；不要在 resources/assets 中再放一份同名语言文件。

详细规则与命令保持在 [语言维护说明](../../../../src/main/lang/README.md)。项目书只解释它在构建中的位置，不复制全部格式规则。构建输出覆盖不了手工源修改，修正应回到维护源。
