# 联动源码归属

独立可选联动位于compat；第三方专用规则由适配类提供，玩法与配置调用方保留自身流程。Curios是核心必需依赖，装备接入仍归公共装备层。

## 专用规则与调用方

| 联动入口 | 职责 | 调用方 |
|---|---|---|
| compat/arsnouveau/ArsNouveauAttributeRules | 提供磷叶石固定属性排除集 | valley/Phosphophyllite 合并用户配置，并在两个处理阶段共用 |
| compat/dummmmmmy/DummySoulRules | 按实体类型的 dummmmmmy 命名空间判断收魂排除 | underworld/SoulBannerKills 在解析击杀来源前调用 |
| compat/mixin/maid/UnderworldMaidAttackMixin | 桥接原版 Mob.doHurtTarget 的类型判定 | 兼容 Mixin 清单注册；插件始终允许，MaidAccessories.seesUndead 决定是否生效 |

## 核心调用与适配职责

| 范围 | 归属说明 |
|---|---|
| config/defaults 下七个 *CompatDefaults | Biome、Structure、Reward、FishingEntity、Effect、GoldenAge、PerfectFluid 的配置汇总器负责默认池装配、初始化标记和配置写入；具体第三方条目由 compat/CompatPresets 集中装配，汇总器通过构造工厂接收预设，配置生命周期仍由汇总器管理 |
| mixin/anvil/AnvilLevelLimitMixin、AnvilScreenMixin 等 | 实现 TLT 对原版铁砧的行为；神化冲突检测与启用决策位于 compat/apotheosis/AnvilCompatPlugin |
| client/diary/DiaryFontEffects、item/NameColoring | 消费和清理 TLT 的 Apotheosis 名称样式标记；标记 ID 保持固定，第三方名称适配在 compat/apotheosis 与 compat/mixin/apotheosis |
| 主题、战斗、事件、客户端中调用 integration/MaidIntegration 的代码 | 主体接入层提供装备、战斗与生命周期接口及缺席默认行为；CompatBootstrap 安装女仆提供者，调用方保持原有流程 |
| farreach/GoldenAgePools：defaultFoodLookup | 反射检查原版/Forge 食物查询声明，保留完整 ItemStack 查询的通用兼容语义；不是某个可选模组的独立适配类 |

## 适配目录与注册

- compat/fluid 集中 AE2、RS、精妙背包、BeyondDimensions 等库存适配、识别与装配；abyss/copy 管理复制图、事务、领取与失败处理。旧 compat/fluid 复制入口转发至主体实现。移除具体实现时保留识别登记，将实现置空，使对应格式停止复制；主体调用路径保持不变。
- compat/maid 与 compat/maidspell 集中女仆接口、饰品运行、账本、战斗反馈、存储和扩展适配。
- JEI、Jade、FTB Teams、Caelus、神化、墓碑、Sounds、Quark 等适配及各模组默认条目位于 compat 对应路径。
- mixins.the_long_travail.compat.json 的 package 为 com.thelongtravail.compat.mixin，所列Mixin位于该路径，由 OptionalCompatPlugin 管理；女仆攻击桥接的运行时判定见上表。

## 女仆接入与装配

`integration/MaidIntegration` 保留无女仆时的空查询、原伤害、原药效、实体身份及玩家 PVP 判断。`compat/maid/MaidIntegrationProvider` 转发到适配门面，`compat/CompatBootstrap` 在模组存在时安装提供者并注册事件。客户端 ThemeTooltips 通过 `compat/CompatTooltips` 调用 `compat/maid/MaidTooltipSupport` 识别提示键；识别器只使用 Minecraft 文本类型，可在模组缺席时处理已构造的文本。追加提示位于 `compat/maid/client`。

移除女仆实现时，同时移除 CompatBootstrap 的安装分支、CompatPresets 的女仆预设登记和兼容 Mixin 清单的女仆项，将 CompatTooltips 的识别入口改为返回 false；主体接入层及默认实现保留。API 编译依赖仅在所有使用者移除后删除。配置与存档中的既有条目不自动清除。

## 主体保留的适配入口

以下入口以 Minecraft、Forge 或 JDK 类型与主体交互。具体第三方 API 和条目规则集中在对应适配目录。

| 入口 | 主体调用位置 | 缺席行为 |
| --- | --- | --- |
| ftbteams/FtbTeamsCompat | 时停豁免、洛伦兹幻想、剑与灯 | 返回不同队伍及空成员集合；查询失败单独返回不可用状态 |
| ftbultimine/TremorUltimine | 高频战栗交互 | 未安装时返回未接管，继续原有处理 |
| caelus/IcarusCaelusCompat | 伊卡洛斯飞行资格 | Gate 未启用时不施加 Caelus 的 DENY |
| quark/DiaryRunes | 日记附魔光效 | 未安装时返回 false，内部 Access 隔离第三方类 |
| attributeslib/PercentAttributes | 属性注册 | 创建原版 RangedAttribute |
| gravestone/GravestoneStorage | 冥府存储对账 | Gate 未启用时跳过墓碑处理，玩家与掉落物对账继续执行 |
| arsnouveau/ArsNouveauAttributeRules | 磷叶石 | 只提供字符串属性排除集，不加载第三方类 |
| dummmmmmy/DummySoulRules | 摄魂幡 | 只比较实体命名空间 |
| sounds/EffectSounds | 客户端 setup、tick、退出 | 维护本地声音策略；Sounds 注入由独立目标契约控制 |
| CompatBootstrap、CompatPresets、CompatTooltips | 启动、配置汇总、提示分类 | 集中装配实现和预设，保持主体调用入口 |

移除第三方模组 JAR 时，保留这些适配入口及缺席分支。移除适配源码时，保留主体所调用的入口并替换为对应缺席行为，再删除内部实现、注册与编译依赖；纯预设类从 CompatPresets 撤销登记后移除。

## 增删联动的配套位置

1. 实现与默认条目放入 `compat/<来源>`，库存适配放入 `compat/fluid`；共享主体规则放在已有领域接口中。
2. 按接入方式登记：启动提供者使用 CompatBootstrap，默认条目使用 CompatPresets，第三方自主发现的客户端插件使用 JEI/Jade 对应入口。
3. 第三方 Mixin 放入 `compat/mixin/<来源>`，同步兼容清单和 OptionalCompatPlugin；共同作用于多个模组的规则保留各自门禁。
4. 声明编译依赖并检查调用签名、类加载端及缺席行为。运行必需依赖仍为 Forge、Minecraft 和 Curios。
5. 数据资源新增第三方 ID 时提供对应加载条件；移除适配时核对资源、预设标记、语言键及文档引用。已写入用户配置或存档的条目由用户配置生命周期管理。

结构检查器固定主体可调用的适配入口，检查未登记的内部实现引用、外部 API import、适配类缺失及 Mixin 注册路径。边界检查与反例入口见[静态检查工具](../../../../tools/structure-regression/README.md)。

## 后续维护

新增可选模组专用判断、反射/API 调用和条目表优先放入 compat；调用方保留玩法流程、配置生命周期和显示职责。迁移 Mixin 时检查完整类名、两份注册文件、插件选择条件、端侧和无可选依赖时的行为。
