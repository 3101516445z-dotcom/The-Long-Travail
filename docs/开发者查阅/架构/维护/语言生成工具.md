# 语言生成工具

[test-language-generation.cjs](../../../../tools/test-language-generation.cjs) 接入 [language.gradle](../../../../gradle/language.gradle) 的check，用独立夹具检查语言生成器。

## 依赖、输入与输出

只依赖 Node.js 内置 assert/fs/path，以及相邻的 generate-language-files.cjs、verify-language-files.cjs；无 npm 安装、Minecraft、Forge、JDK 或第三方 JAR 依赖。测试自行生成五语言、两分组的夹具，不读取用户实际语言文件。

路径以 __dirname 为基准，临时目录在脚本上级 build/tmp/language-tests/case-*，finally 核对父目录后删除本次 case。只创建隔离夹具和语言生成输出，不修改 src/main/lang 或正式生成目录。实际语言源使用 verify-language-files.cjs 检查。

## 运行与检查范围

用例覆盖：重复生成字节及 mtime 稳定、同文件与跨组重复键、非法 JSON/非文本/空文本、语言分组键顺序、格式占位符参数、附加语言颜色码、重复/越界分组名、缺失/未登记文件，以及失败生成不覆盖已有输出。

重现方法：保留 tools/ 下这三个相邻脚本，在任意 cwd 用 node 指向 test-language-generation.cjs。标准仓库命令为：

```text
node tools/test-language-generation.cjs
```

脚本退出码为 0 时完成检查；Generated 为中间的生成提示。
