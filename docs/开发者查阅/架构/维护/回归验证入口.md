# 回归验证入口

按改动选择检查，使用仓库中的共享工具与隔离运行目录。测试的输入、依赖和运行方式以对应工具README为准。

| 改动 | 入口 | 检查内容 |
|---|---|---|
| 普通源码、资源与配置 | 根目录Gradle Wrapper的build、jarJar | 编译、构建接入检查与正式打包 |
| Forge 事件订阅类或方法 | `gradlew.bat verifyEventSubscriberNames` | 扫描编译类，检查 EventBus 6.2.33 的代理名称冲突；同时接入 `check` |
| 语言源与生成器 | [语言工具](语言生成工具.md) | 键集合、顺序、参数及生成错误处理 |
| 架构文档 | [项目书维护](README.md) | 索引指纹、本地链接与标题锚点 |

## 验证层次

EventBus 6.2.33 按包名、订阅类简单名、方法名和事件简单名生成代理名称。内部类的外层类名不参与命名，同包内部订阅类应使用明确且唯一的名称。[事件订阅检查器](../../../../tools/structure-regression/EventSubscriberNames.java)读取编译类的注解与签名，任务定义位于[构建检查](../../../../gradle/event-subscriber-checks.gradle)。

静态检查确认资源和结构约束；隔离服务端检查机制与生命周期；客户端检查显示、交互和同步；整包检查实际模组组合。
