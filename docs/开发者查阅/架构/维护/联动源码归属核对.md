# 联动源码归属核对

核对日期：2026-10-25。范围：当前 src/main/java 的 556 个 Java 文件、两份 Mixin 注册配置及构建依赖声明。本页记录当前联动归属；本次整理与验证范围见 [结构优化实施记录](结构优化实施记录.md)。

## 结论

独立联动实现集中于 compat，当前有 111 个 Java 文件。第三方专用规则由适配类提供，玩法与配置调用方保留自身流程。Curios 属于核心必需依赖，其装备接入不纳入可选联动归属范围。

核对覆盖主源码文件清单、外部 import、加载检测、反射入口、第三方字符串/命名空间、compat 引用及 Mixin 注册。这是静态归属检查，不是完整语义调用图或所有动态兼容行为的证明。

## 留在原路径有明确职责依据的代码

| 范围 | 归属说明 |
|---|---|
| config 下七个 *CompatDefaults | Biome、Structure、Reward、FishingEntity、Effect、GoldenAge、PerfectFluid 的配置汇总器负责默认池装配、初始化标记和配置写入；具体第三方条目已通过 compat 中的提供者接入。名称包含 Compat 不意味着整个类都应迁移 |
| mixin/AnvilLevelLimitMixin、AnvilScreenMixin 等 | 实现 TLT 对原版铁砧的行为；神化冲突检测与启用决策位于 compat/apotheosis/AnvilCompatPlugin，保留当前分工合理 |
| client/DiaryFontEffects | 消费 Apotheosis 名称样式标记，属于渲染侧协议接点；第三方名称适配在 compat/apotheosis 与 compat/mixin/apotheosis。若进一步集中，可抽取标记常量，不应迁移整个渲染器 |
| 主题、战斗、事件、客户端中调用 MaidAccessories 等适配入口的代码 | 调用联动门面不等于自行实现外部 API 适配；玩法协调仍属于调用方 |
| farreach/GoldenAgePools：defaultFoodLookup | 反射检查原版/Forge 食物查询声明，保留完整 ItemStack 查询的通用兼容语义；不是某个可选模组的独立适配类 |

## 已集中范围与注册核对

- compat/fluid 集中 AE2、RS、精妙背包、BeyondDimensions 等库存适配，以及复制图、事务与失败处理；其按业务域分组，不是一模组一目录。
- compat/maid 与 compat/maidspell 集中女仆接口、饰品运行、账本、战斗反馈、存储和扩展适配。
- JEI、Jade、FTB Teams、Caelus、神化、墓碑、Sounds、Quark 等适配及各模组默认条目位于 compat 对应路径。
- mixins.the_long_travail.compat.json 的 package 为 com.thelongtravail.compat.mixin，列出的 15 个 Mixin 均位于该路径，由 OptionalCompatPlugin 管理；女仆攻击桥接的运行时判定见上表。
- compat 之外的外部 import 扫描未发现其他可选模组 API 的直接导入；存在 Curios、Forge/ModLauncher、MixinExtras 等必需依赖和基础设施引用。此结论不等同于不存在字符串或间接联动，相关例外已在上表列明。

## 后续维护

新增可选模组专用判断、反射/API 调用和条目表优先放入 compat；调用方保留玩法流程、配置生命周期和显示职责。迁移 Mixin 时检查完整类名、两份注册文件、插件选择条件、端侧和无可选依赖时的行为。
