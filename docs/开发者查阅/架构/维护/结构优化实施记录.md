目标：基础能力可复用、玩法资格判断有明确归属、事件入口与业务维护分离。每轮通过隔离服务端检查后才修改下一轮源码。

## 已实施

1. common.TickDurations：分离向上取整非负、向上取整有符号、四舍五入至少一 tick 三种策略。RainConfig、FlourishingItemsConfig、TravailEffectActions 保留原入口；Boundless/FarReach 配置不再借用 RainConfig 作时间工具。包括 NaN、无穷及溢出的历史行为保持原样。
2. event.JourneyRuntimeMaintenance：集中旅程提交后维护、完整重置及连接缓存清理。JourneyService 直接调用，TravailEvents 保留事件适配和旧静态入口转发。方法体和语句次序与提取前一致。协调类仍在 event 包以复用包内维护工具；尚未完成包级重排。
3. helper.CurioLookup：只负责当前 Curios 背包的非外观槽查询。AccessoryEquipRules 保留恢复快照分支；BoundlessEquipment 保留日记依赖及逍遥游槽位规则；FarReachEquipment 保留存活/旁观者条件。
