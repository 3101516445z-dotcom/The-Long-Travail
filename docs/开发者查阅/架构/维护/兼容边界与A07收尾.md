# 兼容机制与生命周期

可选联动通过模组存在检查、API 访问门禁和 Mixin 契约检查接入。各功能的输入、状态及清理由对应适配层负责，加载条件与运行行为分别查阅。

## 女仆职责分工

| 职责 | 当前归属 |
|---|---|
| 可选模组门禁 | MaidAccessories |
| 装备、在线主人和身份基础访问 | MaidAccess |
| 阶段、装备资格、canHarm | MaidAccessoryRules |
| 增伤、免疫、减伤与攻击来源 | [MaidCombatCalculations](../../../../src/main/java/com/thelongtravail/compat/maid/MaidCombatCalculations.java) |
| 受击、命中、反击及药效反馈 | [MaidCombatFeedback](../../../../src/main/java/com/thelongtravail/compat/maid/MaidCombatFeedback.java) |
| 属性、治疗及冷却逐 tick 维护 | [MaidPeriodicEffects](../../../../src/main/java/com/thelongtravail/compat/maid/MaidPeriodicEffects.java) |
| 临时状态、延迟任务、换主/卸装失效、移除与停服清理 | [MaidRuntimeState](../../../../src/main/java/com/thelongtravail/compat/maid/MaidRuntimeState.java) |
| END tick 顺序与队列调度 | [MaidRuntimeMaintenance](../../../../src/main/java/com/thelongtravail/compat/maid/MaidRuntimeMaintenance.java) |
| 持久冷却账本 | MaidAccessoryLedger |
| Forge 事件适配及旧公开入口转发 | MaidAccessoryRuntime |


MaidAccess 提供装备、在线主人与实体身份访问；MaidAccessoryRules 组合阶段和生效资格。MaidAccessoryRuntime 注册 Forge 事件并保留公开转发入口。MaidRuntimeMaintenance 从 MaidRuntimeState 获取实体快照，依次刷新、执行 MaidPeriodicEffects，再排空本次队列；MaidRuntimeState 不依赖 MaidPeriodicEffects。

Phase 使用 MaidAccessoryRuntime.Phase 枚举。多数阶段查询取主人的日记状态；phosphophyllitePhase 还要求有效装备。实际装备来自女仆槽位，已死亡或移除的女仆返回空，主人限定在线且连接有效的 ServerPlayer。

## 饰品登记与状态

MaidAccessories.items 当前明确登记 15 项：spring_corner、everlasting_flower、eki、tokaido、midnight_lafite、icarus、don_quixote、azrael、sword_and_lantern、phosphophyllite、a_thousand_years_later、demon_king_of_the_sixth_heaven、myriad_souls_banner、star_voice、lorentz_fantasy。

其余 11 项 immortal_bud、liquefied_abundance、affection、mistletoe、perfect_fluid、golden_age、tower_of_babel、underground_velvet、book_of_the_dead、free_and_easy_wandering、little_prince 未在该饰品绑定列表中。所有权交互、对实体的被动影响和容器作用由各自机制处理。


实体身份保存在 `TravailMaidIdentity`，仅在缺失时生成。MaidAccessoryLedger 在主世界 SavedData `travail_maid_accessories` 中保存持久状态；星之声冷却使用女仆身份。

换装时按饰品清理状态：堂吉诃德忘记攻击状态，死告天使取消 armed 并增加 generation，剑与灯清战斗状态，无穷花卸下取消旧追加链。冻结判断前仍执行属性对账及剑与灯清理，之后才进入相应治疗与冷却处理。

MaidBaubleSync 保存受监视女仆的快照并发送变化；StartTracking 发送初始变化并建立监视。移除与停服清运行状态，持久账本由 SavedData 保存。

## 可选加载与注入

实现入口为 [OptionalCompatPlugin](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatPlugin.java)、[OptionalCompatState](../../../../src/main/java/com/thelongtravail/compat/OptionalCompatState.java) 和 [兼容 Mixin 清单](../../../../src/main/resources/mixins.the_long_travail.compat.json)。请求和加载流程见 [输入请求与可选加载](../链路/输入请求与可选加载.md)。

| 分支 | 加载条件 | 运行时关注点 |
|---|---|---|
| 神化名称、Quark 日记符文 | 按对应模组 ID 存在判断 | 目标版本方法语义及注入成功 |
| 假人伤害 | 目标方法签名及 totalDamageTakenInCombat 的指定写入次数为 1 | 第三方全部伤害路径、显示/实际统计一致 |
| 女仆性格存储 | stamp/buildRequest/resolveRelease/superviseHealthFix 四个静态方法契约 | 动态生命恢复与其他插件写入竞争 |
| MaidSwim/MaidRelicSlot | 检查目标类可读；缺类不加载，IOException 抛 IllegalStateException | 完整 API 版本匹配；异常不是统一静默降级 |
| Gravestone、Caelus | 共享 Gate 检测并缓存状态，检查器见 OptionalCompatChecks | 墓碑插件的私有存储和实际飞行/复活行为 |
| Embeddium 灯光 | calculate 的特定描述符存在 | 渲染正确、光照无残留、性能收益 |
| JEI 覆盖层 | 指定绘制方法名称和 void 返回特征 | 所有参数/内部绘制布局兼容，或配方数据正确 |
| Sounds | 字段、方法及指定指令布局联合检查并缓存 | 所有声音路径在不同插件组合中的行为 |

Gate 由 UNCHECKED 转为 ABSENT/ENABLED/DISABLED，之后复用结果；不因一般配置热重载重新探测。Gate 捕获缺类、IO 和 LinkageError 后禁用，与其他独立分支的异常策略不同。清单 required=true、defaultRequire=1，已放行的注入仍受 required 与 defaultRequire 约束，目标失配可能导致加载失败。


Curios 是必需依赖。运行声明见 [mods.toml](../../../../src/main/resources/META-INF/mods.toml)，编译期 API 见 [optional-compat.gradle](../../../../gradle/optional-compat.gradle)。移动兼容类时同步 package、Mixin 注册、构建与入口文档。

## 回归入口

使用 [结构回归工具](../../../../tools/structure-regression/README.md) 的 config、combat、maid 选择功能检查，restart 使用两个专用服务端进程检查同一存档；maid-social 覆盖所配置的爱恋与性格组合。

重点场景包括主人离线与重连、阶段切换、穿脱与区块重载、重复身份、星之声组冷却、死告天使排队后换装、无穷花卸下、剑与灯追踪，以及目标模组升级后的调用路径。具体版本、结果和待验收项见 [验证状态](当前状态与验收边界.md)。结构演变与各轮测试记录保留在 [实施记录](结构优化实施记录.md) 和 [历史工作包](历史记录/首轮交叉核对与工作包记录.md)。
