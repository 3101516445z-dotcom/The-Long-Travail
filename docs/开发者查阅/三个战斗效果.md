# 三个战斗效果的接入

[EffectCombatRules](../../src/main/java/com/thelongtravail/combat/EffectCombatRules.java) 从原始 DamageSource 解析 LivingEntity 主体，并使用女仆归属门面补充。召唤物不自动继承主人的效果。

## 伤害与生命写入

`DamageScope` 先处理“我于万物之中”的双向伤害阻断，再将“波旬变生”的来源转为直击。波旬的 0.5 加入输出增伤池，“还魂”的 0.01 作为独立输出倍率；已结算重放保留原金额。已有 CombatContext 时不再次乘算；LivingAttackEvent、LivingHurtEvent 对外部单独发布的事件提供相应处理。

`CombatEffectHealthMixin` 按实体维护 20 tick 周期，刷新效果保留计数，移除效果清除计数。`HealthLoss.nonlethalFraction` 在服务端对存活目标扣除 `min(最大生命 × 比例, 当前生命 − 1)`，最低保留 1 点，并跳过“我于万物之中”。该写入不经过 hurt、吸收、伤害倍率或攻击收益。

普通 setHealth 下降受和平效果保护；构造、存档读取和合法最大生命夹取分别处理。GENERIC_KILL 是否放行由配置控制，命令与代码调用使用同一规则；生命写入例外只作用于当前伤害上下文的目标。

女仆经 `MaidIntegration` 转交 `MaidSpellHealth.applyNonlethalEffectLoss`。返回 true 表示已接管，包括拒绝无效请求；只有 false 才回到普通生命写入。

## 仇恨与移动

和平保护通过 `BabelProtection`、目标设置和 Brain 记忆入口清理受保护目标及对应记忆，监守者愤怒另行处理。修改 Brain 初始化的 AI 模组应在 Brain 有效后绑定所属实体；调用时可能仍处于 LivingEntity 构造阶段。

`RevivalMovement` 缩放自主推进，鞘翅、玩家垂直飞行和恶魂自定义 MoveControl 各有入口。鞘翅按原版滑翔计算分离已知外部推力，保留推挤、击退和爆炸速度。自定义移动控制应区分自主速度与外力，避免重复缩放。
