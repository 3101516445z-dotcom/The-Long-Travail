# 三个战斗效果的共用入口

`EffectCombatRules` 从原始 `DamageSource` 解析实际 LivingEntity 主体，再使用已有女仆归属补充。效果不依赖玩家专用的 `CombatContext.attacker`，也不自动让召唤物继承主人的效果。

伤害在 `DamageScope` 进入时先检查双向禁止，再复用 `DamageIdentity.convert` 转为直击。波旬的 0.5 加入原有增伤池，还魂的 0.01 在输出增幅之后独立计算；重放复用既有结算金额。`LivingAttackEvent`、`LivingHurtEvent` 为绕过常规 hurt 的外部入口提供拦截。已经存在 `CombatContext` 时不会再次乘算。

`CombatEffectHealthMixin` 按实体保存 20 tick 周期，刷新保留计数，移除清除计数。`HealthLoss` 独立计算非致死损失，并保护和平实体的 `setHealth` 下降。构造、读取存档与合法最大生命夹取单独处理。女仆法术的生命写入保护通过 `MaidSpellHealth.applyNonlethalEffectLoss` 接入；只有有效、非致死且未被和平保护禁止的预计算损失能够写入。

kill 开关统一控制 GENERIC_KILL，包括命令和代码调用的标准 kill。生命写入复用 CombatContext 当前目标和原伤害来源判定；普通 SH 仍受保护。

仇恨保护沿用 `BabelProtection`、目标设置与 Brain 记忆过滤，只清理受保护目标及对应记忆，保留实体的原有 AI 和生成流程。`BabelLivingMixin` 在构造及 getBrain 返回处检查空值：AI 优化模组可能在 LivingEntity 完成 Brain 初始化之前调用 getBrain，必须等待有效 Brain 才绑定所属实体。监守者的独立愤怒记录另外清理。

移动通过 `RevivalMovement` 共享倍率。相对移动只缩放自主推进量；鞘翅和玩家垂直飞行复用已有无垠恶意注入位置。恶魂自定义 MoveControl 的推进另行覆盖。鞘翅按原版滑翔计算分离已知外部推力，保留推挤、击退以及服务端和客户端爆炸产生的速度变化。
