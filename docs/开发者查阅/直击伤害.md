# 直击伤害

伤害类型：`the_long_travail:direct_strike`，中文名称为“直击伤害”。类型通过数据包 JSON 加载。

`DirectStrikeDamage.TYPE` 提供注册键，`DirectStrikeDamage.source(level, directEntity, causingEntity)` 从当前世界的注册表创建伤害来源。近战时两个实体参数均传攻击者，间接攻击分别传投射物和攻击者，无来源伤害均传 null。调用方在服务端使用 `target.hurt(source, amount)` 造成伤害。`level` 传目标所在世界，实体参数可为 `null`。

类型设置为 `scaling: never`、`exhaustion: 0.0`，不随难度缩放，也不额外增加饥饿消耗。`damage_type.the_long_travail.direct_strike` 为供界面使用的名称翻译键，原版死亡消息使用独立的 `death.attack.*` 键。

洛伦兹幻想见证的追加伤害使用此类型，金额为命中前目标当前生命的配置比例。私有来源身份使其不重复享受普通增伤与必杀，并保留原有追加链分派。配置键 `items.boundless.lorentz.voidRatio` 沿用已有名称，表示当前直击比例。

## 防御边界

直接加入 `minecraft:bypasses_armor`、`minecraft:bypasses_enchantments`、`minecraft:bypasses_resistance`、`minecraft:bypasses_cooldown` 四个标签。Minecraft 1.20.1 的 `bypasses_shield` 包含 `#minecraft:bypasses_armor`，因此同时绕过盾牌。

黄心正常抵扣；创造模式默认免疫；致死时仍可触发原版图腾。Forge 事件、TLT 战斗属性和其他模组独立防御仍按各自逻辑处理。

## 与原版伤害对比

以下对比 Minecraft 1.20.1 / Forge 47.4.10 默认规则。

| 机制 | 直击伤害 | 虚空 out_of_world | generic_kill |
| --- | --- | --- | --- |
| 护甲及韧性 | 绕过 | 绕过 | 绕过 |
| 原版保护类附魔 | 绕过 | 绕过 | 绕过 |
| 抗性提升 | 绕过 | 绕过 | 绕过 |
| 盾牌 | 绕过 | 绕过 | 绕过 |
| 受伤无敌帧 | 绕过 | 不绕过 | 不绕过 |
| 黄心 | 正常抵扣 | 正常抵扣 | 正常抵扣 |
| 创造模式无敌 | 保留 | 绕过 | 绕过 |
| 原版图腾救命 | 保留 | 阻止 | 阻止 |

虚空与 generic_kill 没有加入 `bypasses_enchantments`；原版 `ProtectionEnchantment.getDamageProtection()` 遇到 `bypasses_invulnerability` 会返回 0，因此原版保护类附魔无效。直击伤害直接跳过附魔减伤计算。通过伤害事件实现的附魔效果由对应事件处理器决定。

`/kill` 对 LivingEntity 调用 `kill()`，后者使用 generic_kill 类型、以 `Float.MAX_VALUE` 作为伤害量调用 `hurt()`。该伤害仍经过黄心抵扣与受伤冷却判断。直接使用 generic_kill 时，伤害量由调用方传入。

## 调用示例

```java
DamageSource source = DirectStrikeDamage.source(target.level(), attacker, attacker);
target.hurt(source, 6.0F);
```

命令调用：`/damage <目标> 6 the_long_travail:direct_strike`，造成 6 点无来源直击伤害。
