# 可选依赖接入

苦旅的模组 ID 为 `the_long_travail`。状态查询、外部库存和饰品规则使用下列入口。

| 接入任务 | 入口 |
| --- | --- |
| 查询恶意、见证或时停，写入旅程 | [状态与旅程 API](state-api.md) |
| 让外部库存参与携带判定 | [携带 API](carrying-api.md) |
| 新增有前置条件的饰品 | [饰品佩戴与恢复](accessory-equipment.md) |
| 读取注册项、处理网络与配置重载 | [运行时接入](runtime-integration.md) |

内置模组联动及适用版本见[可选联动](../../README.md#可选联动)。

## 依赖与加载隔离

在调用方的 `mods.toml` 中声明对 `the_long_travail` 的依赖，并按功能需要设置为必需或可选。依赖范围以实际使用的 API 为准；编译时使用包含这些入口的苦旅构建，运行时另行安装。

若依赖可选，应先确认苦旅已加载，再进入引用苦旅类型的实现类。该实现的字段、方法签名和静态初始化同样需要隔离，避免苦旅缺席时提前解析类型。仅服务端可用的入口由逻辑服务端调用，客户端显示使用对应同步状态。

## 注册与状态更新

携带检测器在初始化时单线程注册唯一来源 ID，读取当前真实库存，不保留玩家或物品栈引用。重复注册、运行时来源故障和未知携带结果的处理见[携带 API](carrying-api.md#外部库存检测器)。

延迟旅程写入保存发起时的主题身份，并在执行时交由 `TravailJourneyApi` 校验。饰品卸装和前置失效时只撤销调用方自身的属性与状态，使用[饰品恢复入口](accessory-equipment.md#前置失效与卸装)协调返还。
