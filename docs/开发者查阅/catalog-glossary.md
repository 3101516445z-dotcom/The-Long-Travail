# 拾遗术语解释

拾遗详情页支持直击伤害、处决、见切、必杀和霸主的悬浮解释。正文中每种术语首次出现的位置带下划线，鼠标移到该词上即可查看解释；移开后关闭。

同页后续出现不重复标记，段落及滚动不会重置首次位置。“直击伤害”使用统一词条，不再识别简称。小窗采用灰褐底、低饱和铜色细边框与米灰色文字。

实现：CatalogGlossary 在现有正文染色之后保留样式并添加首次术语标记，CatalogDetailScreen 按最终换行后的文字进行命中检测。术语名、别名和解释维护于五语言 catalog.json 的 glossary 条目。返回、退出、正文滚动保持原有行为。

下划线独立于字体绘制：关闭原版逐字下划线，每段连续术语只画一次，按最终GUI变换保持一个帧缓冲像素厚度，使用70%透明度的低亮铜色。线条与字底留出间距，悬浮命中仍依据文字样式标记。
