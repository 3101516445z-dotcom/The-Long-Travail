# 液化丰饶接入

## 效果与药水数据

[AbundanceEffectPool](../../src/main/java/com/thelongtravail/abyss/abundance/AbundanceEffectPool.java) 从 Forge 效果和药水注册表构建不可变池，在服务端启动和配置重载时重建。按效果、去重等级、去重时长三级抽样，重复样本不增加权重。

空白名单使用全部合格效果，非空白名单限制为有效条目，黑名单优先。非空白名单全部无效时为空池。普通效果没有药水样本时使用配置回退时长；自身回调异常时排除该效果。扩展模组需先完成效果与药水注册，使重建能读取样本。

产物使用原版普通、喷溅和滞留药水，`CustomPotionEffects` 保存单个效果，整数来源标记 `the_long_travail:liquefied_abundance` 为 1。基础 Potion 为空；读取内容时使用自定义效果数据。

带来源标记的滞留药水在 `ThrownPotion.makeAreaOfEffectCloud` 添加效果时，将非瞬时、非无限时长除以四；瓶内保留完整时长。覆盖药水云生成的模组需协调这一换算，避免重复缩短。

## 配方与酿造

[当前配方](../../src/main/resources/data/the_long_travail/recipes/liquefied_abundance.json) 消耗紫水晶碎片、牛奶桶、下界疣及六个玻璃瓶，产出六份液化丰饶。牛奶桶按原版规则返还空桶。

序列化器 `the_long_travail:liquefied_abundance` 继承原版无序配方格式。数据包若在该类型配方中加入蜂蜜瓶，[LiquefiedAbundanceRecipe](../../src/main/java/com/thelongtravail/abyss/abundance/LiquefiedAbundanceRecipe.java) 会消费其容器，不返还玻璃瓶；当前内置配方不含蜂蜜瓶。

[ModBrewing](../../src/main/java/com/thelongtravail/registry/ModBrewing.java) 在 common setup 注册标准 Forge `BrewingRecipe`：瓶位为龙息，材料为紫水晶碎片，产出液化丰饶。物品注册关闭时不登记酿造，展示模组可读取该标准配方。

## 使用会话

`item/LiquefiedAbundanceItem` 使用原版开始、松开和完成使用入口。`abyss/abundance/LiquefiedAbundance` 保存实际物品引用、使用手、起始类型和总刻数，结算前移除会话，同一会话只交付一次。

玩家持久 NBT `the_long_travail:abundance_mode` 的 0、1、2 表示普通、喷溅、滞留。Clone 复制，登录、重生、换维度及切换类型时同步。类型以服务端为准，取消包只取消发送者自己的会话。

使用不超过 5 tick 时松开切换类型，超过 5 tick 且未完成时取消；最短蓄力 10 tick。完成时按起始类型交付。配置重载取消会话，再重建和同步有效配置；空池或药水准备失败均保留原料。

客户端进度提示占用 Action Bar，其他消息覆盖时让位，清除时检查组件身份。替换输入或 HUD 的模组应保留取消与完成调用，避免持续按键重复启动会话。协议见[网络匹配](runtime-integration.md#注册与网络匹配)。
