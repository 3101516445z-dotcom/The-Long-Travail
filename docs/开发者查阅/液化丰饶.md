# 液化丰饶实现入口

`item/LiquefiedAbundanceItem` 使用原版 `startUsingItem`、`releaseUsing`、`finishUsingItem`，手持动作使用 `UseAnim.BOW`，实际蓄满进度由游戏刻计时驱动。`abyss/LiquefiedAbundance` 管理服务端会话，保存实际物品引用、使用手、开始时的类型和总刻数，结算前移除会话以保证同一次使用只交付一次。

`abyss/AbundanceEffectPool` 从 Forge 状态效果注册表及药水注册表构建不可变列表，按效果、去重等级、去重时间三级抽样。服务器启动和配置重载重建，使用时不扫描注册表；服务端停止释放缓存。黑名单接受未安装模组的效果 ID，保留配置并记录诊断。

产物为原版三类药水，使用 `CustomPotionEffects` 保存单个效果，`the_long_travail:liquefied_abundance=1` 标记来源。基础 Potion 为空，名称由可翻译组件提供，颜色由原版效果派生。生存模式由 `ItemUtils.createFilledResult(..., false)` 负责消耗、替换、入包及掉落；创造模式复用 `common/ItemDelivery.give` 交付并保留原料，避免原版 `Inventory.add` 将创造模式满包的溢出物品丢弃。

`AbundanceLingeringPotionMixin` 仅包装 `ThrownPotion.makeAreaOfEffectCloud` 内的 `AreaEffectCloud.addEffect` 调用；有来源标记的滞留药水在复制到药水云时，将非瞬时效果时长除四，无限时长不变。瓶内保留完整时长，和原版滞留提示的 0.25 倍率匹配。未标记药水不变。

`TravailClientEvents.ModBus.setup` 的统一客户端初始化任务调用 `AbundanceUseClient.initialize()`，安装公共逻辑的客户端开始使用回调。`client/AbundanceUseClient` 复用 `SkillNoticeGuiAccessor`，在原版 Action Bar 显示提示文字，并在 RECORD_OVERLAY 渲染后于文字下方绘制细横条；与 DiaryProgressTooltip 共用 ThinProgressBar 的 3 像素高度及灰色填充样式，位置跟随 Forge 的额外生命值行偏移；每刻维持自己的提示寿命，其他提示覆盖后本次让位，清除时检查组件引用，避免删掉其他消息，并以实际使用键维护按压锁，避免长按完成后再次使用原物品或新药水。界面、失焦等取消使用时通过 `AbundanceCancelPacket` 取消服务端会话；该包只能取消发送者的转换，不接受时长、随机结果或奖励参数。网络协议版本为 23。

配置位于 `AbyssItemsConfig`，有效阈值、回退时长、黑名单与效果列表通过 `TooltipConfigSync` 同步。`ConfigReloadCoordinator` 取消活动会话、重建快照后广播。客户端和服务端必须使用同一协议版本。

酿造配方由 `registry/ModBrewing` 在 common setup 阶段注册为标准 Forge `BrewingRecipe`。JEI 15.20.0.132 的 Forge 配方扫描支持这一类型，不额外注册重复展示配方。

针对性验证入口：

```powershell
./gradlew.bat -I tools/structure-regression/abundance.init.gradle runServer --offline
./gradlew.bat -I tools/structure-regression/abundance-client.init.gradle runClient --offline
```

分别使用 `build/abundance-server` 和 `build/abundance-client` 的隔离世界。客户端入口复制前一入口生成的测试世界；不读取正式游玩存档。测试模组不打入发布包。运行结果保存在各隔离目录的 `abundance-result.txt`、`client-result.txt`，具体覆盖与未验收项以当次结果为准。

玩家选择保存于 Forge 玩家持久 NBT `the_long_travail:abundance_mode`，值 0/1/2 分别为普通/喷溅/滞留。Clone 复制，登录、重生、跨维度及点按切换通过仅服务端发送的 `AbundanceModePacket` 同步。客户端状态在退出时清空；当前状态仅由 `ThemeTooltips` 拼入物品描述，不写进 `AbundanceText.details()` 拾遗正文。

`releaseUsing` 在本次会话总刻数减剩余刻数不超过 5 时切换类型，超过 5 但剩余大于零时只取消；`finishUsingItem` 按开始时固定的类型交付。蓄力最少 10 tick；填充宽度为 `floor(clamp(elapsed / total, 0, 1) * width)`，不使用独立秒表。配置重载沿用取消会话与同步版本检查。弓动画本身保留原版节奏，Action Bar 才表示配置对应的实际进度。

## 语义染色

物品摘要与拾遗共用 CatalogTextStyle；液化丰饶专用词表仅匹配 abundance 翻译键，沿用每句最多两处、同段重复术语不重复强调的规则。正文为棕色，物品及机制术语为金色，操作、数值、等级与范围为青绿色。当前类型标签保留正文色，仅类型值使用青绿色。黑名单名称和空表“无”使用 configured_effect 标记保护，沿用完美流体配置列表处理方式，不受通用术语二次染色影响。
