# 开发接入目录

面向 Minecraft 1.20.1 / Forge 的兼容模组、附属和数据包。示例使用当前源码签名，包根为 `com.thelongtravail`。

## API 与运行约定

- [状态与旅程 API](state-api.md)：恶意与见证、旅程写入身份、时停查询。
- [携带 API](carrying-api.md)：外部库存、短期信号及未知结果。
- [饰品佩戴与恢复](accessory-equipment.md)：槽位、唯一性及前置失效。
- [运行时接入](runtime-integration.md)：注册、网络、配置重载及生命周期。
- [可选模组联动](optional-compat.md)：加载隔离、女仆、墓碑及外部库存复制。

## 战斗接入

- [伤害结算与追加效果](伤害结算与追加效果.md)：事件阶段、来源身份与重放。
- [战斗属性](combat-attributes.md)：见切、必杀与霸主。
- [直击伤害](直击伤害.md)：来源创建与防御规则。
- [伤害分类与肃正](伤害分类与肃正.md)：数据包标签与减伤。
- [三个战斗效果](三个战斗效果.md)：伤害、生命、仇恨及移动入口。
- [逐日与籠釣瓶](sun-chaser-kagotsurube.md)：追加链、禁疗、凋零及女仆归属。

## 数据与物品接入

- [六主题物品](六主题物品.md)：回施、限伤、独立保护窗、传送和技能数据。

- [战利品接入](loot-integration.md)：数据表、考古修改器与终结补偿。
- [高频战栗](高频战栗.md)：破坏事件、时运、FTB Ultimine 与 NBT 配方。
- [古今语怪](古今语怪.md)：附魔数据、资格回调与返还。
- [永生芽](immortal-bud.md)：实例标记、耐久及掉落物保护。
- [液化丰饶](液化丰饶.md)：效果池、药水数据、酿造及使用会话。
- [施色与名称显示](name-coloring.md)：样式数据、组件变换与菜单交付。

源码构建和依赖见[项目说明](../../README.md#源码构建)。`api` 包提供接入入口；机制文档中的 Mixin、菜单及运行时类用于定位当前实现，覆盖这些位置时须遵守对应生命周期和数据约定。
