# 开发接入目录

本目录按状态、物品、战斗和运行时整理接口说明。Java 包根为 `com.thelongtravail`。

## 状态与物品

- [状态与旅程 API](state-api.md)：查询主题状态、写入旅程进度和查询时停。
- [携带 API](carrying-api.md)：查询携带物、接入外部库存和短期携带信号。
- [饰品佩戴与恢复](accessory-equipment.md)：装备资格、唯一性、恢复与前置失效。

## 战斗接入

- [伤害结算与追加效果](伤害结算与追加效果.md)：事件阶段、来源身份、命中确认与重放。
- [战斗属性](combat-attributes.md)：属性注册、读取、修饰符与结算约定。
- [直击伤害](直击伤害.md)：来源创建、比例计算与伤害标签。
- [伤害分类](伤害分类与肃正.md)：物理和魔法类型标签及分类优先级。

## 数据与运行时

- [战利品数据接入](loot-integration.md)：数据覆盖、抽样、注入与重载。
- [运行时接入](runtime-integration.md)：注册、网络、配置、共享工具与生命周期。
- [可选依赖接入](optional-compat.md)：依赖声明、加载隔离和状态更新。
