# 伤害分类标签

## 标签与数据包

`DamageClassTags.PHYSICAL` 和 `DamageClassTags.MAGIC` 分别对应 `the_long_travail:physical_damage` 与 `the_long_travail:magic_damage`。标签表示伤害类型集合，可用于增伤、减伤和命中判断。

数据文件位于 `data/the_long_travail/tags/damage_type/`。例如，为第三方伤害补充魔法分类：

```json
{
  "replace": false,
  "values": ["your_mod:spell_damage"]
}
```

将文件保存为 `data/the_long_travail/tags/damage_type/magic_damage.json`，其中类型 ID 替换为实际注册项。

## 分类与结算

分类读取当前有效 `DamageSource` 的类型标签；来源转换后使用转换后的类型。同一类型同时属于物理与魔法时，肃正按魔法类处理。

`DamageReduction` 在输出增幅之后、见切和霸主之前收集适用的剩余倍率并相乘。已结算的伤害重放跳过已应用的减伤。完整阶段见[伤害结算](伤害结算与追加效果.md)。
