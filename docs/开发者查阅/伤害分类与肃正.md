# 伤害分类与肃正

## 公共标签

`DamageClassTags.PHYSICAL` 与 `DamageClassTags.MAGIC` 分别声明 `the_long_travail:physical_damage`、`the_long_travail:magic_damage`。标签只描述类型集合，可供增伤、护盾或命中触发复用，不依赖肃正效果。

数据文件位于 `data/the_long_travail/tags/damage_type/`。默认物理21项、魔法15项，均为原版类型。原版具体类型 `minecraft:magic` 是魔法类标签中的一项，标签不是新的 DamageType。数据包若将同一类型同时加入两组，肃正以魔法类为准，即使只有物理肃正，也不再回退应用物理减伤。

## 结算

`Purification.remainingMultiplier` 查询有效 DamageSource 的标签和目标状态效果；每级10%，Ⅹ级及以上使用0.01剩余倍率。amplifier 达到9时直接返回封顶倍率，避免换算等级时溢出。异常负 amplifier 按Ⅰ级处理。

倍率由 `CombatContext.beforeAbsorption` 的 `DamageReduction` 统一收集并参与百分比减伤乘算，位于输出增幅之后、见切和霸主之前。原版护甲及魔法防御已结算，吸收生命尚未消耗。重放跳过肃正，避免已经结算的金额再次折减。这里只调整当前伤害的倍率。

按有效来源分类：籠釣瓶等转换成自定义直击类型后，不从原来源追溯类别。原版音波仍受到魔法肃正影响，不另检查绕过抗性或护甲标签。默认清单外的 TLT 特殊来源不处理；原有处决与特殊伤害控制流程保持不变。

## 等级与资源

`PurificationEffect.DEFAULT_MAX_LEVEL` 为5。`RuntimePools.reload` 为两个效果补充默认上限，和随机效果池分离；已有显式池配置优先。`IncomingEffectLevels` 保留外部已经取得的高等级，实际减伤始终封顶99%。

注册ID为 `physical_purification`、`magic_purification`；图标使用同名 mob_effect PNG。语言源统一维护于五种语言的 common.json。当前不注册 Potion、配方或随机获取条目。
