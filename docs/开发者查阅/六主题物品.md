# 六主题物品接入

| 物品 ID | 生效入口 | 配置位置 |
|---|---|---|
| `moon_toad_pastry` | `ThemedFoodItem`、`MoonToadHarvest` | `aspects/flourishing.toml` → `items.moon_toad_pastry` |
| `sea_in_a_bottle` | `SeaBottle`、`SeaBottleRecipe` | `aspects/abyss.toml` → `items.sea_in_a_bottle` |
| `horizon_theory` | `HorizonTheory`、`CarryingApi` | `aspects/far_reach.toml` → `items.horizon_theory` |
| `last_affairs` | `LastAffairsItem`、`LastAffairsUseClient` | `aspects/deep_valley.toml` → `items.last_affairs` |
| `living_flesh` | `ThemedFoodItem` | `aspects/underworld.toml` → `items.living_flesh` |
| `holy_fool` | `HolyFool`、`BoundlessPacket.Cast` | `aspects/boundless.toml` → `items.holy_fool` |

六项注册开关沿用 `item-registration.toml` 的主题分组。配置由 `ThemeItemConfig` 装配，提示数值使用 `TooltipConfigSync` 的 `themeItem.*` 条目。四个有序合成配方使用原版 JSON；瓶中海使用 `the_long_travail:sea_in_a_bottle` 配方序列化器，锻造模板为空，基础材料为无垠精粹，附加材料为水瓶。

## 战斗与状态效果

瓶中海的基础栏位增量独立生效，使用独立 UUID 调用 `TravailCurios.syncExtraSlots`，与日记栏位增量相加。归墟恶意和见证分别提供治疗／回施、魔法类伤害增幅。魔法分类读取共享伤害标签，增幅进入 `CombatContext.outgoingBonus`。

回施在 `LivingCombatMixin` 的效果写入完成后检查首次获得或等级提高。来源可为生物或投射物主人，复制本次效果种类、等级、时长及显示参数。原效果保留；回施使用 `EffectInsertion.addOrGet`，合并沿用原版规则。`InsertedEffectSync` 将已确认的效果发送给客户端，并随实体保存效果标记，在开始追踪时补发当前实例；客户端按维度与实体 UUID 写入服务端快照。已标记效果的更新和清除同步给现有追踪者，清除时同时移除标记。同步调用作用域中的回施不再次触发瓶中海回施。无来源、自身来源及瞬时效果不参与。

地平论使用 `CarryingApi` 的现有携带范围。恶意限伤在玩家 `actuallyHurt` 的最终生命写入处应用，保护窗在 `CombatContext` 确认生命或吸收生命损失时启动，并在下一次 `DamageScope` 输入处检查。最大生命比例默认 0.4，保护窗默认 30 tick；两种能力按各自主题阶段生效。标记 `bypasses_invulnerability` 的伤害沿用原有处理。

## 使用与生命周期

身后事的 `ReturnToSpawn` 布尔 NBT 保存目的地模式，缺省为最近死亡位置。完成使用后读取 `getLastDeathLocation`，或读取玩家重生点／主世界出生点，直接跨维度传送到方块中心的 X/Z 与原 Y。成功后消耗物品并授予还魂。客户端使用已有 `ThinProgressBar`，与液化丰饶保持相同样式。

圣愚佩戴在 `head`，技能走已有逍遥游技能请求。`the_long_travail:holy_fool_until` 保存在玩家 Forge 持久数据中，记录主世界游戏时间的到期点；玩家复制时继承，死亡或重新登录不重置冷却。单独佩戴时分别处理圣愚与逍遥游，同时佩戴时仍优先处理逍遥游。

食物的 `saturation` 配置表示饱和度点数，转换为原版 `saturationMod = saturation / (2 × nutrition)`。满饥饿也可食用。青蛙采集固定产出一份月蟾酥、造成 1 点输入伤害、消耗剪刀基础耐久 1 点。

## 战利品配置升级

圣愚进入共享互斥池，默认牧师箱 10%、沙漠神殿 5%、丛林神庙 5%、末地城 7.5%，数量为 1。总概率与权重共同维护，旧物品各自概率保持原值。`ConfigUpgrade.sixThemeItems` 仅将完全匹配旧默认值的四张表升级；自定义表保留原设置，可在 `general.toml` 的 `loot.tables` 中添加圣愚条目。

## 食品提示接入

`FoodTooltips` 组织获取方式和食品效果；`compat.farmersdelight.FarmersDelightTooltips` 在农夫乐事存在时调用其 `TextUtils.addFoodEffectTooltip`，缺席时使用原版药水效果排版。苹果皮存在时使用其营养图示，缺席时由 `FoodIcons` 补充。风味文字与 Alt 提示沿用主题物品提示入口。
