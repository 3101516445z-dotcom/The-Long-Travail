# 原版操作音效

全部复用原版 SoundEvents，不添加音频文件。音量为播放倍率，音高 1 为原音。

| 操作 | 原版音效 | 音量 | 音高 |
|---|---|---:|---:|
| 长按完成、打开日记 | BOOK_PAGE_TURN | 0.35 | 0.90 |
| 切换至其他书签 | BOOK_PAGE_TURN | 0.25 | 1.15 |
| 切换效果/反转条件 | UI_BUTTON_CLICK | 0.12 | 1.30 |
| 所有日记关闭方式 | BOOK_PAGE_TURN | 0.35 | 0.90 |
| 归乡成功 | ARMOR_EQUIP_GENERIC（Curios 默认装备音效） | 0.80 | 1.10 |
| 全修成功 | BOOK_PAGE_TURN | 0.35 | 1.20 |
| 全修的第二声，延后 2 客户端 tick | BOOK_PUT | 0.40 | 1.10 |
| 解密之石首次解密 | AMETHYST_BLOCK_HIT | 0.35 | 繁茂 1.15、归墟 0.90、穷遐 1.05、幽谷 0.95、冥府 0.80、无垠 1.25 |

打开音效不放在界面初始化或渲染循环中，窗口缩放不会重复播放。关闭音效接入统一关闭入口，×、右键、Esc、Backspace、宿主界面关闭等路径均播放一次；重复清理不重播。当前页、悬浮和滚动不响。两类切页共用 80 毫秒最短音效间隔，切页动作本身不受限。

道具成功后服务端只向使用者发送一次 ItemSoundCue；客户端不预测播放。使用 UI 播放方式，无距离衰减，跟随游戏主音量。全修的延迟队列有数量上限，退出、玩家或维度切换会清理失效条目，暂停时不推进延时。

新增 S2C 消息，协议 5 升至 6，客户端/服务端需同步更新。公共网络和物品代码不引用客户端声音类，支持独立服务端。

构建和资源检查通过；独立 Forge 服务端测试核对成功使用、失败、冷却、六种解密及重复解密的实际音效通知，同时保留全修、饰品回收与此前性能/伤害回归。最终音量和音色仍需游戏内试听，不将自动测试视为听感验收。
