# The Long Travail 文档

本目录的玩家说明和开发接入文档随当前源码同步维护；更新日志保留对应版本发布时的变化，不作为现行配置手册。

| 入口 | 内容 |
|---|---|
| [玩家文档](玩家查阅/README.md) | 札记与拾遗操作、配置设置和升级说明 |
| [开发接入文档](开发者查阅/README.md) | 状态与旅程 API、携带查询、饰品、战利品及模组联动 |
| [中文更新日志](玩家查阅/更新日志zh/README.md) | 当前和历史版本的玩家更新说明 |
| [English changelog](玩家查阅/更新日志en/README.md) | Player-facing release notes in English |

物品实际效果以当前源码、资源和服务器有效配置为准。API 文档说明调用约定与兼容边界，完整物品效果可在游戏内「拾遗」中查看。

普通源码构建使用项目根目录的 Gradle Wrapper，环境要求和命令见[项目说明](../README.md#源码构建)。源码构建需要随仓库提供的语言生成与验证脚本，不依赖作者本地的测试世界、测试工具或归档。
