# 繁茂计数与自动效果声音（2026-09-23）

## 声音调查与处理

- 苦旅未直接调用播放饮奶或净化音效。穷遐之见证默认每 5 秒清除负面效果，不足时授予随机增益，默认持续 5 秒。
- 已检查本地 Sounds-2.2.1+1.20.1+forge.jar 的 PotionEventHelper：它逐刻比较当前和上一次的效果集合，对新增、消失的效果播放额外提示音。
- 当前 config/sounds/event.json 中，正负效果消失都配置为 minecraft:item.trident.riptide_1，音高 0.5；正面效果获得是 minecraft:item.trident.thunder。自动增益反复到期会持续触发这些提示。
- 加入可选 Sounds 兼容：仅在佩戴对应已反转苦旅时，将自动处理的效果种类同步到声音比较基线。穷遐处理随机增益池和负面效果的消失提示，保留新负面效果的警告声；幽谷处理其随机增益池、迅捷、黑暗、失明。其他种类的状态提示保留；摘下苦旅后恢复正常比较。
- 这是按效果种类过滤提示音：佩戴期间，同种效果即使来自其他来源，也不再触发 Sounds 的额外获得/消失提示。没有改变药水效果、持续时间、实际饮奶/饮药音效，也没有修改 Sounds 的全局配置。
- 幽谷清除黑暗、失明前增加存在检查，避免对不存在的效果每刻发布移除事件。

## 繁茂显示

- 沿用玩家 persisted NBT 的 visited_biomes，以完整群系 ID 为键；重复进入同一群系不累加，跨维度相同 ID 仍只计一次。已有记录直接沿用。
- 原有探索检测频率保持每秒一次，不要求反转后重新探索；未被旧版记录到的历史途经无法追溯补算。
- 只向本人同步计数：登录、新群系、重生、切换维度；客户端退出时清空缓存。
- 繁茂反转后，在悬浮提示和日记繁茂效果页显示“个人探索：N 种群系 · 恢复加成：+X%”。显示是当前查看者的探索记录，不是物品前任持有者的记录。
- 实际治疗和显示共用同一加成公式，并同步服务器配置上限。
- 网络协议升级为 3；多人游戏客户端和服务端应同时更新。
