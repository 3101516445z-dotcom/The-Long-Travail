# 古今语怪

古今语怪是无垠主题的书类物品，可以在合成栏中收录或转移附魔。每本占一个物品栏格，不能堆叠。

## 获得

在工作台按以下排列合成一本：

```text
竹子  线    竹子
竹子  全修  竹子
竹子  线    竹子
```

## 转移附魔

以下配方均为无序合成，也可使用背包的 2×2 合成栏：

| 材料 | 转移方向 |
| --- | --- |
| 物品＋下界石英＋古今语怪 | 从物品转入古今语怪 |
| 物品＋青金石＋古今语怪 | 从古今语怪转入物品 |

可以额外放入一种筛选材料：蜂蜜瓶仅转移非诅咒附魔；发酵蜘蛛眼仅转移诅咒附魔。不放筛选材料则两者均可转移，不能同时放入两种筛选材料。

每次处理一件物品，只消耗一个石英或青金石，以及一个可选筛选材料。蜂蜜瓶返还玻璃瓶。接收方出现在结果槽，来源作为合成剩余物返还；来源槽不能容纳返还物时，会尝试放入背包，背包满时掉落。

物品和书都不会被转移过程摧毁，名称、耐久及其他数据保留。两本古今语怪不能互转。没有可实际转移的附魔时，不显示结果，也不消耗材料。

## 等级与冲突

- 同种附魔直接相加，目标上限为 255。目标 250 级、来源 10 级，结果为目标 255 级，来源保留 5 级。
- 古今语怪可承载不同装备类型的附魔，但遵循原版冲突限制，例如锋利与亡灵杀手不能正常合并。
- 转入装备时，同时检查装备是否适用和已有附魔是否冲突。
- 不适用、冲突、筛选排除和超过可接收容量的附魔留在来源。
- 普通书接收后变为原版附魔书；原版附魔书可作为来源，提取为空后仍保留附魔书物品。

支持使用标准附魔数据的物品。未知附魔 ID、重复或无法安全解析的附魔数据不会被自动清理，这类输入不生成转移结果。

附魔在转移检查中发生异常时，本次转移取消，材料保留；快捷栏会提示涉及的附魔。相同失败输入不会持续重复提示，调整输入后会重新检查。

## 原版互动

可以放入雕纹书架。未附魔的古今语怪可以在附魔台接受书式随机附魔，完成后仍是古今语怪。

铁砧允许改名、接受右槽原版附魔书；古今语怪不能放在右槽作为附魔材料消耗。铁砧沿用正常等级、经验费用及已有冥府见证规则，不使用合成转移的等级相加规则。高等级附魔再与同种附魔书合并时，可能降至正常附魔上限；仅改名不会触发这种降级。
