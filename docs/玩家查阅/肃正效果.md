# 肃正效果

物理肃正减少受到的物理类伤害，魔法肃正减少受到的魔法类伤害。每级减少10%，本模组内默认最高Ⅴ级；外部来源获得更高等级时，Ⅵ至Ⅸ级分别减少60%至90%，Ⅹ级及以上最多减少99%。

肃正与其他百分比减伤分别相乘，也能减少吸收生命（黄心）的消耗。两种肃正可以共存，同一段伤害不会同时受到两种肃正减免。当前仅提供状态效果，尚无内置获取途径。

分类以实际伤害类型为准，部分法术也会造成物理类伤害。默认仅覆盖下列原版类型，模组自定义类型不自动归类。

| 分类 | 原版伤害类型（省略 minecraft:） |
| --- | --- |
| 物理类伤害 | player_attack、mob_attack、mob_attack_no_aggro、arrow、trident、thrown、mob_projectile、sting、cactus、sweet_berry_bush、falling_block、falling_anvil、falling_stalactite、fall、stalagmite、fly_into_wall、cramming、explosion、player_explosion、fireworks、bad_respawn_point |
| 魔法类伤害 | magic、indirect_magic、wither、dragon_breath、wither_skull、fireball、unattributed_fireball、thorns、sonic_boom、in_fire、on_fire、lava、hot_floor、freeze、lightning_bolt |

虚空、强制击杀、饥饿、溺水、窒息、干涸、世界边界外及通用伤害不在默认范围内。99%是肃正自身的减伤上限，不是所有防御叠加后的总上限。

## 与其他减伤叠加

多项百分比减伤独立乘算，每项减伤作用于剩余伤害。例如第六天魔王提供25%减伤、物理肃正Ⅴ提供50%减伤时，100点进入该环节的伤害变为 `100 × 0.75 × 0.5 = 37.5` 点，总减伤为62.5%。各效果仍需满足自身条件；槲寄生与无穷花是两个独立项。

99%是肃正自身的上限，并非多项效果叠加后的总上限。百分比减伤计算后，再处理见切固定扣减、霸主阈值判断和伤害吸收。
