# 永生芽

永生芽属于繁茂主题。在锻造台依次放入荒野盔甲纹饰锻造模板、任意树叶（minecraft:leaves 标签）和繁茂之石，可获得一个永生芽。

将永生芽与一件具有耐久容量的物品无序合成，消耗一个永生芽，默认修满目标耐久并赋予「恒久长青」标记。两种配方都可在背包 2×2 或工作台中完成。已经具有「恒久长青」标记的物品不能重复赋予；原本带有原版“无法破坏”的耐久物品仍可赋予。

目标保留原名称、附魔及其他物品数据。名称下方单独显示以繁茂主题渲染的“恒久长青”，不改变原名称和品质颜色。

带标记的物品受到耐久保护，不因常规耐久损耗而破损。永生芽自身及带标记物品落地后防火、防岩浆、防爆，且不会自然到期消失；保存重载后继续生效。

合成消耗、物品放置或使用消耗不受「恒久长青」保护。另外，受保护物品若坠入虚空，也无法找回。

赋予标记时固定修满目标耐久。`itemBlacklist` 可排除新的赋予目标，不影响已有标记。
