# 液化丰饶

归墟主题消耗品，最多堆叠 64 个，无须佩戴苦旅。

手持时，在 0.25 秒内松开使用键，按普通→喷溅→滞留循环切换转化类型，不消耗物品；超过 0.25 秒但未蓄满就松开，会取消本次操作。长按蓄满后消耗一个，生成当前类型的随机药水，默认需要 1 秒。潜行不影响操作，每次按住最多转换一个，松开后才能再次操作。

当前转化类型显示在物品描述中，按玩家保存、主副手共用，退出重进后保留，首次默认为普通药水。物品自身不记录类型，不影响堆叠。拾遗页只介绍通用规则，不显示个人当前选择。

蓄力采用弓蓄力动作，快捷栏上方显示对应类型的提示，例如“蓄满后转化为随机滞留型药水”，文字下方使用与拾遗提示一致的灰色细横条。进度按配置的实际蓄力刻数推进。打开界面、失焦、换槽等打断或配置重载均取消操作；重载后的下一次使用采用新时间。

每瓶等概率抽取一种未被禁用的已注册状态效果，包括有益、有害和中性效果。若已有注册药水包含该效果，先从已有等级中随机一个，再从该等级对应的已有时长中随机一个；相同等级和时长去重，不重复加权。没有有效药水参数时使用Ⅰ级、15秒。瞬时效果不使用持续时间。

滞留型药水的持续效果时间为基础时间的四分之一，例如 15 秒变为 3.75 秒；无限时间保持无限。瞬时效果按原版药水云规则生效。药水生成后，其效果不因配置变更而改变。

每次转化消耗一个液化丰饶，创造模式不消耗。手中最后一个直接替换为药水；否则放入背包，背包满时掉落。没有可用效果时会提示，并且不消耗物品。

## 获取

- 1个蜂蜜瓶、3个空玻璃瓶、1个牛奶桶和1个青金石无序合成4个液化丰饶；仅返还空桶。
- 在酿造台下方瓶槽放龙息，上方放青金石块，每瓶龙息转化为一个液化丰饶。三个瓶槽均可使用，一批最多产出三个，消耗一个青金石块；燃料和酿造耗时沿用原版。

## 配置

配置位于 `config/the_long_travail/aspects/abyss.toml`：

```toml
[items.liquefied_abundance]
longPressSeconds = 1.0
fallbackDurationSeconds = 15.0
effectWhitelist = []
effectBlacklist = []
```

`longPressSeconds` 是长按所需秒数，范围为 0.5～3600 秒，默认 1 秒；短按窗口固定为 0.25 秒。按游戏刻计时；服务器卡顿时实际等待可能更长。`fallbackDurationSeconds` 只用于没有有效注册药水参数的持续效果。

`effectBlacklist` 填写状态效果 ID，例如 `["minecraft:poison", "minecraft:wither"]`。它排除整个效果，不是某一种药水等级。黑名单只影响之后生成的药水。拾遗显示服务器配置黑名单中不可转化获得的状态效果名称，空表显示“无”。

**注意：`effectWhitelist` 只要不是空列表，就只会生成名单内的药水效果，所有名单外的效果都不会再出现。** 此列表用于限制效果，不是向原有效果池追加效果。例如，只填写 `["minecraft:speed"]` 时，只会生成速度效果的药水。

白名单默认为 `[]`，表示不额外限制。清空列表可取消白名单限制，但黑名单始终优先：白名单中的效果若同时出现在黑名单中，也不会生成。未知或格式错误的白名单 ID 不参与抽取，重复项不增加权重；非空名单全部无效时不会恢复为全部效果。筛选后没有可用效果时，提示并取消转换，不消耗物品。

两张名单仅改变可抽取的效果种类，保留效果的等级和时长抽样规则不变。修改只影响之后生成的药水，已有药水保持原样。拾遗同时显示非空白名单及黑名单。
