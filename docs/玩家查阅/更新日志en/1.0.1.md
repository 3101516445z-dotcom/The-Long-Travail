# The Long Travail 1.0.1

Release date: Pending  
Last updated: 2026-11-04

This update fixes item descriptions and catalog presentation, updates RSI integration, and revises several compatibility implementations. Item balance, trigger probabilities and cooldown durations are unchanged.

## Tooltip and Catalog Fixes

- Fixed tooltip paths that exposed the internal `summary_marker` key instead of the item description. Items now generate complete summaries directly, with handling for legacy markers and repeated processing.
- Added bundled English fallback text for summaries, catalog details and glossary cards. Missing translations are logged once per key per game session.
- Restored progress bars beneath hold-to-open catalog hints, including hints wrapped inside summary components.
- Decoupled glossary text layout from internal registration order, so inserting a term no longer changes existing cards' layout rules.
- Reduced the cursor-to-card gap from 12 to 6 GUI pixels, including when cards flip direction near screen edges.

## Wording and Languages

- Added the “Damage from Others” glossary card: damage with an attributable source, caused by an entity other than oneself. The corresponding Star Voice and Azrael catalog descriptions now use this term, following existing highlighting, underline and first-occurrence hover rules. Insight's definition is unchanged.
- Clarified that Star Voice makes a time-stop roll when the wearer deals damage, connecting the description to the roll cooldown rules. Chances, durations and cooldowns are unchanged.
- Revised Ancient Strange Tales' tooltip: removed an unnecessary blank line, simplified punctuation, presented enchantment-filter ingredients as a list, and highlighted “filter enchantments” in gold while preserving ingredient and effect colors.
- Synchronized these changes across Simplified Chinese, Traditional Chinese (Taiwan and Hong Kong), Classical Chinese and English.

## Compatibility and Implementation

- Updated Perfect Fluid's RSI integration to target **RSI 1.5.3**, replacing the older adapter. Update RSI when using this integration; older RSI versions are no longer the compatibility target.
- Updated unified and resonance disk copying for long item/fluid quantities and Mana, Source and Soul data. Capacity and ownership are preserved, while copies retain independent identities and storage files.
- Retained backup-state checks during preparation and commit, together with quarantine and copy-refusal handling.
- Replaced selected reflection calls with direct APIs or optional Mixins in AttributesLib, FTB Teams, Gravestone, maid spell health, FTB Ultimine and Perfect Fluid external-storage integrations. Existing decisions and failure behavior are preserved.
