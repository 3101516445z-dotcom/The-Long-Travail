# The Long Travail 0.1.3

Release date: Unreleased

This update adds three language options and compatibility presets for multiple configuration pools, and improves mod compatibility, configuration readability and recovery, and loot validation.

## Language Support

Added **Traditional Chinese (Taiwan)**, **Traditional Chinese (Hong Kong)**, and **Classical Chinese (Huaxia)**, available through the game's language settings. Thanks to [zgxhzhr](https://github.com/zgxhzhr) for contributing the translations in [PR #1](https://github.com/3101516445z-dotcom/The-Long-Travail/pull/1).

Refined the Classical Chinese descriptions of carrying items, maximum health, the proportion of health lost, and effect ranges to match their actual behavior.

Added 12 vanilla default structures, two per aspect, with the default structure draw count set to 2. Flourishing includes a plains village and a woodland mansion. Compatibility presets expand the candidate pools; existing configurations and journeys are preserved.

## Mod Compatibility

The relevant Gravestone, Caelus, and Apotheosis adapters now check compatibility against the actual interfaces. If a check fails, the mod logs a warning and disables the affected adapter, preventing these interface mismatches from directly aborting game startup.

- **Gravestone**: Disabling the integration pauses The Long Travail's grave item reconciliation while preserving grave contents and existing records. Compatibility is checked again after restoring a compatible version and restarting the game.
- **Caelus**: An incompatible interface disables the flight adapter. Icarus then uses its flight checks without that adapter.
- **Apotheosis anvils**: When Apotheosis is installed, it handles anvil level limits to avoid overlapping changes. The Long Travail's cost cap, free item pickup, and name styling remain independently active.

Added biome presets for Terralith (65 candidates across all six themes), Incendium (8 for Underworld), and Alex's Caves (6 biomes across Flourishing, Abyss, Deep Valley, and Underworld). Terralith and Incendium support both mod and data pack installations. On first detection, available biomes are added with weight 1 and names resolved through language resources. Existing settings for the same IDs are preserved; deleted entries are not automatically restored after initialization.

Added 82 candidate structures from 14 mods as theme-specific presets. Structure and biome initialization are tracked independently, preserving manual settings. Structure draw counts remain controlled by the existing configuration. Acropolis belongs to Abyss; Maid Spell uses Hidden Cherry Tree, Elven Realm, and Fallen Sanctum, while Alex's Caves adds only biome presets.

Expanded the vanilla defaults for Underworld fishing and Boundless phantom rewards to 12 items, adding nautilus shells, netherite scraps and echo shards while adjusting basic-material weights. Added 49 reward candidates from 8 mods with preset weights and quantities. Missing items are appended on first detection, with separate defaults, compatibility presets and initialization for each pool; existing manual settings are preserved.

Updated the 9-entry vanilla fishing entity default pool, replacing pufferfish with villagers and adjusting weights. Added 15 entity candidates from Youkai's Feasts, Youkai's Homecoming, Ars Nouveau, Ars Elemental and Touhou Little Maid, preserving manual weights with separate initialization. Fishing trigger chances are unchanged.

Added 36 beneficial-effect candidates from 12 sources to each of the Far Reach and Deep Valley pools, with weight 1 and per-effect level caps. Each pool initializes independently and adds only registered beneficial effects, preserving manual settings and existing vanilla default weights.

Added Golden Age compatibility blacklists: when their mods are installed, Celestial Fruit and Abyssal Stew are excluded from food rewards, while L2 Complements' six immunity enchantments and Celestial Enchantments' Death Blade and Celestial Shelter are excluded from enchantment rewards. The lists initialize separately, preserve existing settings and do not restore entries removed afterward.

Youkai's Homecoming and Youkai's Feasts have separate entity and beneficial-effect presets with their own namespaces and initialization records. Existing Feasts initialization does not prevent presets from being added when Homecoming is installed later.

## Perfect Fluid

- **Sophisticated Backpacks**: Copying is refused for backpacks containing captured mobs and supported containers that contain such backpacks at any nesting depth. Originals and crafting ingredients are preserved. This restriction applies automatically without configuration blacklist entries; empty backpacks and backpacks with an unused Mob Catcher upgrade are unaffected by this restriction.
- **Beyond Dimensions**: Added copying support for matter compression balls, preserving supported resource quantities and creating independent copies of supported nested inventories. Blacklist filtering and special inventory restrictions still apply. Crafting must use the vanilla player crafting grid or crafting table; the dimensional network itself is not duplicated.
- **Descriptions**: Updated the copying scope to “almost any item” and clarified that ingredients are retained when copying is refused due to a special inventory, across all five languages.

## Configuration and Loot

### Reading and Managing Configuration

Reorganized configuration files: each theme starts with its biome and structure pools, while preset processing records appear at the end, grouped by type and labeled with the corresponding mods. Layout changes preserve existing keys, values and list order.

Shortened repeated comments, clarified units and the distinction between ratios and flat attribute bonuses, and explained that preset records control further automatic additions rather than enabling or disabling features. Clarified the per-item carrying location switches for Eki and Tower of Babel.

Reorganized both configuration guides into syntax, presets and other mechanics. Added basic syntax, list formats, an introduction to presets and instructions for retrying or skipping additions. Section codes in configuration comments lead to the relevant detailed rules.

### Recovery and Validation

Improved handling of invalid configuration files. If a file cannot be parsed at startup, its original contents and an error report are saved under `config/the_long_travail/invalid/` before restoring that file's defaults. Settings in other configuration files are preserved.

- **Validation**: Supports UTF-8 files with a BOM and valid numeric strings. Invalid ordinary settings use their defaults at startup or retain effective values during the current session. Runtime edits that cannot be parsed remain on disk for repair.
- **Loot isolation**: An invalid table no longer blocks other valid tables. It retains its effective rules from the current session, or disables its rewards if none exist. Perfect Fluid's fishing chance is handled independently; explicit disabling and deletion still take effect.
- **Reloading and notices**: Supports both direct writes and file replacement by editors, with a single summary notice for single-player users or server administrators. Duplicate warnings are suppressed, error records have a fixed capacity, and warning bursts use limited detail output with summaries of omitted counts and affected files.
