# The Long Travail 1.0.2

Release date: 2026-11-06

This release standardizes slot tooltips for universal accessories, clarifies Immortal Bud descriptions, and reorganizes theme mechanics and configuration code. Item stats, trigger chances, cooldowns, and equip requirements remain unchanged.

## Accessory slot tooltips

- Free and Easy Wandering, Everlasting Flower, Phosphophyllite, Don Quixote, and Voice of the Stars now display “Slot: Any accessory slot”.
- Their slot descriptions no longer expand into long lists or collapse to the less specific “Curio” depending on the slots registered by other mods.
- Existing diary requirements, duplicate-item restrictions, and cosmetic-slot restrictions remain unchanged.

## Catalog and translations

- The Immortal Bud catalog page now explicitly mentions protection from cactus damage while dropped.
- The Evergreen glossary card includes the same clarification for marked items. This is a description update; the protection itself is unchanged.
- Updated Simplified Chinese, Traditional Chinese (Taiwan/Hong Kong), Literary Chinese, and English.

## Internal maintenance

- Reorganized source directories and responsibilities for theme mechanics, configuration management, and runtime logic, and updated developer documentation.
- Existing configuration options and gameplay rules remain unchanged.
