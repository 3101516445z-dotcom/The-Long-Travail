# The Long Travail 1.0.3

Release date: 2026-11-07

## Theme item registration switches

- Added a separate configuration file to enable or disable registration of each of the 30 theme items. All items are enabled by default.
- Disabled items are excluded from the catalogue, creative inventory and related JEI displays. Built-in recipes and acquisition paths that require them are also disabled.
- Registration changes require a restart. Clients and servers must use matching switches.

Disabling registration may remove existing items from saved worlds. Back up the world before changing these switches.
