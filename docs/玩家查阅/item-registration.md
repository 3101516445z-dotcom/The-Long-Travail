# 主题物品注册开关

`config/the_long_travail/item-registration.toml` 控制 30 件主题物品是否注册，按六主题分组，默认全部为 `true`。

```toml
[abyss]
eki = true
perfect_fluid = false
```

`true` 启用物品注册，`false` 关闭物品注册。修改后必须完全退出并重启游戏或服务器；`/reload` 不会改变注册结果。联机双方必须使用相同的开关设置，不一致时连接会被拒绝。

关闭后，物品不会出现在创造物品栏、拾遗和相关 JEI 展示中；依赖它的内置配方、交易和酿造也会停用。旧村民中包含关闭物品的交易也会在读取存档时移除。其他主题物品保持各自设置，例如关闭伊卡洛斯会停用以伊卡洛斯换取逐日的交易，但不会关闭逐日本身及其考古来源。

关闭共享掉落池中的物品不会提高其他主题物品的掉落概率：其原有权重对应不产出物品；考古、钓鱼的特殊单轮表则将关闭项的概率还给原版结果。用户原有掉落配置不会因此删除条目。

日记、旅程工具、主题之石和精粹不受这组开关控制。关闭整个主题的五件物品也不会关闭该主题的旅程机制。

**旧存档中已有的物品可能因取消注册而丢失，重新开启不保证恢复。** 请先备份世界，在副本中调整。其他模组的数据包或脚本如引用了被关闭的 ID，也需要相应调整。

文件缺失时生成全开默认值，缺少的开关补为 `true`。无法解析的文件、错误的布尔值或读取失败会阻止启动；修复后重启。未知配置键保留并记录警告，不会当成有效开关。
