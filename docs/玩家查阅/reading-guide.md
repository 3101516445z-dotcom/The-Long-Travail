# 札记与拾遗阅读

苦旅物品悬浮提示中，长按[Shift]阅读札记，长按[Alt]打开拾遗。其他收录物品长按[Alt]打开对应详情；提示会显示实际绑定的按键，未绑定时显示[未绑定按键]。

拾遗收录旅程助力、解密之石、此世精粹与六类主题物品，不收录苦旅本体。父页搜索支持中文、英文名称，以及已登记的拼音和首字母；选择搜索结果会定位到对应卡片，再点击卡片阅读详情。长正文可以滚轮滚动。

拾遗展示完整机制和服务器有效设置。主花、配花、绑定伙伴和功能开关等单件状态，请查看实际物品的悬浮提示。

## 返回与退出

| 所在页面 | 操作 | 结果 |
| --- | --- | --- |
| 札记或拾遗父页 | 点击关闭按钮 ×、Esc 或右键 | 关闭阅读界面 |
| 从父页进入的拾遗详情 | Esc、右键或底部返回 | 返回原父页，保留搜索与滚动位置，收起下拉列表 |
| 从物品直接打开的详情 | Esc 或右键 | 关闭拾遗 |
| 从物品直接打开的详情 | 底部返回 | 打开拾遗父页顶部，搜索为空 |
| 任意拾遗页面 | 点击右上角关闭按钮 × | 关闭整个拾遗 |

Backspace 不承担退出或返回功能；在搜索框中按正常退格键使用。
