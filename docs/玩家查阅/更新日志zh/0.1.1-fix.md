# The Long Travail 0.1.1-fix

本次更新新增六种主题精粹与车万女仆饰品兼容，调整部分饰品的受击触发方式，并改善时停提示、剑与灯照明及旅程判定。

## 新增

### 六种主题精粹

- 新增繁茂、归墟、穷遐、幽谷、冥府、无垠六种精粹，须佩戴已生成旅程的苦旅后使用。
  - 对应主题尚有恶意时，随机完成一条未完成的旅程记录；已经见证时，重置该主题并重新抽取条件，其他主题不受影响。
  - 重置会清除该主题的进度、见证来源及指令强制设置的状态，但不会清除已有战斗冷却或限时效果。
- 精粹可堆叠 64 个，成功使用后冷却 1 秒；无法完成操作时不消耗。
- 不同精粹可从指定箱子、考古、钓鱼宝藏、嗅探兽挖掘、村庄英雄赠礼、猪灵交易、猫的晨间礼物或破坏紫水晶母岩中获得。

### 车万女仆饰品兼容

- 支持春日的游戏、剑与灯、死告天使、一千年后、星之声、伊卡洛斯、东海道五十三次与駅。
- 女仆须将饰品放入**原生饰品栏**，普通背包、手持与 Curios 均不生效，本模组物品也不能放入女仆的 Curios 饰品栏。
- **苦旅本体不能作为女仆饰品**，需要恶意或见证状态的效果，将读取**在线主人所佩戴苦旅的状态**。
- 同一主人的苦旅成果可以支持多名女仆，但每名女仆仍须实际装备对应饰品。
- 女仆佩戴东海道五十三次时，仅获得符合条件的回血与火焰免疫，不能恢复饱食度或主动唤雨。
- 伊卡洛斯不提供女仆滑翔能力。

### 进度与提示

- 新增普通进度“苦旅”，戴苦旅即可完成。
- 星之声成功触发时停时，会出现短暂的末地烛粒子环并播放轻微共鸣音效。
  - 玩家与女仆均适用，提示本身不会被时停冻结。
- 新增 JEI “方块破坏”来源页，可查询紫水晶母岩产出幽谷精粹的概率与条件。

## 调整

### 饰品与战斗

- 星之声的恶意效果、死告天使的受击准备、剑与灯的受击战斗记录，以及春日的游戏中玫瑰丛的反伤，改为**受击即可判定，不再要求实际扣血**。
- 星之声恶意分支每次受击判定后，默认进入 **0.2 秒**的隐藏冷却，无论此次是否触发时停。
- 白日梦更名为**逍遥游**，并修改为可在不同的 Curios 功能饰品槽中佩戴。
- 除苦旅外，其他饰品可右键穿戴，仍须满足各自的穿戴条件。
- 新增创造／观察者模式的负面效果配置，默认豁免这两种模式的玩家。
  - 苦旅的相关内容是否豁免采用同一配置调控。
  - 死告天使的处决、星之声的时停、春日的游戏的负面效果与反伤、伊卡洛斯的点燃可分别调整。

### 剑与灯

- 手持时潜行右键可切换照明，开关随物品保存，对佩戴、主副手持有及掉落状态均有效。
- 照明范围扩大至 **12 格**，中心 **3 格**保持最高亮度，向外逐渐变暗，仅改变视觉亮度，不改变世界实际光照。
- 优化多个光源重叠和移动时的显示开销，光源亮度与范围不变，光源出现或消失可能稍晚显示。

### 获取途径与默认概率调整

以下为默认配置下的概率，整合包自定义配置以实际设置为准。

| 来源 | 物品 | 概率 |
| --- | --- | --- |
| 丛林神庙箱子 | 春日的游戏 | 10% |
| 钓鱼 | 駅、东海道五十三次 | 各 5%，共用一次抽取机会 |
| 猪灵交易 | 冥府精粹 | 0.5% |
| 玩家破坏紫水晶母岩 | 幽谷精粹 | 0.5%，精准采集与时运不影响概率或数量 |

| 林地府邸箱子 | 三叉戟 | 18% |

- 对应箱子中，每件候选苦旅饰品或道具的默认抽取概率调整为 **10%～25%**，每个战利品表最多抽取一件。
- 三叉戟、鹦鹉螺壳和干海绵共用独立的材料奖励池，不占用苦旅饰品或道具的奖励名额。
- 考古、钓鱼宝藏、嗅探兽挖掘、村庄英雄赠礼、猪灵交易及猫的晨间礼物中的精粹，与原有奖励共同抽取。

### 旅程与使用体验

- 放宽旅程到访判定：结构默认按整体范围判断，并增加水平、垂直各 **4 格**的容差。
- 群系会补查水平方向的邻近位置，也可通过配置启用逐结构部件判定。
- 新增 `/the_long_travail reverse` 无编号用法，可一次将六个主题全部强制设为见证；原有复原指令仍恢复按真实旅程进度判定。
- 更新旅行日记槽位的空槽图标，采用苦旅轮廓的灰色描边，与 Curios 默认图标风格保持一致。
- 简化解密之石的说明，名称采用对应主题的渲染样式，并排列在创造物品栏各主题的首位。
- 整理中英文提示，补齐引路人英文消息中的苦旅名称，并修正少量文字错误。
- 优化旅程检测、女仆饰品、时停及死者之书的处理开销，保持原有触发条件、冷却和效果数值。

## 修复

- 修复与神化同时安装时，铁砧功能冲突导致的启动崩溃，保留冥府之见证的费用封顶以及上限设为 0 时的免费操作。
- 修复部分其他模组的考古奖励池导致战利品表加载失败的问题，并改善战利品配置重载的兼容性。
- 修复开启死亡不掉落时，星之声和死告天使在重生后被错误退回背包的问题。
- 修复时停期间怪物反复播放最后一段动画、原地抽搐的问题。
- 修复逍遥游退出失败时恢复信息可能丢失，以及断线或重生后旧请求仍可能触发入梦或退出的问题。
- 修复死者之书的旧见证记录重新反转已重置的冥府旅程的问题，并加强异常存档下的苏生保护。
- 完善死告天使处决异常后的生命值与伤害吸收值恢复，减少与其他模组交互时留下异常状态的问题。
- 完善女仆饰品与万法皆通、爱恋及性格的兼容，避免生命上限变化或收纳恢复时错误保留春日的游戏提供的临时生命加成。
- 修复部分模组影响移速计算时，駅加速、无垠减速或僵硬限制可能失效的问题。

## 升级说明

- **联机客户端与服务端须同步更新。更新后生成或重置的旅程数据不支持降级到旧版。**
- 逍遥游的英文名称改为 **Free and Easy Wandering**，物品 ID 改为 `the_long_travail:free_and_easy_wandering`；自定义脚本、任务或数据包若引用旧 ID，须同步调整。
- 配置结构与中英文说明已整理，已有合法配置值保留，详细用法集中到自动生成的中英文配置说明文件中。
- 死告天使部分创造／观察者模式配置的旧路径会自动修正并保留原值，新旧路径同时存在时以新路径为准。
- 移除伊卡洛斯尚未实际接入的生长范围、高度与间隔配置，不影响现有饰品效果。
