# The Long Travail 1.0.2

发布日期：2026-11-06

本版本统一通用饰品的槽位提示，补充永生芽相关说明，并整理主题机制与配置管理的内部结构。物品数值、触发概率、冷却时间与佩戴条件不变。

## 饰品槽位提示

- 逍遥游、无穷花、磷叶石、堂吉诃德和星之声统一显示“槽位：任意饰品栏位”。
- 这五件饰品的槽位说明不再随其他模组登记的槽位变化而展开长列表，或简写成含义不够明确的“饰品”。
- 原有的日记前置、单件限制与装饰槽限制保持不变。

- 同步更新简体中文、繁体中文（台湾／香港）、文言及英文。
