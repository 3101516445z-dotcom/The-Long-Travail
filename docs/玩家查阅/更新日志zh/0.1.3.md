# The Long Travail 0.1.3

发布日期：未发布

- 洛伦兹幻想见证的追加伤害改为直击伤害，仍按命中前目标当前生命值的2%计算，同一射手对同一目标的间隔仍为0.5秒。

本次更新新增液化丰饶、永生芽与施色物品、三种语言支持与多类联动配置预设，调整墓碑、Caelus 与神化铁砧的兼容处理，并改善配置阅读、恢复与战利品校验。

## 逐日与籠釣瓶

- 新增穷遐主题携带物品 **逐日**：免疫火焰和岩浆伤害，不会被点燃；岩浆内每秒恢复1点生命，并豁免归墟恶意的周期性流体伤害。恶意时反弹来袭弹射物，弹射物增伤50%、燃烧目标增伤30%；见证时命中施加10秒禁疗和受伤无敌帧抑制，对燃烧目标追加最大生命值1%的直击，不再增伤或必杀。
- 逐日由制箭师大师以1个伊卡洛斯＋1个穷遐精粹兑换，也可在原版考古中以5%概率获得。
- 新增冥府主题腰带 **籠釣瓶**：每笔实际伤害施加5秒凋零Ⅰ，已有凋零则保持等级并延长5秒；恶意时见切＋15、霸主＋0.1，见证时将归属于佩戴玩家的伤害转为直击。使用诅咒附魔书、冥府精粹、下界合金剑及两朵凋零玫瑰有序合成。
- 两件物品的恶意与见证能力互不继承，均保留基础效果；补充拾遗说明、风味描述及五种语言文本。
- 逐日与籠釣瓶支持女仆饰品栏；基础效果作用于女仆，恶意与见证根据在线主人所佩戴苦旅的状态生效。

## 液化丰饶

新增归墟主题物品 **液化丰饶**，最多堆叠 64 个。点按切换普通、喷溅、滞留类型；长按蓄满后转化为当前类型的随机药水，默认 1 秒，中途松开取消。当前类型按玩家保存并显示在物品描述中，蓄力提示位于快捷栏上方，文字下方使用与拾遗提示一致的细横条显示进度。

- 包含原版与模组注册的状态效果，支持效果白名单与黑名单；从已有药水中随机等级及对应时长，无对应药水时默认Ⅰ级、15秒，回退时长可配置。
- 1个蜂蜜瓶、3个空玻璃瓶、1个牛奶桶和1个青金石无序合成4个液化丰饶，仅返还空桶；也可在酿造台下方放龙息，上方放青金石块获得。
- 每次消耗一个，创造模式不消耗；加入长按进度提示和拾遗说明。

- 白名单非空时，只会生成名单内的药水效果，名单外效果全部停止生成；黑名单优先。筛选后无可用效果时不消耗材料，已有药水不变。

## 主动技能冷却

- 唤雨默认冷却由300秒调整为120秒，入梦默认冷却由60秒调整为30秒；持续时间仍分别为60秒、10秒。已有配置值保留。

## 永生芽

新增繁茂主题物品 **永生芽**，由任意树苗、骨粉与无穷花各一个无序合成。

- 与一件有耐久的物品无序合成，消耗一个永生芽，默认修满耐久并赋予「恒久长青」；保留原有名称、附魔及其他数据，已赋予的物品无法重复赋予。
- 「恒久长青」保护物品耐久，阻止常规损耗和过高的一次性耐久消耗造成的破损。
- 永生芽自身及受保护物品在掉落状态下防火、防岩浆、防爆，且不会自然消失；正常合成、放置和使用消耗照常，坠入虚空的物品无法找回。
- 拾遗中可查看完整使用说明；受保护物品在名称下方显示繁茂主题的「恒久长青」标记。

- 新增赋予时修复开关与目标黑名单；关闭修复后保留原损伤，黑名单只限制新的赋予，不撤销已有标记。

## 施色与拾遗

新增物品 **施色**，用八份萤石粉围绕一把原版刷子合成。手持右键打开界面，将物品放入左侧槽位，选择样式后从右侧领取，支持一次处理整组物品。

- **名称染色**：提供七种主题样式，以及「镀金」「陶染」两种样式，共九种可选效果；仅改变物品名称的显示样式，不改动名称文字、说明、附魔和属性。
- **还原样式**：可去除本模组的物品名渲染特效；神化物品仍保留其品质颜色。
- **拾遗展示**：在「旅程助力」中加入施色及使用说明，调整四个物品的排列，与下方物品列对齐，并改善说明末尾标点的换行。

## 联动兼容

墓碑（Gravestone）、Caelus 与神化（Apotheosis）的相关适配改为按实际接口检查兼容性。检查不通过时，在日志中提示并停用对应适配，避免因这类接口不匹配而直接中断游戏启动。

- **墓碑**：停用联动后暂停苦旅的墓碑物品校正，保留墓碑中的物品和已有记录；恢复兼容版本并重启后重新检查。
- **Caelus**：接口不兼容时停用飞行适配，伊卡洛斯沿用未启用该适配时的飞行判定。
- **神化铁砧**：安装神化时，铁砧等级限制交由神化处理，避免重复修改；苦旅的费用封顶、免费取出与名称样式功能继续独立生效。

新增联动群系预设：Terralith 为六个主题提供65个候选群系，Incendium 为冥府提供8个，Alex 的洞穴提供6个群系，分配至繁茂、归墟、幽谷与冥府。Terralith 与 Incendium 支持模组版和数据包版。首次检测到时按实际存在的群系补充配置，新增权重为1，名称随语言资源显示；保留已有同 ID 设置，处理后不再自动补回玩家删除的条目。

新增14个模组的结构预设，共82个候选结构，按主题自动补充。结构与群系分别记录初始化状态，保留手动配置；结构抽取数量仍由原有配置决定。卫城归入归墟；万法皆通采用隐世樱花树、精灵秘境与堕天圣堂，Alex 洞穴仅补入群系。

冥府钓鱼与无垠幻翼的原版奖励默认池扩充为12项，加入鹦鹉螺壳、下界合金碎片与回响碎片，并调整基础材料的权重。新增8个模组、49个物品的奖励预设，保留各自权重与数量；首次检测到时补入缺少的条目，两个奖励池的默认值、联动预设与初始化记录分别维护，已有手动设置保留。

钓出生物的原版默认配置池调整为9项，以村民替换河豚并调整权重；新增妖怪们的飨宴、妖怪们的归家、新生魔艺、Ars Elemental 和车万女仆的15项生物联动候选，按实际注册内容补充。保留已有权重，独立记录初始化，钓鱼触发概率不变。

穷遐与幽谷新增12个来源、各36项增益效果联动候选，权重均为1，并保留各效果的预设最高等级。两个池分别初始化，只补充已注册的增益效果，保留玩家已有配置；原版默认权重不变。

黄金时代新增联动黑名单：安装对应模组时，将天体果实、深渊乱炖加入食物黑名单，将莱特兰扩充的六种免疫附魔及星月附魔的死亡刀刃、星月庇护加入附魔黑名单。两类分别初始化，保留已有配置；手动移除后不再自动补回。

妖怪们的归家与飨宴分别提供生物和增益效果预设，保留各自命名空间与初始化记录；已处理飨宴预设的配置仍可补充后来安装的归家预设。

## 完美流体

- **精妙背包**：拒绝复制内部装有捕获生物的背包，以及嵌套包含此类背包的受支持容器，原件与合成材料保留；该限制自动生效，无需填写配置黑名单，空背包或仅安装捕捉升级但未捕获生物的背包不受此限制。
- **超越维度**：新增压缩物质球复制适配，保留受支持资源的数量，独立复制其中受支持的嵌套库存，并沿用黑名单清理及特殊库存限制；需在原版背包合成栏或工作台完成，不复制超维网络本身。
- **提示说明**：将复制范围说明调整为“允许复制几乎任何物品”，并明确特殊库存拒绝复制时会保留材料，同步全部五种语言。

## 配置与战利品

### 配置阅读与管理

- **剑与灯**：新增围攻最低敌人数与判定半径配置，默认分别为11个、64格；可调整范围分别为2～64个、8～64格，玩家与女仆共用。
- 联动预设处理标记补齐中英文说明，中文模式名称统一为“旁观者模式”。

重新整理配置排版：六个主题均将群系池、结构池放在前面，联动预设处理记录集中在文件末尾，按群系、结构、奖励等类型分组，并标明对应模组。排版调整保留已有配置键、数值与列表顺序。

精简重复注释，补充数值单位、比例与属性加值的区别，并明确预设记录只控制是否继续自动补入，不代表功能启用状态。駅与巴别塔的独立携带位置开关说明同步澄清。

中英文配置说明书按“配置写法 → 预设 → 其他机制”分区，新增基础写法、各类列表格式、预设介绍及重试／跳过操作说明；复杂规则通过注释中的章节编号快速查找。

### 配置恢复与校验

改善配置写错时的处理。启动遇到无法解析的配置文件时，先将原件与错误说明保存在 `config/the_long_travail/invalid/`，再恢复该文件的默认设置；其他配置文件保持原有设置。

- **配置校验**：支持带 UTF-8 BOM 的配置和合法数字字符串。普通设置填错时，启动使用该项默认值，运行中沿用本次运行的有效值；无法解析的运行中修改会保留原文件，等待修正。
- **战利品隔离**：一张表写错不再阻断其他有效表；错误表沿用本次运行的有效规则，没有旧规则时暂停对应奖励。钓鱼宝藏子表概率独立处理，正常禁用和删除仍生效。
- **重载与提醒**：兼容直接保存和替换文件的保存方式；配置问题向单人玩家或服务器管理员汇总提醒一次。重复警告会被抑制，大量错误改为限量输出详情并汇总数量与文件，限制错误记录占用。

## 获取配置更新

已有配置需删除 `loot.tables."minecraft:gameplay/fishing"`，按上述来源调整箱表，并将 `loot.perfect_fluid.fishingChance` 替换为 `loot.fishing_treasure.itemChance = 0.1`；保存后执行 `/reload` 或重启。

## 高频战栗
