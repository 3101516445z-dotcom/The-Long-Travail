# The Long Travail 1.0.0

发布日期：2026-11-03

本次新增七件物品，让附魔转移、耐久保护、随机药水和名称染色有了新的选择；同时加入札记诗文、结构探索目标，并调整装备强度与获取方式。

## 新增内容

### 七件新物品

- 古今语怪：提取、保存并转移附魔。同种附魔合并时取较高等级再加 1，上限 255；可用蜂蜜瓶或发酵蜘蛛眼筛选非诅咒与诅咒。

- 永生芽：修满目标耐久并赋予「恒久长青」，保护耐久，防止掉落物被火焰、岩浆、爆炸或仙人掌破坏，也不会自然消失。

- 液化丰饶：点按切换普通、喷溅、滞留类型，长按转化为随机药水；支持模组效果，可通过合成或酿造获取。

- 施色：为物品名称选择九种显示样式，支持整组处理与还原，不改变物品属性。

- 高频战栗：挖掘速度为下界合金镐的两倍，不损失耐久。佩戴苦旅后可潜行右键发动能力：恶意提高掉落计算中的时运与幸运，见证可破坏黑名单外的通常不可挖掘方块。支持 FTB 连锁破坏。

- 逐日：携带时免疫火焰与岩浆伤害，在岩浆中恢复生命。恶意强化弹射物并反弹来袭弹射物；见证抑制目标治疗与无敌帧，并对燃烧目标追加直击伤害。可通过大师制箭师交易或沙漠考古获取。

- 籠釣瓶：腰带饰品，使伤害附带或延长凋零。恶意提高见切与霸主；见证将归属于佩戴者的伤害转为直击伤害。

逐日与籠釣瓶也支持女仆原生饰品栏，阶段能力取决于在线主人所佩戴的苦旅。具体配方与完整效果可在游戏内「拾遗」查看。

### 札记与语言

- 苦旅札记：新增卷首与题记诗文，加入卷首书签与双页独立滚动。

- 拾遗与悬浮说明：统一基础能力、恶意、见证和主动技能的排版；为直击伤害、处决、见切等术语加入悬浮解释。

- 语言支持：新增繁体中文（台湾／香港）与文言（华夏）。感谢 [zgxhzhr](https://github.com/zgxhzhr) 的翻译贡献。

- 视觉更新：更新黄金时代贴图，以及僵硬、视觉剥夺的状态图标。

## 玩法调整

以下数值均指模组默认设置；已有配置不会因默认值调整而自动覆盖。

### 生效条件与伤害规则

- 黄金时代、死者之书：由佩戴生效改为携带生效；死者之书仍需佩戴苦旅。

- 万魂幡：佩戴与收魂不再依赖苦旅；主题属性加成仍需对应阶段。

- 洛伦兹幻想：箭矢不下坠与穿透强化不再依赖苦旅；阶段能力仍需苦旅。

- 堂吉诃德、星之声、磷叶石：可放入任意功能饰品槽，每种仍限一件；星之声和磷叶石仍需佩戴苦旅。

- 直击伤害：堂吉诃德的恶意追加、春日一隅的玫瑰丛反击、洛伦兹幻想的见证追加改用此类型。伤害绕过护甲、减伤、无敌帧、盾牌与黄心，不消耗已有黄心；创造模式免伤与原版图腾仍生效。

## 获取与探索

### 配方与交易

- 全修：移除龙息与下界之星，改用萤石粉、回响碎片、紫水晶碎片、羽毛、青金石和黑色染料。

- 路引：移除下界之星，改用紫水晶碎片、钻石、青金石和末影之眼。

- 黄金时代：下界合金锭改为紫水晶块，青金石改为青金石块。

- 伊卡洛斯：下界之星改为阳光探测器。

- 槲寄生：中心材料由繁茂之石改为附魔之瓶。

- 无穷花：四个槲寄生改为四份骨粉与四份萤石粉，仍使用春日一隅。

- 地下丝绒：原配方的线改为羊毛，产出由 1 个增至 16 个；另增「六根线＋两份青金石＋一颗钻石」产出 1 个的配方。

- 洛伦兹幻想：交易价格由「64 绿宝石＋64 龙息」改为「16 龙息＋1 龙头」。

- 磷叶石：交易中的幽谷之石改为绿色染料，仍需 64 青金石。

已有大师村民的相关交易会同步更新材料，保留已使用次数。

### 钓鱼、考古与宝箱

- 钓鱼：駅、东海道五十三次移入宝藏子表，各占宝藏结果的 10%；完美流体由 5% 提高至 10%，归墟精粹由 10% 提高至 20%。这些是宝藏内占比，不是每次钓鱼的总概率。

- 沙漠考古：堂吉诃德由 5% 提高至 15%，新增逐日 15%；沙漠水井的穷遐精粹由 15% 提高至 20%。

- 海底废墟与古迹废墟：移除堂吉诃德；海底废墟新增完美流体 15%；普通古迹废墟新增磷叶石 10%，稀有古迹废墟的磷叶石由 5% 提高至 20%。

- 宝箱来源：死者之书从要塞图书馆移至下界要塞，一千年后从下界要塞移至林地府邸；逍遥游移出要塞箱子，死告天使移出远古城市，伊卡洛斯移出末地城。沉船补给箱新增完美流体。

- 宝箱概率：重新分配主题奖励，单件默认概率统一为 5%、7.5% 或 10%，每箱主题奖励总概率为 10%～20%。

### 结构探索

- 六主题各加入两个原版默认结构，结构目标的默认抽取数量由 0 个增至 2 个。

- 安装支持的模组后，自动补充对应群系与结构候选，包括 Terralith、Incendium、Alex 的洞穴等；已有配置和已生成的旅程保留。

## 联动与体验改善

- 完美流体：新增超越维度压缩物质球的复制支持；禁止复制装有捕获生物的精妙背包及包含它们的受支持容器，拒绝时保留材料。空背包不受此限制。

- 奖励与效果：扩充冥府钓鱼、无垠幻翼、钓出生物及穷遐／幽谷增益效果的默认池与模组预设；黄金时代新增联动食物和附魔黑名单。

- 可选模组兼容：改善墓碑、Caelus 与神化铁砧适配；接口不兼容时停用对应适配并提示，避免因此中断启动。

- 战斗兼容：完善一千年后在替换原版附魔实现的模组中的亡灵判定。

- 配置恢复：配置文件损坏时先备份原件再恢复该文件的默认值；单张战利品表出错不再阻断其他有效表，错误提示改为汇总提醒。

- 配置查阅：群系与结构池前置，联动预设记录集中展示；补全单位、列表写法与中英文说明书。

- 显示修复：修复部分 Forge 环境退出世界后的梦境冷却与时停显示残留；伊卡洛斯的资源包贴图异常时回退到内置贴图。

## 升级须知

- 存档与配置：更新前请备份。更新后生成或重置的旅程数据不支持降级；旧配置不会自动套用全部新默认值。

- 能力配置：剑与灯新增围攻人数和检测半径设置；路引搜索半径开放为 16～30000000 格，默认 5000 格；东海道唤雨不再提供禁用开关。

- 峰值配置：伊卡洛斯与午夜拉菲的特殊环境加成改为“普通峰值＋额外增量”，旧值自动换算；两项参数及见证加成的最低值均为 0.01。

- 考古保护：新增默认开启的结果保护，会跳过 Forge 全局战利品修改器对考古结果的后续修改；依赖这类修改的整合包可关闭该选项。

- 旧钓鱼配置：删除 `loot.tables."minecraft:gameplay/fishing"`，将 `loot.perfect_fluid.fishingChance` 改为 `loot.fishing_treasure.itemChance = 0.1`。新值表示駅、东海道五十三次和完美流体各自在宝藏内的概率。调整后执行 `/reload` 或重启；需要采用新版宝箱分布时，也须同步调整旧箱表。
