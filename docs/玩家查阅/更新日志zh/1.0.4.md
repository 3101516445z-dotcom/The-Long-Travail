# The Long Travail 1.0.4

发布日期：2026-11-08

## 未发布补充

### 三个战斗效果

- 新增中性效果“波旬变生”：获得50%伤害加成，伤害转为直击；命中施加5秒凋零Ⅲ，不覆盖更高等级凋零。每秒独立损失最大生命值的10%，最低保留1点生命。
- 新增中性效果“我于万物之中”：禁止造成和受到伤害，阻止SH扣血及生物仇恨。默认免疫所有标准kill，可通过配置关闭此项保护。
- 新增负面效果“还魂”：造成的伤害独立减少99%，自主移动速度减少50%。
- 三种效果均为固定强度，适用于玩家、女仆和其他生物，并使用独立图标。具体规则见[三个战斗效果](../三个战斗效果.md)。

### 肃正效果

- 新增物理肃正与魔法肃正，分别减少指定原版伤害类型中的物理类与魔法类伤害。
- 每级减伤10%，模组内默认上限Ⅴ；外部高等级最高减伤99%，与其他百分比减伤相乘。
- 两种效果使用独立图标，当前没有内置获取途径。伤害范围见[肃正效果](../肃正效果.md)。

### 伤害结算

- 将适用的百分比减伤统一为独立乘算环节，先补齐输出增幅，再结算减伤、见切、霸主与伤害吸收；各效果保留原有适用条件和单项上限。

### 饰品修复与优化

- 修复丁香延长负面效果时丢失隐藏药效的问题，玩家与女仆均保留后续药效，延长仅作用于当前药效。
- 地下丝绒无法确认奖励送达时提示玩家；保留已发奖励和冷却，不返还已消耗物品，也不补发奖励。
- 完美流体复制统一盘失败时，各项清理分别执行，避免一项报错阻止其余清理，原盘保持不变。
- 补充喜欢的心情、堂吉诃德、完美流体和高频震动对缺失注册信息的处理。
- 减少完美流体预览、磷叶石属性核对、槲寄生更新及部分花饰查询中的重复工作，保留原有生效条件、结算时机与奖励规则。

## 古今语怪

- 调整同种附魔转移所需的额外材料：
  - 相差11～100级，需要1个回响碎片和1个任意唱片；
  - 相差超过100级，需要1个回响碎片、1个任意唱片、1个下界之星和1个龙首。
- 相差不超过10级时仍无需额外材料，其他转移规则不变。

## 堂吉诃德

- 恶意状态下追加的直击伤害，由目标最大生命值的4%改为原攻击结算前目标当前生命值的4%，触发条件不变。
