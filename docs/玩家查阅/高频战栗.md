# 高频战栗

幽谷主题镐子，具有下界合金镐的采掘等级。正常挖掘速度乘以 2，不再损失耐久。最大耐久为2031。

## 合成

| | | |
| --- | --- | --- |
| 幽谷精粹 | 死告天使 | 幽谷精粹 |
| 空 | 下界合金镐 | 空 |
| 空 | 永生芽 | 空 |

有序合成获得 1 个。按照原版锻造的物品标签继承规则，保留下界合金镐的附魔、名称及其他标签数据，唯一例外是损伤值清零，合成结果修复至满耐久。

## 使用

主手持有、佩戴苦旅时，潜行右键方块发动能力。普通右键保留方块交互。

- **幽谷恶意**：立即完成普通挖掘，掉落计算中的时运等级与幸运值乘以 2。不能破坏负硬度方块；采收资格仍按下界合金镐判定，工具不满足掉落条件时不产生战利品。
- **幽谷见证**：可以破坏通常不可挖掘的方块，黑名单除外；掉落按手持镐子的正常规则结算，没有正常掉落的方块不会强制掉落自身。
- 两种状态都保留时运、精准采集与保护事件的作用。精准采集遵循方块战利品表：例如原版钻石矿在精准采集分支掉落矿石，不进入时运增产分支；恶意不会额外复制精准采集产物。创造模式不产生普通挖掘掉落。
- 沿用方块自身的正常掉落逻辑，不额外复制物品、容器库存或经验。按包含苦旅等饰品加成的有效时运计算，例如时运 III 加冥府见证 +6，恶意按 (3 + 6) × 2 = 18 计算；没有附魔但有 +6 时按 12 计算。没有任何时运来源时仍为 0。恶意计算后的有效时运固定最高为 1024，不开放配置；异常负时运按 0 处理。此限制不改变普通挖掘或幽谷见证的时运。幸运仅影响使用幸运参数的战利品表，不保证掉落数量翻倍。镐子的实际附魔与玩家幸运属性保持原值。
- 安装 FTB Ultimine 时，潜行并按住连锁键右键，能力应用于其选区；保留 FTB 的选区限制和排除规则，每个方块独立检查保护及黑名单。

## 黑名单

位置：`config/the_long_travail/aspects/deep_valley.toml`。

```toml
[items.high_frequency_tremor]
    witnessBreakBlacklist = ["minecraft:barrier"]
```

填写完整方块 ID。默认仅禁止见证破坏屏障；基岩允许破坏，但不会凭空生成基岩掉落物。名单只限制见证的特殊破坏，同样作用于连锁中的每个方块。

黑名单必须使用完整的 `namespace:path`，不自动补全或修改大小写。存在非法条目或类型错误时，整项黑名单在重载时保留上次有效值，磁盘上的错误内容不改写；启动时备份原文件并恢复默认黑名单，其他有效配置保留。完整但尚未注册的 ID 会保留并提示，便于可选模组配置；空列表 `[]` 合法。

特殊破坏的回调出现普通运行时异常时，本次操作停止并记录日志；连锁不再处理后续方块。已发生的方块变化和掉落不会回滚，也不会通过重试补发物品。

直接点中的方块被见证黑名单禁止时，快捷栏上方提示“高频战栗：该方块已被列入破坏黑名单。”；特殊破坏或连锁执行异常时提示“高频战栗：特殊破坏发生异常，本次操作已停止。”。同一使用者的同一种提示每40游戏刻最多显示一次，两类提示分别限频。连锁内部跳过的黑名单方块不逐块提示。

## 游戏内说明

风味文本：破碎的世界摇摇欲坠，直到祂尖叫着醒来。

拾遗末行按服务器有效配置显示“当前无法破坏的方块：……”，默认显示屏障，空名单显示“无”。方块名称随语言变化，未注册条目显示原 ID；该列表不枚举领地保护等临时限制。
