# 波旬变生、我于万物之中与还魂

这三个效果强度固定，提高效果等级不会改变下述数值。效果可以施加于玩家、女仆和其他生物。

| 效果 | 分类 | 规则 |
| --- | --- | --- |
| 波旬变生 | 中性 | 获得 50% 伤害加成，造成的伤害转换为直击；命中施加 5 秒凋零 III，不覆盖更高等级凋零。每 20 游戏刻损失最大生命值的 10%，本次损失不会使生命低于 1。 |
| 我于万物之中 | 中性 | 禁止造成和受到伤害，保护生命值免受 SH 扣除；其他生物不能以该实体为攻击或复仇目标。治疗仍按原有规则生效。 |
| 还魂 | 负面 | 造成的伤害独立减少 99%，自主移动速度减少 50%。 |

波旬变生的周期损失独立计算，不参与伤害增减幅，不消耗吸收生命，也不触发攻击收益。刷新效果不会重新开始扣血计时，移除后重新施加则重新计时。凋零通过正常药水入口施加，保留已有时长规则。

还魂的减速覆盖行走、游泳、飞行与鞘翅水平移动，保留跳跃高度、自然下落和外部推力。

“我于万物之中”默认阻止所有标准 kill（包括管理员 `/kill` 和普通 `LivingEntity.kill()`）。在 `config/the_long_travail/general.toml` 中，将 `effects.amongAllThings.immuneToKill` 设为 `false` 可放行标准 kill 伤害；其他来源的伤害与 SH 仍受保护。

注册名依次为 `the_long_travail:mara_transformation`、`the_long_travail:among_all_things`、`the_long_travail:revival`。
