# 解密之石

替换原旅人纹章客户端联动。未见证页面始终显示解密页签，只有当前玩家使用对应石头后才显示条件；使用石头不直接授予见证，也不更改苦旅已有的反转判定。

六个物品 ID：`flourishing_stone`、`abyss_stone`、`far_reach_stone`、`deep_valley_stone`、`underworld_stone`、`boundless_stone`，命名空间均为 `the_long_travail`。材质直接复制制作人提供的六张 64×64 RGBA PNG。

右键使用：服务端首次记录对应位并消耗一颗（创造模式不消耗）；已经解密时提示并不消耗。无需先装备苦旅，可先使用石头，之后再获得或更换苦旅。

记录位于玩家持久 NBT 的 `PlayerPersisted/the_long_travail/revealed_aspects`，不在物品 NBT 中。玩家复制事件只深拷贝本模组的玩家数据；登录、重生、换维度、使用石头均同步至客户端，离线时清空客户端缓存。网络协议升级为 4，联机双方应更新相同版本。

配方按用户给定九宫格输出一颗。任意陶瓦接受原色及 16 色陶瓦，不包含带釉陶瓦；垂滴叶接受大、小垂滴叶。穷遐之石中心已改为空地图 `minecraft:map`，移除 Goety 条件；六套配方的全部材料均为原版物品。桶等容器沿用原版合成余物行为。

检查：六套九宫格共 54 个材料位置的资源引用、输出及模型；原材质字节一致；两种语言键一致；解密六位独立、重复解密、NBT 压缩保存/读取、克隆副本和不同玩家隔离；Gradle 编译与打包。尚未在完整游戏中实测合成、使用、死亡复活和更换苦旅。
