# 第二批修复

## 实现

- 幻翼：删除 getAllEntities。使用 getEntitiesOfClass(Phantom.class, AABB, predicate) 查询附近已加载实体，再做球形距离判断。默认半径 32 格，每秒一次；按玩家 UUID 错开 tick；不主动加载区块。扫描范围配置上限 128 格，检查周期不低于 1 秒。
- 数量限制：额外槽位和单次效果数量上限 64，效果等级上限 256、等级奖励上限 255；单次随机奖励数量最多 4096。当前整合包相关配置均低于上限。Forge 对超限标量记录纠正警告；池中超限数量记录警告后限制。
- 随机池：服务端启动和配置重载时预解析并缓存，过滤无效/未注册目标，重复 ID 保留第一项并警告；随机抽取仍在每次触发时独立进行。
- 页面：缓存正文分行、光学对齐偏移、效果与条件列表，以及条件名称映射。页面、见证、解密、条件 NBT、探索数量、配置、语言或字体资源变化时刷新对应缓存；攻击冷却 NBT 不影响缓存。光晕采样与视觉效果不变，书签仍逐帧更新。
- 生命周期：退出时清理同步配置与输入状态；窗口失焦清理可能丢失释放事件的按键记录。只读 NBT 不再调用 getOrCreateTag。
- 飞行：记录基线与苦旅上次写入速度；发现外部改写时重建基线，撤销时不覆盖新的外部速度，支持 100% 减速。仍不能保证兼容所有每 tick 同时强写速度的模组，需要按实际组合验证。
- 吸收生命：只在 Player.actuallyHurt 的首次吸收抵扣读取处，对 fluid_erosion 返回 0。真实吸收状态不清零、不恢复快照，后续原版伤害/图腾流程继续运行。
- 可选兼容：在应用 JEI/Sounds Mixin 前检查目标字节码中的方法/字段结构，不匹配时跳过并警告。可选注入不再因缺少目标方法单独强制失败；核心注入仍严格检查。
- “反转条件将在佩戴后生成。”补全句号，英文对应句同步补句号。
