# 日记界面验收

## 已确认设计

- 唯一入口：实际悬浮苦旅并显示其物品提示时，按可重绑的阅读键（默认 J）。目标必须是这一件物品。
- Esc、Backspace、鼠标右键、右上角 × 关闭阅读层，返回原界面，不穿透输入。
- 六个独立书签、固定平整双页、局部手写字体、短条目和可滚动条件。
- 联动未安装或当前为见证时无解密入口；其他状态按纹章佩戴与初始化状态决定披露。

## 检查项目

1. 非悬浮时按阅读键无效，移开后无效；悬浮目标能打开；长按只打开一次。
2. 更改阅读键后，原键失效、新键生效，物品提示同步更新；取消绑定时提示未绑定。
3. 四种退出均保留原容器界面，右键不拿取、放下或分割下面的物品；按键释放不穿透。
4. 各书签切换正确，返回记住篇章；当前详情数值来自服务端同步配置。
5. 无联动时不显示纹章相关内容；见证不显示反转入口；未解密不显示目标名称和完成进度。
6. 佩戴对应纹章后仅开放对应篇章；摘下后锁定；未初始化时显示首次佩戴提示。
7. 中文、英文、长群系名称、长结构名称以及多条条件换行和滚动正确。
8. 小窗口中书签、× 和正文不超出窗口，字体不缺字，界面不显示退出快捷键说明。
9. 阅读层存在时原容器失效，阅读层也随之关闭，不恢复失效菜单。

测试客户端使用 `build/diary-client`，与项目原有 `run` 存档隔离。测试环境中若输入法拦截普通字母键，可临时将阅读键绑定 F7、物品栏绑定 F6；这不改变模组默认 J 的定义。

构建命令：Java 17 环境下运行 `gradlew.bat build`。

## 当前 UI 调整（待实机复测）

- 界面整体缩小 20%，使用游戏默认字体，移除内置手写字体。
- 日记打开时拦截 JEI 的独立绘制入口，关闭后恢复。
- 书本和书签启用透明混合；书签只保留颜色，悬浮提示不变。

## 当前长按交互（待实机复测）

- 悬浮同一件苦旅并长按阅读键 1.5 秒打开；松开后进度回退，换物品清空进度。
- 进度条紧接长按提示下方：无括号、无分段的连续细线，高 3 像素，与提示文字等宽；暗灰底（#353535）、中灰填充（#858585），上方留 3 像素、下方留 5 像素。默认左 Shift，长按 1.5 秒打开，松开回退。
- 不再绘制屏幕底部的 ASCII 进度条。
- 中文提示加入精确内容校验，防止编码转换将汉字替换为问号。
- 复测原版、Obscure Tooltips 与 JEI 下的提示排版、按键重绑定、提前松开及退出。
