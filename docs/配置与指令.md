# 配置与指令

配置位于 `config/the_long_travail/`，首次启动时自动生成。各主题设置放在 `aspects/` 下，饰品与道具奖励在 `general.toml` 中调整；材料与精粹来源由战利品数据表及注入规则定义，详见 [配置说明](../src/main/resources/assets/the_long_travail/config/configuration-guide.zh_cn.txt)。

主题文件按 `travail`（苦旅）、`items`（物品）和 `presets`（预设注入区）分组。在对应主题的 `presets` 分组中调整联动预设。

## 清除自身状态

管理员可用以下命令分别清除苦旅造成的僵硬和视觉剥夺。

```text
/tlt stiff clear
/tlt visual_deprivation clear
```

普通 `/effect` 命令只能添加或移除这两个状态的图标，不会改变实际限制。

## 反转调试指令

以下指令需要 2 级权限，并在旅行日记槽位佩戴苦旅：

- `/tlt reverse`：将六项全部强制设为见证，相当于依次执行 `reverse 1` 至 `reverse 6`。
- `/tlt reverse <编号>`：正数 `1` 至 `6` 强制设为对应见证，负数 `-1` 至 `-6` 强制设为对应恶意；`0` 无效。
- `/tlt reverse clear`：清除全部调试覆盖，恢复按照真实旅程进度判定。
- `/tlt reverse clear <编号>`：清除对应编号的调试覆盖；`0` 表示全部。

调试指令不会补完或清空真实旅程进度。
