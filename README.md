# The Long Travail / 苦旅

由 **Phoebe_Real** 制作的 Minecraft Forge 模组。佩戴核心饰品「苦旅」后，你将背负六种恶意，前往旅程指定的群系与结构，逐一将恶意反转为见证。

用旅行日记查看旅程记录，用解密之石揭开各篇章的反转条件。长按 **Alt** 打开物品图鉴「拾遗」，查阅物品的效果、用法与当前配置数值。

## 环境要求

Minecraft **1.20.1** · Forge **47.4.10 或更高的 47.x 版本** · Java **17** · Curios **5.14.1 或更高的兼容版本**
