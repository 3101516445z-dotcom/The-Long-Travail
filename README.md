# The Long Travail / 苦旅

由 **Phoebe_Real** 制作的 Minecraft Forge 模组。模组围绕不可轻易卸下的核心饰品“苦旅”展开：玩家需要背负六种恶意踏上旅程，探索随机生成的群系与结构条件，并将恶意永久反转为见证。

## 环境要求

- Minecraft 1.20.1
- Forge 47.4.20 或更高的 47.x 版本
- Java 17
- Curios 5.14.1 或更高的兼容版本（必需）

## 安装

1. 安装 Minecraft 1.20.1 对应的 Forge 与 Curios。
2. 将本模组 JAR 放入游戏实例的 `mods` 文件夹。
3. 启动游戏；首次进入世界时默认会获得“苦旅”，该行为可以通过配置关闭。

## 主要内容

- 六组“恶意／见证”状态与独立的随机探索旅程。
- 专属旅行日记 Curios 槽位和可阅读的旅程记录界面。
- 六种解密之石，用于揭示各篇章的反转条件。
- “归乡”物品，可在保留进度的情况下取下苦旅。
- 丰富的服务端配置，以及中英文界面文本。

## 高空速度惩罚

无垠之恶意的高空移动速度惩罚不是移动速度属性修饰符，而是在读取移动速度时计算。

因此它无法被任何“抵消移动速度减益”的手段移除，也不依赖任何特定模组：潘多拉之咒的「现实第四诅咒：羸弱」、祝福之潘多拉对应的反转祝福，以及其他同类机制都只能作用于属性修饰符，触及不到该惩罚；这些模组自身的加成与饱食度相关效果照常生效。

高度阈值、压制比例与解除条件沿用无垠原有配置，不重复施加减速。步行与游泳在移动速度读取处处理，创造飞行与鞘翅仍按各自路径独立处理。模组内描述不添加上述联动说明。

## 视觉剥夺

幽谷之恶意在受击时按配置概率施加「视觉剥夺」：画面脉动变暗、视野收紧、天空被遮蔽、夜视失效。它只影响画面，不改变任何数值，也不会阻碍移动、攻击或跳跃。

解除方式：等待持续时间结束，或饮用牛奶（遵循原版解除负面效果的逻辑）。

画面由本模组自己记录的状态驱动，而不是由药水效果驱动。因此「免疫负面效果」「清除负面效果」一类的饰品或模组最多只能挡住状态栏上的图标，挡不住画面本身；同理，「免疫黑暗」也不再能免除幽谷之恶意。

可调配置（`config/the_long_travail-common.toml` 的 `[deepValley]` 段）：

- `visualDeprivationChanceOnHit`：受击时施加的概率，默认 0.50
- `visualDeprivationDurationSeconds`：持续秒数，默认 5.0
- `visualDeprivationFadeInTicks`：开始时的渐入刻数，默认 30；实际不会超过持续时长的 40%
- `visualDeprivationFadeOutTicks`：结束时的渐出刻数，默认 30；实际不会超过持续时长的 40%

画面本身的可调项在 `[visualDeprivation]` 段：变暗强度对应 `worldDarkening`（默认 0.65），波动对应 `pulseDepth`（默认 0.0，0 表示不波动），其余见 [视觉剥夺设计说明](docs/visual-deprivation.md)。
